# DuckbillFisher 대표 아이콘

2026-11-15 공개0.10.0.1: 원본 그림을 직접 편집하는 방식으로 넓적한 부리·갈색 몸/크림 배·작은 눈을 우선하고, 오른쪽에서 짧은 앞발로 낚아 올리는 자세로 정리했다. 후속으로 물고기를 얼굴 가까이 모으고 낚싯대 곡선을 낮춰 작은 크기에서 얼굴과 낚시 동작이 연결되도록 했다. 발밑의 옅은 세이지색 물결 두 줄과 따뜻한 물가 면을 조금 넓히고 꼬리 뒤에 작은 풀잎을 더해 떠 있는 느낌을 줄였다. 큰 물고기와 낚싯대로 낚시 기능을 먼저 구분하며 글자·원형 배지·파란 배경은 제거했다. Calendar/Tweak과 윤곽선·색감을 맞춘 투명 PNG다.

- `duckbillfisher-icon.png`: README/설치 목록에서 사용하는 512×512 RGBA PNG.
- `source/duckbillfisher-icon-master.png`: built-in image_gen의 수정하지 않은 원본(1254×1254). 배포용은 alpha>16의 그림 경계(137,270 / 1001×784)를 기준으로 아주 옅은 외곽 잔상/여백을 정리하고 비율을 유지해 축소했다. 가장 긴 변에 최소7% 여백을 두며 그림을 다시 그리거나 색을 바꾸지 않았다.
- `previews/duckbillfisher-128.png` / `previews/duckbillfisher-64.png`: 실제 축소본. 스모크/펄 배경에서 기능 구분과 윤곽을 확인했다.
- [생성 프롬프트와 참조 이력](icon-prompt.txt): 기존 Fisher `aced4cc`에서 이어진 `1ed6aeb`의 원본을 편집 대상으로 사용해 물가 면/풀잎만 조금 보강했다. 512/128/64px·스모크/펄 배경에서 전후를 비교했다. 세 플러그인의 바닥/주변 맥락을 보강하고 같은 여백 기준으로 축소했다.

현재 PNG는 v0.10.0.1 태그에 게시했고 ZIP/체크섬·태그 아이콘의 익명 해시를 확인한 뒤 설치 목록을 갱신했다. 이전 원형 그림과 과거 공개 태그/ZIP은 보존한다.
