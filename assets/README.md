# DuckbillFisher 대표 아이콘

2026-11-15 개발 후보: 원본 그림을 직접 편집하는 방식으로 넓적한 부리·갈색 몸/크림 배·작은 눈을 우선하고, 오른쪽에서 짧은 앞발로 낚아 올리는 자세로 정리했다. 후속으로 물고기를 얼굴 가까이 모으고 낚싯대 곡선을 낮춰 작은 크기에서 얼굴과 낚시 동작이 연결되도록 했다. 발밑에만 옅은 세이지색 물결 두 줄과 따뜻한 물가 면을 작게 추가해 떠 있는 느낌을 줄였다. 큰 물고기와 낚싯대로 낚시 기능을 먼저 구분하며 글자·원형 배지·파란 배경은 제거했다. Calendar/Tweak과 윤곽선·색감을 맞춘 투명 PNG다.

- `duckbillfisher-icon.png`: README/설치 목록에서 사용하는 512×512 RGBA PNG.
- `source/duckbillfisher-icon-master.png`: built-in image_gen의 수정하지 않은 원본(1254×1254). 배포용은 alpha>16의 그림 경계(138,272 / 1000×781)를 기준으로 아주 옅은 외곽 잔상/여백을 정리하고 비율을 유지해 축소했다. 가장 긴 변에 최소7% 여백을 두며 그림을 다시 그리거나 색을 바꾸지 않았다.
- `previews/duckbillfisher-128.png` / `previews/duckbillfisher-64.png`: 실제 축소본. 스모크/펄 배경에서 기능 구분과 윤곽을 확인했다.
- [생성 프롬프트와 참조 이력](icon-prompt.txt): 기존 Fisher `aced4cc`에서 이어진 `a10bc49`의 원본을 편집 대상으로 사용해 작은 물가 면만 더했다. 512/128/64px·스모크/펄 배경에서 전후를 비교했다. Calendar/Tweak은 변경하지 않았다.

현재 파일은 개발 후보이며 기존 공개 태그·Release·설치 JSON은 바꾸지 않았다. 기존 원형 그림은 Git 이력에 보존한다. csproj IconUrl과 README의 경로는 유지하며 게시할 버전의 태그에 새 PNG가 포함되어야 한다.
