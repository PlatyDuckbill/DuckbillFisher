2026-11-15 개발 후보: 원본 그림을 직접 편집하는 방식으로 넓적한 부리·갈색 몸/크림 배·작은 눈을 우선하고, 오른쪽에서 짧은 앞발로 낚아 올리는 자세로 정리했다. 큰 물고기와 낚싯대로 낚시 기능을 먼저 구분하며 글자·원형 배지·파란 배경은 제거했다. Calendar/Tweak과 윤곽선·색감을 맞춘 투명 PNG다.

- `source/duckbillfisher-icon-master.png`: built-in image_gen의 원본(1254×1254). 그림/alpha를 유지해 크기만 정규화했다.
- `previews/duckbillfisher-128.png` / `previews/duckbillfisher-64.png`: 실제 축소본. 스모크/펄 배경에서 기능 구분과 윤곽을 확인했다.
- [생성 프롬프트와 참조 이력](icon-prompt.txt): 기존 Fisher `aced4cc`의 대표 그림을 직접 편집 대상으로 사용했다. 생성 후에는 크기만 정규화했다.

현재 파일은 개발 후보이며 기존 공개 태그·Release·설치 JSON은 바꾸지 않았다. 기존 원형 그림은 Git 이력에 보존한다. csproj IconUrl과 README의 경로는 유지하며 게시할 버전의 태그에 새 PNG가 포함되어야 한다.
