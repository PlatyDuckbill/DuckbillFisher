작성: 2026-11-04 · 갱신: 2026-11-04. 이 문서는 KR·글로벌을 함께 지원하고 공식 Dalamud 저장소(goatcorp/DalamudPluginsD17)에 등록하는 작업의 **전략·단계·진행도**를 담당한다. 현재 공개판의 사실은 [STATUS](../STATUS.md), 확정된 구조는 [ARCHITECTURE](../development/ARCHITECTURE.md)를 따른다. 이 문서의 계획은 단계별 승인 전에는 코드·방침 변경 지시가 아니다.

## 전략

1. **실행 계약은 Dalamud 생태계 방식을 따른다.** ClientStructs와 Dalamud는 실행 중인 배포판이 제공하는 것을 사용하고, 로드 가능 여부는 Dalamud의 API 레벨 판정에 맡긴다. DLL 해시나 게임 빌드 번호를 정확히 일치시키는 검사는 제거 대상이다.
2. **안전은 기능 단위로 확보한다.** 각 네이티브 기능은 실행 중에 자신의 계약을 검사한다(화면 형태, 로그 형식, 값 범위, 스레드/수명). 실패하면 그 기능만 Unknown으로 끄고 수동 상태를 보존한다. 하나가 실패해도 다른 기능을 막지 않는다.
3. **지역과 언어에 의존하는 판정을 없앤다.** 번역 문장이나 지역별 하드코딩 오프셋으로 판정하지 않는다. ID와 구조로 판정하고, 이름과 표시는 클라이언트 시트 언어를 따른다.
4. **자료는 하나로 관리한다.** 가능하면 ID 기반 자료 하나를 두고, 실행 중인 클라이언트 시트에 없는 행은 숨긴다. 지역별 파일 분리는 차이가 입증된 경우에만 검토한다.
5. **공식 정책을 우선한다.** 자동 조작·서버 상호작용·런타임 HTTP 금지 같은 기존 경계는 유지한다. 제출 직전에 공식 규정을 다시 확인한다.
6. **산출물 하나로 두 지역을 지원한다.** KR 배포판도 공식 PluginMaster를 같은 판정 코드로 사용하고, 공식 목록에는 플러그인마다 항목이 하나뿐이다([근거](../verification/native/GLOBAL-COMPAT.md#p0-kr-배포판의-공식-저장소-사용)). 사용하는 API와 ClientStructs 멤버는 KR과 글로벌 참조 양쪽에서 빌드 검사를 통과해야 한다. API 전환기에는 다른 공식 플러그인과 마찬가지로 글로벌 API를 따르고, KR 설치본은 KR 배포판이 따라올 때까지 이전 버전으로 유지된다.

## AI 사용 정책 대응

- 공식 정의상 현재 방식은 **Copilot(사람이 계획·검증, AI가 대부분 작성)과 Auto(사람은 방향·승인, 코드를 직접 다루지 않음)의 경계**다. 최종 수준 판단과 PR의 AI 공개 문구는 정책상 **사람이 직접 작성**해야 한다. AI가 대필하지 않는다.
- 사람의 실질적 관여(기획·판단·테스트)가 있으므로 "전부 AI 생성"의 자동 거절과는 다르다. 다만 Copilot/Auto 제출은 검토자 재량이며, 코드가 작성자가 보여 준 이해 범위보다 크거나 복잡하면 **전체 검토 없이 닫힐 수 있다.** 현재 C#은 약 2만 줄(Plugin 약 1.64만 줄)이다.
- 검토자의 "왜 이렇게 구현했나"에 "AI가 했다"로 답하면 안 된다. 제출자 본인의 테스트도 필수다.
- 대응 방안:
  1. **설명 가능성 확보:** 핵심 흐름(가드·수집·타이머·예측·저장)을 사용자가 직접 설명할 수 있도록 학습용 구조 설명 자료와 설계 결정 기록을 만든다.
  2. **규모와 복잡도 축소:** 등록에 필요 없는 진단·개발 전용 경로와 중복 구현을 줄이는 후보를 검토한다.
  3. **사전 문의:** 제출 전 goatcorp Discord에서 AI 사용 수준과 플러그인 범위를 미리 문의할지 결정한다.
  4. **아이콘 공개:** 유지하기로 했으므로 설명에 AI 생성을 공개한다.

## 기존 공식 플러그인과의 관계 (조회 2026-11-04)

- 공식 목록 500개 중 낚시를 다루는 플러그인은 다음과 같다.

  | 플러그인 | 다운로드 | API | 범위 |
  |---|---|---|---|
  | GatherBuddy | 약 458만 | 15 | 채집 전반과 낚시 |
  | DistantSeas | 약 34만 | 15 | 먼바다 전용 |
  | AcquisitionDate | 약 6만 | 15 | 습득 날짜 표시 |
  | OceanFishin | 약 1.5만 | 8 | 구버전, 먼바다 |

  일반 낚시에서 실질적으로 겹치는 것은 GatherBuddy 하나다. 공식 제한 규정에 기능 중복 금지 조항은 없지만, 검토는 "생태계 영향"을 포함해 주관적이다.
- GatherBuddy의 낚시 관련 구성은 소스 폴더와 탭 이름으로 확인했다(세부 동작은 미확인).
  - 어종 탭(조건 확장 표시), 알람 탭, 채집 창(출현 목록)
  - 날씨 탭, 기록·통계 탭
  - 낚시 타이머 창(FishTimer, FishRecorder 기반 입질 기록)
  - 작살 도우미, 채집 그룹, 위치 탭, 명령어
- **겹치는 범위:** 어종 목록과 조건, 출현 시간, 출현 알림, 날씨, 시전 타이머와 기록. 플러그인의 기본 골격은 상당 부분 겹친다.
- **겹치지 않는 범위(차별점):** 터주작 진행 흐름에 집중된 기능들이다.
  - 추천 세 탭(지금 노릴 어종, 밑작업, 출현 드문 순)
  - 직감 선행 조건 예측과 계산 근거 표시, 물고기의 눈 예측 전환
  - 30일 출현 일정표(시간축, 월 달력)
  - 확장팩·지역별 수집 현황과 도감 대조
  - 즐겨찾기·필터 대상의 미끼 준비와 소지 수량, 게임 미끼 화면의 페이지 표식·강조
  - 현재 낚시터의 미수집 터주·터주왕 알림
  - 어종별 메모·도전 횟수, 설정 백업, 한국어 UI
- **GatherBuddy가 더 넓은 범위:** 채광·원예 채집, 작살, 입질 시간 통계(이 플러그인은 사용자 보류)
- **방향:** 설명과 소개는 "낚시 타이머/목록"이 아니라 **"터주작 진행 도우미"**로 차별점을 앞세운다. 사전 문의를 한다면 중복 범위와 차별점을 함께 밝힌다.
