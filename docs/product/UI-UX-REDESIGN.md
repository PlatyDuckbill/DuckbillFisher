# UI 구성과 사용성 기준

현재 사용자 동작은 [PRODUCT](PRODUCT.md#화면과-상호작용), 구현 책임은 [ARCHITECTURE](../development/ARCHITECTURE.md)를 따른다. 이 문서는 화면 합의와 조사 근거를 유지한다. 과거의 최대 세 화면/독립 필터 설명을 현재 제약으로 적용하지 않는다.

## 확정한 화면 구조

- 알림 설정(2026-10-24 합의): 즐겨찾기 관리의 ‘즐겨찾기 / 출현 알림 설정 / 발송 기록’ 세 탭으로 출현 알림 설정을 모으고 기존 메인 일반 설정에서는 옮긴다. 켜기 스위치는 가운데 탭 최상단의 강조 영역에 두고 바깥 스위치/톱니는 없앤다. 기본 사전 시간·채널은 각각 라벨/입력이 같은 행이다. 캐스팅 알림·프리셋 편집과 전용 채팅 채널은 기존 타이머 설정에 유지하며 공통 출력 이동 버튼을 제거한다. 입질·터주·터주왕 효과음에는 채팅 기능을 추가하지 않는다. 어종별 메모·수동 횟수·프리셋 연결은 후속 개발본의 [메모·캐스팅 타이머 관리](FISH-PERSONAL.md) 접힘 영역에 구현했다.

- 일반 설정 정리(2026-10-24 합의): 기존 구역 순서를 유지하고 입력을 두 열의 라벨/값으로 정렬한다. 배율 복원은 선택기 옆 아이콘으로, 업데이트 내역은 같은 값 열의 버튼으로 묶는다. 백업 동작은 동일 폭의 아이콘 버튼으로 정렬하고 긴 설명은 기본 접힘으로 옮긴다. 필수 오류/복원 안내는 숨기지 않는다. 캐스팅 알림의 반복 설명은 줄이고 상세는 관련 입력/버튼 툴팁에 둔다.

- 수집 현황: 2026-10-20 사용자 합의로 메인의 별도 탭이다. 확장팩→지역 펼침 표와 진행 막대를 함께 제공한다. 도감 전체 기준이며 일반 낚시는 전체/터주(왕 포함)/터주왕 보기를 전환하고 먼바다는 별도 구역에 둔다. 일반 낚시 합계는 사용자 추가 선택으로 표 위 큰 요약 블록에 분리한다. 지역별 막대는 가용 폭을 따르며 진행률별 색을 나눈다. 확장팩/지역/먼바다 막대는 독립 어종 목록1개를 재사용하고 직접 닫기 전까지 유지한다. 일반/도감 합계에는 클릭 목록을 제공하지 않는다. 먼바다는 시트의 해역 ID별 현황과 클릭 목록을 제공한다. 합계 옆 클릭 안내/하단 기본 접힘 수집 규칙을 사용한다. 메인 탭은 아이콘과 문구를 함께 표시한다.0.4 내역은 새 기능 소개·기능별 설명과 기타 개선으로 나눈다. Unknown은 미수집과 나눠 표시한다. 세부 집계 계약은 [PRODUCT](PRODUCT.md#화면과-상호작용)를 따른다.

- 메인: 어종 목록/수집 현황/즐겨찾기 관리/낚시 기록/설정. 어종 선택은 오른쪽 상세 패널을 갱신한다. 2026-10-20 사용자 선택에 따라 상세 상단의 등급·별·수집 상태와 같은 줄에 ‘별도 화면으로 보기’를 둔다. 좁은 폭에서는 툴팁을 가진 아이콘으로 축약한다. 기존 독립 상세1개를 재사용하며 이후 메인 선택과 독립적으로 유지한다.
- 간이 목록: 출현 중→예정 목록. 즐겨찾기 여부를 제외한 메인 일반 필터를 공유하며 즐겨찾기만 보기/예정 범위는 별도 저장한다. 상단 별 버튼과 옵션의 체크박스로 같은 전용 필터를 조절한다. 선택한 어종은 독립 상세 하나를 재사용한다.
- 비교 상세: 생미끼/직감 선행 어종 클릭으로 원래 상세를 유지한 채 별도1개를 연다. 비교 안에서 이동/뒤로(최대32단계)가 가능하다. 2026-10-19 사용자 선택으로 합의했으며 어종별 다중 생성은 하지 않는다.
- 캐스팅 타이머: 현재 낚시와 최근 시전 기록. 낚시터 이름 옆 어종 보기에서 독립 수집 필터 목록을 연다.
- 미끼 준비: 직접 닫기 전까지 유지되는 독립 보조 화면. 메인을 닫아도 유지한다. 상세 제목의 미끼 찾기와 역할을 구분한다.
- 기존 세 화면 합의 이후 타이머·준비 화면이 별도로 승인됐다. 추가 분리/주요 배치 변경은 사용자에게 차이와 동선을 설명하고 합의 후 구현한다.

## 표시와 상호작용 기준

- 목록/즐겨찾기 탐색을 중심에 두고 진단은 개발자 옵션 뒤로 둔다. 개발자 옵션을 정상 수집/예측/알림의 동작 조건으로 사용하지 않는다.
- 도감 미조회와 호환성 차단은 구분한다. 중요한 상태·필요 동작은 눈에 보이게 두고 보조 설명만 툴팁에 넣는다.
- 미끼·날씨·스킬은 게임 아이콘을 사용하고 이름/의미/대체 표시를 제공한다. 단계 순서·현재/직전·AND/OR 의미를 아이콘 축약으로 잃지 않는다.
- 어종 아이콘 크기를 유지하고 오른쪽 정보 묶음과 세로 중앙 정렬한다. 넓은 폭은 가로 묶음, 좁은 폭은 줄바꿈과 보조 툴팁으로 정보 접근을 유지한다.
- 이름 바로 아래 등급·별·수집 선택을 묶는다. 수동 지정은 명시하고 자동이라는 기본 표시는 반복하지 않는다. Unknown을 체크 해제=미수집으로 바꾸지 않는다.
- 출현 중/예정은 짧은 문구·아이콘·색상을 함께 쓴다. 시간과 실제 시각 범위를 가까이 두고 개인 준비 완료를 확정하지 않는다.
- 필터 기본값 복원은 정렬이 보이는 위치에서 접근한다. 초기화/전체 보기/프리셋 불러오기의 의미를 구분한다.
- 전승록은 상세에서만 표시한다. 0.3.4.0부터 필터 줄에 물고기의 눈 아이콘 ON/OFF를 두고 기본 OFF·선택 기준 시간순 정렬을 제공한다. 고정 미사용 안내는 삭제하며 상세의 두 예측은 달라질 때만 표시한다. 직감 계산 구역은 대상/선행 어종 시간과 최종 결과를 구분한다.
- 0.3.5.0부터 직감 계산은 기본 접힘이다. 펼친 표에는 어종 아이콘·대상/선행 역할·각 구간을 나누고 최종 출현은 색과 시계 아이콘으로 강조한다. 반복 준비 상태 문장은 없애고 보조 문구 하나만 둔다. 지속 시간 미확인은175초 가정으로 예측하며 상세의 짧은 경고는 접어도 보인다. 하루 이상 시간도 `일:시:분:초`를 사용한다.
- 한국어/영어·좁은 폭·재로드·선택/스크롤 유지·게임 테마별 가독성은 관련 변경의 실제 확인 항목이다. 대표 확인과 전수 확인은 구분한다.

## 어종 데이터 확장 상세보기 시안 (2026-11-05 · 구조 미승인)

사용자는 기존 상세에 꼭 필요한 정보만 추가하는 방향을 선택했다. [상세9개 상황 시안](mockups/fish-detail-data.html)은 가상 어종/수치이며 실제 Plugin UI·내장 자료는 변경하지 않았다. 직감 진행도를 상세에서 제외하는 부분은 아래 권고안으로 검토한다.

- **이중·삼중:** `이중 2마리 · 삼중 3마리`처럼 한 정보행으로 묶는다. 비해당·1마리·범위·미확인은 원본 의미대로 구분한다. 최소 어획 획득력과 복수 어획 보장 임계값을 혼동하지 않는다.
- **소장품:** `소장품 납품원 · 소장가치 300 / 450 / 600+` 또는 `단골 NPC A · 소장가치 300 / 450 / 600+` 한 정보행만 추가한다. 숫자는 구간 시작값의 가상 예시다. 도시/마을명·좌표·별도 지도 버튼은 표시하지 않는다. 좁은 폭에서는 자연스럽게 줄바꿈한다.
- **제외:** 구체적 화폐·길·경험치·만족도 보상, 보상표, 소장가치 직접 입력, 기본/보너스 선택, 주간 요청 상태, 납품·보상 전환을 제거했다. 준비·재준비 설명은 접힘 영역까지 제거했다.
- **직감 권고안:** 상세는 선행 어종/필요 마릿수/지속 시간의 고정 조건만 둔다. 현재 `2/3마리` 같은 진행도와 진행 막대는 기존 캐스팅 타이머에서만 본다. 상세에서 준비 조건을 확인하고 낚시 중에는 타이머를 보는 역할 구분이다. 지속 시간 미확인과 예측 가정 경고는 유지한다. 앞 시안의 진행도는 가상 제안이었으며 실제 추가된 기능이 아니다.
- **나머지:** 생미끼는 기존 가로 경로/줄바꿈·관련 어종 비교를 유지한다. 작살은 크기/속도와 숨은 어장의 선행 조건을 짧게 묶는다. 최소 획득력은 한 행이며 내 능력치 비교 영역은 추가하지 않는다.
- [이전 먼바다 메인 메뉴 제안](mockups/ocean-data-view.html)은 별도 미승인 참고안이다. 이번 간소화가 새 메인 메뉴나 전체 상세 재구성의 승인으로 이어지지 않는다.

소장품의 구간 구조는 [공식 납품원 DB](https://na.finalfantasyxiv.com/lodestone/playguide/db/shop/a78fc483b4c/), 단골거래의 보상/주간 구분은 [공식6.3 안내](https://na.finalfantasyxiv.com/lodestone/topics/detail/764840557caa22a8f77550b480aa3c79b2e733d2)에서 확인한 조사 근거다. 구체 보상과 주간 상태는 이번 표시 범위에서 제외하며, 실제 KR/글로벌 어종별 대상·구간 연결은 후속 자료 검사 대상이다.

시안은 일반/생미끼/직감/납품원/단골/작살/먼바다 일반/먼바다 직감/복합9개 케이스를 유지한다. 이전 큰 시안과 입력·진행도 검사의 이력은 Git에 남긴다. 수정본은9개 전환·320/420px 배치의 가로 넘침 없음·밝은/어두운 대표 렌더링·문서 검사·diff 공백 검사를 확인했다. 제품 테스트·빌드·게임 실기는 실행하지 않았다.

## 사진 기반 개선 근거

0.1.32.0 사용자 사진에서 다음 7개 개선을 제안하고 승인 후 0.1.34.0에 반영했다. 기존 UI-UX-SCREENSHOT-REVIEW의 제안은 이 구역으로 통합했다. 상세 결과는 [사진 개선 기록](../archive/ui/CHANGES.md#mvp-01-ui-screenshot-polish)을 따른다.

| 관찰 | 적용 방향 |
|---|---|
| 상세 생미끼 경로가 세로 공간을 많이 차지함 | 가로 경로/줄바꿈, 단계 옆 낚아채기·입질·정보 |
| 직전/현재 날씨의 반복 설명 | 후보 / 후보 → 후보 / 후보 묶음과 툴팁 |
| 수집 선택 상자가 남는 폭 전체를 차지함 | 이름 아래 조작 줄 유지, 내용에 맞춘 폭 |
| 목록의 반복 정보 아이콘이 과도함 | 아이콘/묶음 툴팁, 생략 정보가 있을 때만 추가 표식 |
| 메인 상단이 여러 줄로 분산됨 | 검색·도구 모음·결과/이동을 묶고 폭에 따라 줄바꿈 |
| 목록/상세의 여유 공간 불균형 | 넓은 목록의 조건 묶음 정리, 기존 조절 테이블 유지 |
| 녹색 면적/배경 게임 텍스트가 과도함 | 채도·시간 강조·대비 조정 |

사진의 여러 행에서 종료 00:00:01이 보였다는 사실만으로 타이머 오류를 확정하지 않았다. 이 기록으로 예측 재조사를 자동 재개하지 않는다. 초기 구조·후속 세부 조정은 [화면 검증 색인](../verification/README.md#목록필터화면)에 있다.

## 조회한 UX 근거

2026-10-16~17에 확인한 자료이며 이번 문서 통합에서 재조회한 것은 아니다. 외부 코드/에셋은 도입하지 않았다.

- [NN/g 사용성 원칙](https://www.nngroup.com/articles/ten-usability-heuristics/): 상태 가시성·일관성·불필요한 정보 축소. 도감 안내/공통 행/조작 묶음에 적용했다.
- [Fluent 툴팁](https://fluent2.microsoft.design/components/web/react/core/tooltip/usage): 비필수 보조 정보는 툴팁, 필수 피드백은 화면에 유지한다.
- [W3C 색상 사용](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html): 색상만으로 상태를 전달하지 않는다. ImGui 접근성 인증을 주장하지 않는다.
- [FFXIV Fish Tracker](https://ff14fish.carbuncleplushy.com/): 상시 숨김·출현 정렬·미끼/낚아채기·지도 접근의 비교 사례다. 코드 복제나 예측 공식 변경 근거로 사용하지 않는다.
