# 출현 일정표

갱신: 2026-10-21 · **개발0.5.0.0 r7 / 옵션 제거·단일 대상 전환 버튼 / 인게임 확인 대기 / 미게시**

사용자 사진에서 그래프가 다섯 행 정도에 그치고, 하단 설명·동시 출현·제외 어종 영역이 공간을 차지하는 문제를 확인했다. 사용자가 지정한 새 구성에 따라 시간 확인에 집중하도록 바꿨다.

- [가상 HTML 시안](mockups/spawn-schedule.html): 현재 r7 배치의 가상 예시. 기본 크기 연결 보기 탭(HTML32px 높이·14px 제목/16px 아이콘·기본 굵기·선택 배경/얇은 하단 선)·대상/검색/수집 숨김/물고기의 눈 아이콘을 상단에 묶고, 검색창이 남는 폭을 사용한다. 기간·월 이동은 콘텐츠 바로 위에 둔다. 넓게1100/보통800/좁게580 폭 비교, 시간축/월 달력·날짜 선택·높이 조절/목록 숨김을 조작할 수 있다. 실제 ImGui는 현재 글꼴/배율에 맞춰 비례 크기와 줄 구성을 계산한다. HTML의 고정 px와 완전히 같은 렌더링을 보장하지 않는다. 모든 어종·시각·필터는 가상 자료이며 물고기 표식은 게임 아이콘의 자리 표시다.
- 실제 동작 확인은 [UI 검증 기록](../verification/catalog/UI.md#0500-r7-옵션-제거와-단일-대상-전환-2026-10-21)을 따른다. HTML과 실제 ImGui의 글꼴·배율·높이는 다르며 실제 화면 검증을 대신하지 않는다.

## 1. 화면 구성

메인 → 출현 일정표 맨 위에 **기본 크기의 연결된 시간축 / 월 달력 탭**과 단일 대상 전환 버튼·검색·수집 숨김·물고기의 눈 아이콘을 둔다. 탭 높이는 주변 버튼과 같은 GetFrameHeight이고 제목/아이콘은 현재 기본 글꼴 크기로 한 번만 그린다. 임의 글꼴 확대나 중복 그리기로 굵기를 만들지 않는다. 폭은 제목·아이콘·여백 실측으로 확보한다. 두 탭은 항상 보이며 테두리, 선택 배경·얇은 하단 선으로 구분한다. 반복 설명은 툴팁이다.

검색은 대상·필터 폭을 먼저 확보한 뒤 남는 폭을 사용한다. 넓으면 상단 한 줄이고, 중간 폭은 보기/필터와 대상/검색 두 줄, 작은 폭은 보기·대상/검색·필터 묶음으로 나눈다. 긴 번역·큰 배율에서 물고기의 눈 아이콘이 필터 옆에 들어가지 않으면 다음 줄로 옮긴다. 개별 요소의 임의 FlowNext에 전체 배치를 맡기지 않는다. 기간 또는 월 이동·오늘·목록 숨기기/표시는 상단 아래 콘텐츠 조작 줄에 둔다. 시간축 범위와 현재 시각은 기간 옆에 배치하고 부족하면 범위 줄을 내린다. 게임 배경 때문에 읽기 어렵지 않도록 해당 영역은 현재 테마의 배경색을 진하게 사용한다.

| 공통 조작 | 계약 |
|---|---|
| 대상 전환 | 현재 대상을 표시하는 버튼 하나를 누를 때마다 즐겨찾기/현재 필터 어종 전환. 두 문구 중 긴 폭으로 고정해 전환 시 검색창이 움직이지 않음. 툴팁에 다음 대상 표시 |
| 즐겨찾기 | 전체 즐겨찾기. 메인 검색·지역·등급·수집 조건과 독립 |
| 현재 필터 어종 | 메인 목록의 전체 검색·필터 결과 재사용. 화면에 보이는 행에 제한하지 않음 |
| 검색 | 선택한 대상에 이름·지역·낚시터·기존 ID 검색 추가 적용 |
| 수집한 어종 숨기기 | 기본 ON. 최종 Caught만 제외, Unknown 유지. 현재 필터 모드에도 추가 적용 |
| 물고기의 눈 | 두 보기 상단에 기존 게임 아이콘 버튼으로 노출. 기존 세션 공통 예측 기준만 바꾸며 알림은 일반 기준 유지 |
| 저장 | 대상·기간·수집 숨김은 공통 저장. 검색·뷰 전환·날짜·선택은 세션 상태 |

메인의 수집됨만 조건에 일정표의 수집 숨김을 더하면 결과가 0종일 수 있다. 자동으로 조건을 풀지 않는다. 언어 변경으로 사용자의 검색/날짜/선택을 초기화하지 않는다.

## 2. 시간축

- 기본은 **3시간**, 선택은 1·3·6·12·24시간이다. 초기 개발판의 저장된 6시간은 schema17 이전 시 한 번 3시간으로 옮기고, 다른 기간 선택은 보존한다.
- 그래프가 남은 높이 대부분을 사용한다. 고정 높이의 큰 설명 영역을 예약하지 않는다.
- 행은 **어류 아이콘 + 이름/낚시터·지역, 시간 막대, 지도 핀**이다. 이전 약3.5글자 높이를 약2.15글자 높이와 셀 여백으로 줄였다. 낚시터·지역은 두 번째 줄에 표시하고, 잘리면 툴팁에서 전체를 확인한다. 시간을 왼쪽 열에 추가해 행을 늘리지는 않는다. 머리글은 한 줄이며 세로 스크롤/보이는 행 렌더링을 사용한다.
- 출현 중/출현 예정 텍스트·범례·반복 설명은 표시하지 않는다. 녹색/청색 막대와 현재선으로 위치를 구분하고, 정확한 시간은 마우스 오버로 확인하고 클릭은 기존 어종 상세를 연다.
- 작은 구간은 최소3px 표식과 조금 넓힌 클릭 범위만 제공한다. 표식 범위가 겹치면 툴팁에 모든 해당 회차의 실제 시각을 표시하고, 클릭은 동일 어종의 상세를 연다. 임의의 회차를 고르지 않는다. 가짜 지속 시간을 계산하지 않는다.
- **하단 선택 영역은 표시하지 않는다.** 막대/어종 아이콘·이름을 누르면 기존 어종 상세를 바로 연다. 좁은 폭의 출현 시간 목록도 클릭하면 같은 상세를 연다. 지도 핀은 직접 클릭할 때만 위치를 연다. 남은 시간·ET·직감 설명·동시 출현 스크롤 목록도 표시하지 않는다. 미끼·날씨·직감 가정 등은 기존 어종 상세에서 확인한다.
- 동시 출현 강조는 별도 옵션 없이 항상 사용할 수 있다. 한 막대 구간에 마우스를 올린 동안 다른 어종의 막대 빗금으로 표시하고, 벗어나면 해제한다. 인접 회차가 함께 잡히면 임의의 회차를 강조하지 않는다. 같은 구간에 머무는 동안 교집합을 반복 계산하지 않는다. 대상은 현재 표시 중인 다른 어종이며, 실제 교집합 [시작, 종료)로 계산한다. 이동/준비/어획 성공을 판단하지 않는다.
- 그래프에 표시하지 않는 어종은 아래 **기본 접힘 항목**으로만 남긴다. 사용자가 펼친 경우에만 이름·사유를 확인한다.
- 좁은 폭은 같은 탭의 간결한 시간 목록으로 전환한다. 아이콘·이름·시간·핀을 유지한다.

## 3. 시각과 예측

계산·회차 식별은 UTC, 화면 시각은 PC 현지 시간이다. 머리글 위에는 날짜 범위와 현재 현지 시각을, 막대 툴팁은 실제 시작/종료를 제공한다. 현재선의 머리글 표식은 눈금 글자를 가리지 않도록 아래쪽에만 그린다. 날짜 범위 툴팁은 현재선과 축 시작의 차이를 설명한다. 시간축 시작은 현재 직전30분 경계이며 끝은 계산 시각 + 선택 기간이다. 매초 정렬하지 않고 최대30초·출현 경계에서 갱신한다.

행 순서는 출현 중 종료순 → 예정 첫 시작순 → 이름/ID다. 화면 끝으로 잘린 막대는 화살표, 계산으로 끝을 모르는 경우는 종료 미확인이다. Unknown·상시·지원 밖·기간 내 없음·부분 계산을 구분한다. 일반 예측과 알림의 최대30일 계약은 유지한다.

## 4. 월 달력

- 달 이동과 오늘 버튼으로 한 달을 선택한다. 일요일부터 토요일까지 7열, 해당 달의4~6주를 모두 표시한다.
- **날짜 칸에는 어종별 첫 출현의 ‘시간 - 어종’**을 표시한다. 공간에 맞는 항목만 보여주고 남은 개수는 더 보기로 알린다. 첫 출현 요약이라는 설명은 월 제목의 툴팁에 둔다.
- 달력과 목록 사이의 구분선을 위아래로 드래그해 높이 비율을 조절한다. 기본은 약58% 달력이며, 창 크기/배율에 맞춰 최소 달력·목록 높이를 확보한다. ‘목록 숨기기’를 누르면 달력만 남은 높이를 사용하고, ‘목록 표시’를 누르면 조절한 비율로 돌아온다. 높이 비율과 목록 표시 여부는 이번 UI 인스턴스 동안 유지하며 설정 파일에는 추가 저장하지 않는다.
- **날짜를 누르면 아래에 그날의 모든 출현 회차**를 시간순 목록으로 표시한다. 시간·어류 아이콘/이름·지역·위치 핀·상세 버튼만 둔다. 반복 출현은 별도 행이다.
- 자정을 넘는 구간은 해당하는 날짜마다 포함하고, 날짜별 목록의 시각은 해당 날짜 범위로 잘라 보여준다. 마우스 오버에서는 원래 UTC 구간을 현지 날짜/시각으로 확인한다.
- 시간축과 같은 대상/검색/수집/물고기의 눈을 적용한다. 상시·조건 미확인·먼바다/확인된 작살은 시간 막대가 없는 것처럼 달력에도 회차를 추정해 채우지 않는다.
- 과거 날짜도 현재 내장 조건으로 계산한 **예측**이며 실제 어획 기록이 아니다. 실제 버프·선행 어획 진행도는 관측하지 않는다.

### 달력 계산과 상한

31일과 일광절약시간 전환을 포함하기 위해 달력 전용 EnumerateCalendar 진입점은 최대32일 UTC 범위로 제한한다. 월 시작 UTC를 직감 준비 기준으로 고정하며 공통 시간/날씨 스캔을 쓴다. 시간축/기존 Find의 최대30일을 늘리는 방식이 아니다.

결과는 날짜·어종별 작은 UTC 구간 배열로 보관하고, 날짜 선택 시에만 해당 날짜의 전체 회차 배열을 만든다. 전체 월의 UI 행/표시 문자열 복사본은 만들지 않는다. 월 저장100만 건 또는 어종당4096회 상한이면 부분 계산임을 화면에 표시하며 빈 정상 일정으로 숨기지 않는다. 날짜 경계는 현지 시간대를 통해 UTC로 변환한다.

## 5. 수명과 책임

| 책임 | 구현 |
|---|---|
| Core | 공통 구간 스캔·일반30일/달력32일 제한·직감/물고기의 눈·취소 확인 |
| Framework | 기존 CatalogQuery로 대상 준비, 선택 교집합/선택 날짜의 정렬된 회차 캐시 |
| 계산 작업 | 게임 객체 없는 관리 입력만 받아 취소 가능한 작업 하나에서 계산 |
| 종료 | 탭 이탈·닫기·세션/자료/조건/월 변경 시 취소/결과 폐기. 2초간 미렌더 시 정리 |
| UI | 현재 스냅샷과 보이는 행만 그리기. 지도는 명시적 핀 클릭, 상세는 명시적 클릭 |
| 저장/번역 | schema17, 이전schema16 수용과 새 기본값 이전. TextKey·한영 리소스·고정 ImGui ID |

월 계산은 입력/월/시각 변화 때 갱신하며 날짜를 누를 때마다 월 전체를 다시 계산하지 않는다. 일반 시간축의 주기 갱신은 이전 결과를 유지하되 조건/시계 변경 때 오래된 값을 숨긴다. SDK·의존성·정적 데이터·네이티브 계약은 변경하지 않았다.

## 6. 업데이트 내역과 확인

0.4.0의 새 기능 소개 형식에 맞춰 **새 기능 · 출현 일정표** 제목과 짧은 소개 뒤 대상 전환·시간축·월 달력·지도/상세 동선을 항목별로 설명한다. 개발0.5.0.0 후보의 내장 내역/manifest이며 원격 배포 완료를 의미하지 않는다. 같은 개발 버전을 이미 확인했다면 설정 → 업데이트 내역에서 다시 볼 수 있다.

빌드·리소스·문서 검사와 실제 게임 확인은 구분한다. 테스트는 사용자 명시 요청이 없어 추가/실행하지 않는다. 실제 월 계산 성능·날짜 경계·전체 배율/폭·핀/상세·캐릭터 격리는 새 수정본의 대표 확인 대기다. 초기 사진의 UI 문제 확인을 새 화면/예측 검증 완료로 확대하지 않는다.
