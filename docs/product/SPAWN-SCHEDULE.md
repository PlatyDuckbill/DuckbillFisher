# 출현 일정표

갱신: 2026-10-20 · **개발 0.5.0.0 구현 / 인게임 대표 확인 대기 / 미게시**

> 여러 어종의 출현 구간을 같은 시간축에서 비교하고, 다음에 확인할 목표를 직접 고르는 화면.

사용자가 화면 구성을 승인하고 개발을 요청했다. 추가 요청인 **1시간 보기**, **현재 필터 어종 기준**, **동시 출현 문구**, **접힘 없는 어종·사유 목록**, **작은 구간의 안내 문구 제거**를 반영했다.

- [HTML 시안 03](mockups/spawn-schedule.html): 브라우저에서 독립 실행하는 가상 자료 기반 검토 화면. 어종·지역·시각·조건·현재 필터 결과는 모두 예시다.
- 실제 동작은 아래 계약과 개발 DLL을 기준으로 확인한다. HTML의 세로로 펼친 높이, 글꼴, 가상 시각은 실제 ImGui와 다르다.
- 현재 빌드·실기 범위는 [STATUS](../STATUS.md), [대표 확인 순서](../verification/catalog/UI.md#0500-출현-일정표-2026-10-20)를 따른다.

## 1. 진입과 사용 흐름

메인에 **출현 일정표** 탭을 추가했다. 가로 폭 전체를 시간축에 사용하고, 아래에 보고 있는 일정과 동시 출현 어종, 시간축에 표시하지 않는 어종을 둔다. 어종 상세는 기존 독립 상세 한 개를 재사용한다.

| 순서 | 동작 | 결과 |
|---|---|---|
| 1 | 메인 → 출현 일정표 | 기본 즐겨찾기·6시간·수집한 어종 숨김 |
| 2 | 즐겨찾기 / 현재 필터 어종 선택 | 선택한 범위의 어종으로 계산 |
| 3 | 1·3·6·12·24시간 선택 | 해당 실제 기간의 여러 출현 회차 표시 |
| 4 | 막대를 누름 | 해당 회차의 정확한 시각·남은 시간·ET·동시 출현 어종 표시 |
| 5 | 어종 상세 누름 | 기존 상세에서 미끼·날씨·직감 조건 확인 |

## 3. 대상과 필터

| 항목 | 동작 |
|---|---|
| 즐겨찾기 | 전체 즐겨찾기를 사용. 메인 검색·지역·등급·수집 필터와 독립 |
| 현재 필터 어종 | 메인 어종 목록의 검색·지역·확장팩·현재 지역·등급·시간제·수집·즐겨찾기 등 현재 쿼리를 재사용. 화면에 보이는 행 수로 제한하지 않음 |
| 일정표 검색 | 선택한 대상에 이름·지역·낚시터·기존 ID 검색을 추가 적용 |
| 수집한 어종 숨기기 | 기본 ON. 최종 Caught만 제외하고 Unknown은 남김. 현재 필터 모드에서도 추가 적용 |
| 기간 | 실제 1·3·6·12·24시간. 기본 6시간 |
| 물고기의 눈 | 기존 세션 공통 ON/OFF를 공유. 메인·간이 목록의 탐색 기준도 함께 바뀜 |
| 알림 | 대상 모드·검색·숨김·기간·물고기의 눈 변경은 기존 일반 기준 알림을 바꾸지 않음 |
| 저장 | 대상 모드·기간·수집 숨김은 공통 설정 schema16에 저장. 검색·선택·동시 출현 강조는 세션 상태 |

예를 들어 메인에서 수집됨만 고른 뒤 일정표에서 수집 숨김을 켜면 결과가 0종일 수 있다. 각 조건을 동시에 적용한 결과이며 자동으로 필터를 풀지 않는다. 언어 변경으로 검색·선택·저장 상태를 초기화하지 않는다.

## 4. 시간축과 막대

- 내부 계산·구간 식별은 UTC다. 가로축과 상세 시각은 PC 현지 시간이며 날짜와 UTC 오프셋을 함께 표시한다. ET는 별도 보조 정보다.
- 시작은 현재 직전 30분 경계, 끝은 계산 시각 + 선택 기간이다. 20:30에 6시간이면 20:30 이전부터 진행 중인 구간도 읽을 수 있도록 20:00~다음 날 02:30을 표시한다. 과거 기록 조회 기능은 아니다.
- 동일 어종의 여러 회차를 한 행에 그린다. 진행 중인 구간은 녹색, 예정은 청색, 보고 있는 회차는 테두리, 동시 출현 부분은 빗금이다. 공간이 있으면 막대에 상태명을 쓰고 정확한 시각은 툴팁/선택 요약으로 제공한다.
- 현재 시각은 세로선과 지금 시각으로 표시한다. 주기 갱신은 최대 30초 간격이며 시작/종료 경계에서도 갱신한다. 매초 재정렬하지 않는다.
- 행 순서는 출현 중 종료순 → 예정 첫 시작순 → 이름/ID다. 회차는 어종 ID와 UTC 시작으로 식별하며 종료되면 보고 있던 출현의 종료를 안내한다.
- 화면 밖으로 이어지는 막대는 화살표로 잘림을 알린다. 실제 종료 미확인은 별도 문구로 구분한다.

### 폭이 작은 구간

막대의 실제 길이를 기준으로 그리되 3px 미만이면 세로 표식으로 보이게 한다. **범례·툴팁에 이를 설명하는 별도 문구는 넣지 않는다.** 클릭 범위만 좌우로 조금 넓히며 실제 지속 시간이나 동시 출현 계산에는 영향을 주지 않는다.

인접한 회차의 클릭 범위가 겹치면 해당 후보들의 시각을 목록으로 보여주어 직접 고르게 한다. 12·24시간에서 자세히 확인하기 어려우면 1·3·6시간으로 줄여 볼 수 있다. 자유 확대/축소·드래그 이동·미니맵은 첫 범위 밖이다.

## 5. 보고 있는 일정과 동시 출현

선택 대상은 어종 하나가 아니라 **특정 출현 회차 하나**다. 같은 어종의 다른 막대를 누르면 해당 회차의 시작·종료·남은 시간으로 바뀐다.

- 조작 문구는 **동시 출현 강조**, 요약 제목은 **같은 시간에 출현하는 어종**이다.
- 현재 표시 중인 다른 어종들과 비교한다. 자기 자신의 다른 회차는 제외한다.
- 교집합은 반열린 구간 [시작, 종료)다. A가 20:48에 끝나고 B가 20:48에 시작하면 동시 출현으로 세지 않는다.
- 각 어종의 동시 출현 시각과 길이를 표시한다. 종료 미확인은 표시 범위까지만 비교한다고 안내한다.
- 직감 지속 시간을 175초로 가정한 경우 이름 옆 가정 표식과 보고 있는 일정의 경고를 유지한다. 실제 버프나 선행 어획 진행도를 뜻하지 않는다.
- 일정이 겹친다고 포기하거나, 겹치지 않으면 연속 어획할 수 있다고 판단하지 않는다. 이동·직감 준비·GP·텔레포 시간은 계산하지 않는다.

## 6. 시간축에 표시하지 않는 어종

시간축 아래에 **어종 / 지역 | 표시하지 않는 사유 | 상세** 목록 하나를 접힘 없이 둔다. 그래프에 없다는 사실은 실제로 출현하지 않는다는 뜻과 다르다.

| 상태 | 사유 표시 |
|---|---|
| 기간 내 출현 없음 | 선택한 실제 기간에 출현 구간 없음. 기존 예측에서 확인된 다음 시각이 있으면 함께 표시 |
| 조건 미확인 | 계산 자료/직감 선행 조건/물고기의 눈 지원 부족 등의 이유. 빈 일정이나 상시로 추정하지 않음 |
| 상시 출현 | 현재 예측 기준에서 시간·날씨 제한 없음. 출현 시간 비교용 막대 대신 목록에 안내 |
| 일정표 미지원 | 먼바다·확인된 작살·일반 예측 대상 밖 |
| 일부 계산 미완료 | 어종당 512회 상한 도달 시 명시. 계산한 구간은 표시하되 누락을 숨기지 않음 |

같은 검색·수집 숨김을 적용하며 필터로 제외한 어종은 이 목록에 다시 넣지 않는다. 기간 확대로 구간이 들어오면 시간축으로, 물고기의 눈 기준에서 상시가 되면 이 목록으로 이동한다. 대상/검색 결과 0종과 계산 중·계산 실패를 구분한다. 30일 내 검색 실패도 영구적인 출현 불가로 표현하지 않는다.

## 7. 구현과 수명

| 책임 | 구현 |
|---|---|
| Core | FishingAvailability 공통 구간 스캔을 Find와 Enumerate가 공유. FishingForecast.Enumerate는 대상·직감·물고기의 눈 규칙으로 지정 UTC 범위를 한 번 탐색 |
| 예측 기준 | 구간마다 기준 시각을 앞으로 옮기지 않고 요청의 기준 UTC를 고정. 화면 밖 끝 경계는 기존 최대 30일까지 이어서 확인하고 불명은 null 유지 |
| Plugin | SpawnSchedule이 Framework에서 대상 필터링. 관리 값만 캡처한 취소 가능한 작업 하나로 계산하고 완료 snapshot 게시 |
| 갱신 | 입력 revision 변경·30초 경과·다음 출현 경계·시계 역행/긴 중단에서 새 계획. 다음 경계는 완료 시 캐시 |
| 종료 | 탭 이탈·닫기·캐릭터 전환·재로드·입력 변경에서 이전 작업 취소/결과 폐기. 2초간 그려지지 않아도 작업 정리 |
| 시각 제어 | UTC와 단조 시각은 주입 가능한 TimeProvider 사용. UI는 동일 시계 참조 |
| 선택 | Framework에서 선택 회차의 동시 출현 결과를 캐시. Draw에서 전체 어종 필터링/장기 예측/게임 조회를 하지 않음 |
| 저장 | schema15 등 이전 설정 수용. 새 선택 필드가 잘못되어도 기존 즐겨찾기/수동 상태를 버리지 않고 일정표 기본값으로 복구 |
| 번역 | 안정적인 TextKey와 기본 영어·한국어 리소스. 고정 ImGui ID와 타입 상태 사용 |

SDK·의존성·정적 조건 데이터·네이티브 읽기 계약은 변경하지 않았다. 새 게임 조작·런타임 HTTP·원격 갱신은 없다.

## 8. 범위와 확인

개발 0.5.0.0의 메인 탭·대상 전환·기간·검색/수집 숨김·여러 회차·동시 출현·사유 목록·좁은 폭 목록·독립 상세 연결을 구현했다. 독립 일정표 화면, 달력/특정 날짜 이동, 경로 추천, 즐겨찾기 그룹, 실제 직감 버프는 별도 후속이다.

빌드·리소스 검사와 게임 확인은 구분한다. 사용자 명시 요청이 없어 테스트는 추가/실행하지 않았다. 한영·UI 배율·실제 목록과 시각 일치·대량 대상 성능·절전/시각 변경·다른 캐릭터 격리는 [대표 확인 순서](../verification/catalog/UI.md#0500-출현-일정표-2026-10-20)에 따라 확인한다.

HTML 시안은 문법 검사만 완료했으며 브라우저 렌더링/조작 확인은 대기다. 개발 DLL의 ImGui 화면과 실제 게임 시각도 아직 사용자 대표 확인 전이다. 공개 배포는 수행하지 않았다.
