# 설정 백업과 전용 WAV

설정 화면의 ‘설정 백업’에서 내보내기·가져오기를 제공한다. 공개판과 개발본의 실제 확인 범위는 [STATUS](../STATUS.md), 이번 구현의 검사/실기 절차는 [검증 기록](../verification/configuration/SETTINGS-BACKUP.md)을 따른다.

## 포함 범위와 사용 흐름

- UI 언어·배율·개발자 도구, 목록/간이/일정표 필터, 즐겨찾기와 목록 프리셋, 출현 알림/개별 시간, 타이머 알림/프리셋과 낚시 효과음을 포함한다.
- 캐릭터 식별자·수동 수집·자동 수집 백업, 낚시 기록, 알림 발송/중복 방지 기록과 업데이트 안내 확인 버전은 내보내지 않는다. 복원할 때도 이 정보는 유지한다.
- 기본으로 ‘커스텀 WAV 포함’을 켠다. ZIP 하나에 `settings.json`과 현재 소리 선택이 ‘커스텀 WAV’인 용도의 WAV만 저장한다. ‘없음’/SE를 선택했다면 예전 경로가 남아 있어도 제외하고 내보내는 설정 사본의 해당 경로만 비운다. 알림 기능 자체의 켜짐/꺼짐과 소리 종류 선택은 구분한다. WAV를 하나도 선택하지 않았다면 ZIP에는 JSON만 담긴다.
- 옵션을 끄면 설정과 WAV 경로만 담은 JSON 하나를 저장한다. 다른 PC에서 가져올 때 파일 경로가 없으면 소리를 다시 선택해야 한다.
- 내보내기는 선택한 경로에 새 파일을 만든다. 같은 이름의 기존 백업은 덮어쓰지 않으며 다른 파일명을 사용한다. 포함할 WAV가 없거나 읽기/검증에 실패하면 불완전한 ZIP을 내보내지 않는다.
- 가져오기는 먼저 전체 파일을 검증하고 백업 UTC·즐겨찾기/목록 프리셋/WAV 수를 표시한다. ‘설정 복원’을 눌러야 공통 설정과 포함된 음원을 교체한다. 취소는 적용하지 않는다.

```text
DuckbillFisher-backup-YYYYMMDD-HHmmss.zip
├─ settings.json
└─ sounds/
   ├─ spawn-alert.wav
   ├─ bite.wav
   ├─ big-fish.wav
   └─ legendary-fish.wav
```

선택한 용도의 파일만 포함하며 파일명은 UI 언어와 무관한 영어로 고정한다.

## WAV의 영구 복사본

- 새 WAV를 지정하면 `GetPluginConfigDirectory()/sounds/` 아래에 위 네 용도별 고정 이름으로 복사한다. 같은 용도를 재지정하면 해당 파일을 원자 교체하며 이전 음원을 계속 쌓지 않는다. 사용자 원본은 수정/삭제하지 않는다.
- 설정에는 성공한 전용 복사본의 경로를 저장한다. 같은 경로의 내용을 교체한 경우에도 재생기를 다시 로드한다. 설정 저장에 실패하면 이전 전용 파일로 되돌린다.
- 현재 ‘커스텀 WAV’인 용도의 기존 외부 경로는 시작/세션별 해당 경로를 한 번 읽어 전용 파일로 이전한다. ‘없음’/SE의 예전 경로는 자동 이전하지 않는다. 원본이 없거나 저장할 수 없으면 기존 경로를 보존하고 오류를 표시한다. 실제 설정을 자동으로 빈 경로나 ‘없음’으로 바꾸지 않는다.
- 원본을 옮기거나 삭제해도 이미 저장한 영구 복사본은 유지된다. 원본 수정 사항을 반영하려면 파일을 다시 선택한다. ‘재불러오기’는 현재 전용 복사본을 읽는다.
- 기존 재생용 임시 복사본/MCI alias는 그대로 유지한다. 영구 파일과 임시 재생 파일은 수명이 다르며 전용 영구 파일을 재생기가 잠그지 않는다. WAV 10MB/30초 제한과 Windows waveaudio의 인코딩 지원 범위는 유지한다.

## 형식과 호환성 계약

- 최초 백업은 `Product=DuckbillFisher`, `FormatVersion=1`, `SettingsVersion=21`, `CreatedUtc`, `Settings`, `SoundHashes`를 사용한다. 앱 배포 버전과 백업/설정 버전은 분리한다. Dalamud 원본 설정 JSON을 직접 가져오는 기능은 아니다.
- ZIP의 WAV 경로는 `sounds/<용도별 이름>.wav`이며 JSON에는 음원별 SHA-256을 기록한다. 복원은 정확한 용도별 엔트리만 읽고 전용 경로를 직접 구성한다. 임의 엔트리 경로로 파일을 추출하지 않는다.
- 현재 허용 크기는 JSON 4MB, ZIP 64MB, WAV 각각 10MB이며 ZIP 엔트리는 JSON 1개와 WAV 최대4개다. 중복/예상 밖 엔트리·누락 음원·해시 불일치·잘못된 값·미지원 버전은 설정 적용 전에 거절한다.
- 이전 백업은 해당 설정 버전을 보존해 읽고, 일반 설정 로딩과 공유하는 정규화/이전 절차를 거쳐 현재 설정으로 바꾼다. 형식1의 기존 필수 필드는 유지하고 **나중에 추가하는 필드는 선택 필드와 도입 당시 기본값**으로 둔다. 의미/범위가 바뀌면 버전별 변환을 추가하며 설정21 이후의 이전 경로를 삭제하지 않는다.
- 설정schema22의 캐스팅 전용 채널은 Timer.AlertChannelId에 저장한다.21 이하 백업에 이 필드가 없으면 당시 출현 알림/공통 채널을 이어받고,22 이후 백업은 독립 채널을 그대로 복원한다. 백업 FormatVersion은1을 유지한다.
- 호환 가능한 항목 추가만으로 `FormatVersion=1`을 올리지 않는다. 구조를 바꾸어 새 형식이 필요하면 기존 형식 판독기를 유지해 이전 백업을 현재 관리 값으로 변환한다. 미래 백업을 구버전 플러그인에서 무리하게 읽지는 않는다.
- 파일 읽기/쓰기/압축은 관리 작업자에서 수행한다. 복원 WAV를 준비한 뒤 Framework에서 현재 캐릭터 세션을 확인하고 기존 설정 저장 경로로 적용한다. 세션 변경/종료는 오래된 요청을 취소한다. 실패 시 설정은 이전 성공본을 유지하고 교체한 WAV도 되돌리며, 되돌리기 자체가 실패하면 별도 안내를 표시한다.

아직 미래 버전/과거 백업 조합의 실기 확인을 완료한 것은 아니다. 새 설정을 추가할 때 이 계약과 이전 백업의 재확인 범위를 함께 유지한다.
