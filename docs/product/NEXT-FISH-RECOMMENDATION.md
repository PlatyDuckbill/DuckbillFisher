# 터주작 추천 — 출현 일정과 준비 조건

2026-10-26 공개0.6.0.0. 목적은 ‘지금 터주작이나 해볼까?’에 답할 여러 후보와 판단 자료를 제공하는 것이다. 사용자가 조건·일정 중심의 간소화를 선택했다. 준비 시간·첫 투척 예상·종합 점수·보관 경로/최적 수량 계산과 롱카 전용 예외는 제거했다. 현재 도전 목표·이미 확보한 미끼·직감 진행도·개인 GP는 읽지 않는다. [검사와 대표 확인 대기](../verification/forecast/RECOMMENDATIONS.md).

## 0.6.0.0 구현 계약

| 탭 | 포함 기준 | 정렬 |
|---|---|---|
| 지금 노릴 어종 | 현재 출현 중이거나 지금부터30분 이내 출현할 후보 | 잔여10분 초과 출현 중 → 가까운 예정 → 상시 → 잔여10분 이하. 임박 후보끼리는 잔여가 긴 순 |
| 밑작업 | 선택한 조회 기간 안 생미끼·직감 필요 후보 중 대상/준비 어종이 모두 상시인 경우 제외 | 지금 탭과 같은 일정 순서. 짧은 생미끼1단계도 포함 |

- 일반 필드의 미수집 터주·터주왕, 기본3시간(1/3/6/12/24), 물고기의 눈OFF다. 현재 출현도 포함한다. 수집 미확인 포함/즐겨찾기만/터주왕만 필터를 유지한다. 기간은 조회 범위이며 플레이 시간 제한이 아니다. 밑작업은 사전 준비를 완료할 수 있다는 판정이 아니다.
- 밑작업은 대상 자체가 상시여도 시간·날씨 제한이 있는 준비 어종이 있으면 유지한다. 조건 Unknown은 상시로 간주해 제외하지 않는다. 지금 탭과 희귀 탭의 포함 기준은 이 상시 제외 규칙으로 바꾸지 않는다.
- 임박 판정은 표시 중인 대상/대표 준비 어종의 실제 구간 종료까지10분 이하이고 아직 종료 전인 경우다. 종료 미확인을 임박으로 추정하지 않는다. 지금/밑작업의 순위는 조회·갱신 시점에 정하고 읽는 동안 유지한다. 잔여는 계속 흘러 임박 시 황금색으로 표시한다. 희귀 탭의 빈도 정렬은 유지한다.
- 대상에 자체 시간·날씨 제한이 있으면 그 대상의 실제 구간·다음 구간을 사용한다. 직감 필요 대상도 개인의 직감 충족을 ‘출현 중’으로 확정하지 않는다. 목록 직감 배지와 준비 조건을 함께 확인한다.
- 대상 자체가 상시면 준비 어종의 실제 조건을 표시한다. 현재 탭의 범위(지금 탭30분, 나머지는 선택 기간) 안에 기회가 있는 제한 어종 중 출현 횟수가 적은 어종을 대표로 삼고 이름/직감 마릿수를 연결한다. 직감과 생미끼 준비를 문구로 구분한다. 여러 어종의 구간을 합치거나 직감 지속 시간만큼 가상 출현을 늘리지 않는다. 제한된 준비 어종이 모두 기간 밖이면 제외 목록에서 접근한다.
- 생미끼 경로는 내장 BaitSteps/BaitPath를 공통 표시하고 직감 요구는 이름/요구 마릿수로 제공한다. 각 어종의 자체 시간·날씨 구간을 조회하며 준비 순서·어획 시간·동시 완성·성공 여부를 판정하지 않는다. 선행 어종의 직감/추가 생미끼 조건은 기존 어종 상세에서 확인한다. 미끼 목록의‘1마리’는 최적 보관량으로 쓰지 않는다.
- 대상 자체 빈도와 다음 출현을 우선한다. 자체 시간·날씨 제한이 없을 때만 대표 준비 어종의 빈도를 이름과 함께 참고값으로 표시한다.30일간 이어지는 시간·날씨 구간을1회로 세며 실제 직감 발동 횟수·복합 준비 기회·낚일 확률이 아니다. 상시는 희귀 정렬에서 제외한다.
- 빈도 기간은 조회일의UTC0시부터30일이다. 캐시는 자료 인스턴스/UTC 기준일별로 보관한다. 전날부터 이어진 구간과 늦은 시각의24시간 조회를 위해 계산 여유를 두되 횟수는 표시한30일만 센다. 구간 종료가 계산 범위 밖이면 종료 미확인으로 표시하며 출현 중 후보를 버리지 않는다.
- 알려진 출현은 준비 시간이 부족할 것이라는 추정으로 제외하지 않는다. 대상 조건 자체가 Unknown이면 확인 필요에 두고, 대상 일정은 알지만 준비 어종 조건이 Unknown이면 대상은 유지하며 부족한 정보를 구분한다. 직감 지속 시간 누락만으로 어종을 숨기지 않는다.
- 첫 진입/필터 변경/‘갱신’ 클릭 때 조회하고 읽는 동안 목록과 순위를 유지한다. 세 탭 전환은 재조회하지 않는다. 남은 시간만 흐르며1분 경과·자료/수집 변경·시각 점프는 갱신 안내를 표시한다. 캐릭터 전환·취소·요청 세대로 오래된 결과를 폐기하고 Draw에서 장기 조회/파일 읽기를 하지 않는다.

## 화면과 동선

- 기존 전체 폭·세 열/세 줄 목록과 상단 왼쪽 세 탭/오른쪽 갱신·기간·필터·도움말을 유지한다. 추천 하위 탭은 기본 높이를 사용하고, 선택 탭의 붉은 배경·밝은 밑줄과 비선택 탭의 어두운 배경으로 구분한다. 조회 도구와 같은 높이의 한 줄을 유지한다. 아이콘/등급·지도 핀/위치·미끼·직감 배지·출현 구간·다음 회차·횟수·짧은 조건 설명을 보여준다. 날씨·ET는 기존 상세에서 확인한다.
- 행/상세 보기는 기존 어종 상세, 추천 근거는 같은 위치의 팝업이다. 팝업에는 실제 출현·다음 출현, 생미끼/직감별 필요 어종과 일정, 간단한 이유를 표시한다. 접힌‘조회 정보’에는 빈도 기준/분석 날짜만 둔다.
- 준비 예상·첫 투척·점수/계산식·보관 전략 선택은 표시하지 않는다. 롱카만 별도로 안내하지 않으며 생미끼 경로를 공통으로 제공한다. 보관 가능한 어종·수량·기술 순서를 자동으로 권하는 기능은 이번 버전 범위에서 제외했다. 2026-11-06 TODO 정리에서도 준비/보관/점수 최적화는 현재 계획에서 제외했으며 구조의 확장 지점만으로 자동 재개하지 않는다.
- 이름·미끼 경로·조건이 길면 잘림 툴팁을 사용하고, 하단 조회 시각은 고정 한 줄을 유지한다. 지도/버튼 클릭은 행 클릭과 분리하며 팝업은 조회 세대/캐릭터 변경 때 폐기한다. 자동 게임 조작·미끼 변경·알림 자동 등록은 없다.

- 사용자가 추천 테스트 교체/실행을 명시 허용했다. 이전 준비 시뮬레이션17개를 새 일정/선별/Unknown/취소 기준으로 교체했다. 최신 결과·게임 대표 확인은 검증 문서를 따른다. 실제 게임 화면/추천 활용·성능·새 알림 실기는 확인 대기다.
