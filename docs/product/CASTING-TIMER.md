# 캐스팅 타이머와 낚시 기록

현재 동작과 유지보수 진입점이다. 최초 API 후보·구조·소스 대조는 [초기 조사 원문](../archive/design/CASTING-TIMER-INVESTIGATION.md)에 보존한다. 최초 조사 때의 ‘미확인/아직 미구현’을 현재 구현 상태와 혼동하지 않는다.

## 사용자 동작

- 상단은 낚시터 이름·물고기 아이콘과 어종 보기 문구·스톱워치 설정 버튼을 한 줄에 둔다. 두 버튼의 폭을 먼저 확보하고 긴 낚시터 이름은 잘라 표시하며 툴팁으로 전체 이름을 제공한다. 설정 아이콘의 툴팁은 타이머 설정이며 낚시터 미확인으로 어종 보기가 비활성이어도 설정은 열 수 있다.
- 타이머의 설정 버튼은 별도 화면을 연다. +/−로 알림을 최대32개 추가/삭제하고 각 이름(선택)·1~3600초·사용 여부·기본SE1~16/소리 없음을 지정한다. 기본은 빈 알림 목록이며 새 알림은10초·SE1이다. 이름 있는 프리셋은 최대20개, 같은 이름 저장은 교체이며 불러오면 현재 알림 목록을 교체한다. 설정·프리셋은 공통 로컬 저장이다. 개별 WAV는 제공하지 않는다.
- 시전 시작을 알고 있는 현재 시전에서 설정 시간을 넘을 때 로컬 채팅과 선택SE를 한 번 출력한다. 채팅 채널은 기존 공통 출력 설정을 따른다. 같은 갱신의 알림은 채팅1건으로 합치고 같은SE는 한 번만 요청한다. 타이머를 닫아도 동작하며 낚아채기·중단·전환/재로드·5초 넘은 관찰 공백의 지난 알림은 다시 울리지 않는다. 도중에 켜거나 프리셋을 불러와도 지난 시간은 소급하지 않으며 이미 출력한 알림ID는 같은 시전에서 재출력하지 않는다.
- 기존 시전 경과 바로 아래에 거대한 루어/소박한 루어의 아이콘·기술명·중첩·사용 후 경과를 표시한다. 실제 입력 순간이 아니라 공개 StatusList에서 같은 시전의 새 중첩을 관찰한 시각(200ms 주기)부터 센다. 중첩이 늘면 다시 세며 효과 제거·낚아채기·새 시전/관찰 실패/닫기/전환에는 과거 값을 버린다. 이미 적용된 효과로 다시 열었거나 시작을 보지 못했다면 경과는 미확인이다. 기존 시전 타이머·인내/직감은 함께 유지한다. [KR 근거·실기 대기](../verification/fishing/TIMER-HISTORY.md#복수-시전-알림과-루어-경과-개발본-2026-10-23).
- 별도 타이머에서 현재 낚시터·현재 미끼·시전 ET·시전 후 단조 경과·낚시 시작부터의 경과를 본다. 지역 이름만으로 정확한 낚시터를 만들지 않는다.
- 시전 ET 아래에 인내·직감의 아이콘과 실제 남은 `분:초`를 표시한다. 인내1·2는 공통 월척 확률 증가 상태850, 직감은 어부의 직감568을 관찰하며 기술 종류/예측 지속 시간을 추측하지 않는다. 효과 없음은 미적용, 읽기 불가/1초 넘은 표본은 미확인이다. 현재 효과는 최근 기록과 별개이며 재로드/캐릭터 전환/닫기 때 폐기한다. [계약·대표 확인/한계](../verification/fishing/TIMER-HISTORY.md#타이머-인내직감-남은-시간-2026-10-22).
- 낚아채기 관찰 시 대표 경과를 멈추고 결과 수신까지의 시간은 별도로 기록한다. 입력 순간을 직접 후킹한 타이머라고 표현하지 않는다.
- 낚시터 이름 옆 ‘어종 보기’는 같은 버튼으로 독립 목록을 열고 닫는 토글이며 기존 목록 행을 재사용한다. 수집 버튼은 전체↔수집 숨김 두 상태이며 메인 일반 필터와 독립이다. 수집 상태는 수집됨=녹색·미수집=붉은색·미확인=회색 배경/테두리 배지와 문구로 표시한다. 이름을 식별하지 못하면 버튼을 비활성화하고 안내 툴팁을 제공한다.
- 낚시 종료 후 마지막 낚시터 보기는 유지하지만 새 Phase1 시전에는 이전 위치를 지운다. 본인1110의 PlaceName950은 ‘미지의 낚시터’, 시전했으나 이름이 없으면 ‘낚시터 확인 중’이다. 본인 시전 로그의 Territory+PlaceName이 유일하게 대응하거나, 같은 시전의 검증한 본인 어획3512와 발견/등록1115·1130·3513이2초 안에 짝지어지고 결과 단계2/4와 유일한 매핑을 만족하면 새 이름/목록을 반영한다. 출처 없는 발견 메시지 하나나 어획 어종/지역만으로 낚시터를 추측하지 않는다. 새 발견 연결의 실기 확인은 [기록](../verification/fishing/TIMER-HISTORY.md#03110-미지의-낚시터와-이전-위치-분리-2026-10-20)에서 별도로 관리한다.
- 아래 최근 기록에는 현재 낚시의 시전이 쌓인다. 중단 후에는 최근 낚시임을 표시하고 지역을 이동해도5분간 유지한다. 단조 시계 기준5분이 지나거나 새 낚시를 시작하면 교체/비우며 로그아웃·캐릭터 전환·재로드·해당 기록 삭제는 즉시 비운다. 종료된 경과는 멈추고 당시 미끼/낚시터를 표시한다. 최근 표시와 현재 네이티브 표본을 섞지 않는다. 메인 저장 기록은 미리 보기 만료로 삭제하지 않는다.
- 메인 기록은 지역·낚시터/날짜·시작/총 낚시 시간/시전·성공 횟수의 요약 목록이다. 클릭하면 같은 탭에서 상세를 보고 목록으로 돌아온다. 목록과 상세 표는 열 너비를 조절하며 상세에는 어종·미끼 아이콘과 결과 수신까지의 시간을 표시한다. 좁은 상세는 기존 간략 행을 사용한다. 묶음/전체 삭제는 확인 후 수행한다.

## 기록과 실패 계약

- 시전 당시 미끼 Item·UTC·ET를 복사한다. 이후 장착 미끼 변경이나 보관 생미끼 소모로 과거 기록을 바꾸지 않는다.
- 발견/본인 어획의 기존2초·같은 시전·유일 지역/이름 계약이 충족되면 확인된 성공 시전 ID의 비어 있는 SpotId와 해당 묶음 위치를 함께 채워 저장한다. 이미 종료된 성공도 갱신한다. 알려진 위치를 덮어쓰거나 과거의 다른 미확인 시전/저장 기록 전체를 추정 보정하지 않는다.
- 총 낚시 시간은 첫 관측 시전부터 낚시 종료까지이며 시전 사이 대기를 포함한다. 진행 중과 새 종료 기록은 단조 시계로 계산하고 종료 값은 summary.DurationSeconds로 저장한다. 기존 종료 기록은 저장된 첫 시전/시작과 종료 UTC가 유효할 때 차이를 표시하고 근거가 없으면 미확인이다.
- 검증된 본인1121/미끼 플래그로 확정한 생미끼 Item이 같은 묶음의 직전 성공 어획과 일치하면 MoochSourceId를 저장한다. 최신순 목록의 생미끼 시전 행과 바로 아래 원본 어획 행을 왼쪽 세로선·화살표로 잇고, 연속 생미끼도 이어 표시한다. 미끼 문구는 짧게 유지하고 연결 설명은 행 툴팁에 둔다. 보관 생미끼는 별도 종류로 표시하며 직전 어획으로 연결하지 않는다. 과거 연결 정보가 없는 행을 마지막 어종으로 추측하지 않는다.
- 새1110 없이 이어지는 생미끼는 같은 연속 묶음·지역의 직전 성공 어획에 확인된 위치가 있고 위 생미끼 연결이 확정될 때만 그 위치를 타이머/어종 목록·새 시전 기록에 이어받는다. 단순 생미끼 플래그나 어종 이름만으로 위치를 채우지 않는다. 새1110(미지/식별 불가 포함)이 있으면 그 정보를 우선하고, 낚시 종료·이동·관찰 공백·읽기 실패에는 이어받기 후보를 폐기한다.
- 성공·명시적 실패·취소·중단·미확인은 구분한다. 미확인 결과를 실패로 확정하지 않으며 결과 어종이 없으면 미끼 아이콘을 결과 아이콘으로 대신 쓰지 않는다.
- 캐릭터별 100묶음, 묶음별 최근 2,000시전을 보관한다. 총 횟수와 저장 행 수를 구분하고 진행 중 묶음을 개수 정리에서 보호한다.
- 저장 schema 2, 묶음별 원자 파일·요약/선택 상세 읽기·이전 형식 원본 보존 가져오기다. DurationSeconds/MoochSourceId는 기본null의 선택 필드이며 기존 파일을 일괄 마이그레이션하지 않는다. 재로드/삭제 재시도/캐릭터 전환에서 오래된 요청이 다른 기록에 적용되지 않게 한다.
- 수첩 등록 이벤트와 어획 기록은 별개다. 기록 관찰로 수집/즐겨찾기 해제 정책을 변경하지 않는다.

## 확인 범위와 남은 일

- 일반 생미끼·명시적 실패·빈 결과 아이콘, 보관 생미끼 첫 칸, 저장 복원/최신순/삭제 후 재등장 방지의 사용자 대표 확인이 있다. 최신 배포 확인은 [STATUS](../STATUS.md)를 따른다.
- 모든 보관 칸·다른 캐릭터·장애/절전·보관 상한·언어/폭 조합까지 확인한 것은 아니다.
- 복수 어획·수량·추가 결과 유형은 사용자 후속 범위다. 필요한 KR 표본을 정하기 전 성공/실패/수량을 추정해 추가하지 않는다.
