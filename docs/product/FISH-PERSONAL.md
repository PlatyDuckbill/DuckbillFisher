# 어종별 개인 기록

어종 상세의 이름/상태 아래 ‘나의 기록’ 펼침 영역에서 메모·수동 도전 횟수·캐스팅 타이머 프리셋 연결을 관리한다. 메인·별도 상세·비교 상세·즐겨찾기 상세가 같은 기능을 사용한다. 기본 접힘 제목에는 도전 횟수와 메모/미저장 여부를 표시한다. [검수 순서](../verification/configuration/FISH-PERSONAL.md).

## 저장과 메모

- 어종별로 캐릭터 공통 저장한다. 수집 상태·실제 시전 기록과 독립인 사용자 입력이며 캐릭터가 없어도 공통 설정을 편집할 수 있는 상태라면 사용할 수 있다.
- 메모는 최대1,000자, 줄바꿈·탭을 허용한다. 입력 후 ‘메모 저장’을 눌러야 영구 저장한다. 빈 메모를 저장하면 메모만 지우며 횟수와 프리셋 연결은 보존한다.
- 다른 어종을 보거나 UI 언어를 바꿔도 작성 중인 초안을 유지한다. 같은 어종을 여러 상세에서 열면 같은 초안을 사용한다. 초안은 최대64개이며 모두 미저장인 경우 새 초안 편집을 막고 안내한다. 깨끗한 초안만 먼저 교체한다.
- ‘되돌리기’는 현재 저장된 메모를 다시 불러온다. 저장된 원문이 다른 요청으로 바뀌었다면 낡은 초안으로 덮어쓰지 않고 충돌 안내를 표시한다. 저장 실패는 기존 성공본과 초안을 유지한다.
- 미저장 초안은 백업에 포함하지 않는다. 캐릭터 세션 변경·설정 백업 복원·플러그인 종료/재로드 때 초안은 초기화되며 저장된 메모는 설정을 따른다.

## 수동 도전 횟수

- `− / 숫자 입력 / +`로0~1,000,000회를 직접 조절한다. 증감은1회 단위이며0 미만/상한 초과로 넘지 않는다. 숫자 변경과 증감은 기존 Framework 설정 큐에서 저장한다.
- 무엇을 도전1회로 셀지는 사용자가 정한다. 시전·입질·어획·출현 회차를 관찰해서 자동으로 더하지 않는다. 실제 실패 어종이나 어획 성공률의 근거로 사용하지 않는다.
- 횟수를0으로 바꾸어도 메모와 프리셋 연결은 유지한다. 모든 항목이 비었을 때만 해당 어종의 빈 저장 항목을 제거한다.

## 타이머 프리셋 연결

- 저장된 캐스팅 알림 프리셋 하나를 선택해 연결한다. ‘연결 없음’은 연결만 해제하며 현재 타이머 설정은 바꾸지 않는다.
- ‘타이머에 적용’을 누를 때 연결된 프리셋의 **현재 알림 목록**을 불러온다. 상세를 보거나 어종을 선택하는 동작만으로는 적용하지 않는다.
- 적용은 현재 캐스팅 알림 목록만 교체한다. 캐스팅 채팅 채널·입질/터주/터주왕 효과음·다른 프리셋과 연결 정보는 보존한다. 불러온 설정은 이후 다른 설정/프리셋을 적용할 때까지 유지한다.
- 같은 이름으로 프리셋을 덮어쓰면 연결은 유지되고 다음 적용 때 새 내용을 사용한다. 프리셋 삭제 시 해당 연결만 해제하고 메모/횟수는 보존한다. 존재하지 않는 연결은 로딩/복원에서도 해제한다.
- ‘프리셋 관리’는 기존 타이머 설정의 캐스팅 알림 탭을 열고 상단 프리셋 영역으로 이동한다. 설정/적용만 제공하며 게임 시전·키 입력·미끼 변경은 하지 않는다.
- 기존 시전별 알림ID·단조 시간 경계/소급 방지 계약을 사용한다. 프리셋을 적용했다고 지난 알림이나 이미 출력한 같은ID의 알림을 다시 출력하지 않는다.

## 설정·백업 계약

- 설정schema23의 `PersonalRecords`는 FishParameter ID를 키로 메모·횟수·연결 프리셋ID를 저장한다. 최대4,096종이며 게임 어획 Item ID와 혼용하지 않는다. 메모/횟수 편집만으로 목록/예측의 CatalogRevision은 올리지 않는다.
- JSON·ZIP 백업 모두 저장된 세 항목과 타이머 프리셋을 함께 포함한다. 미리 보기에 개인 기록이 있는 어종 수를 표시한다. [백업 범위와 제한](SETTINGS-BACKUP.md).
- 백업 FormatVersion은1을 유지하고 PersonalRecords는 선택 필드로 추가했다. schema21/22 백업은 빈 기록으로 읽는다. 이 백업을 복원하면 현재 개인 기록도 비워지므로 기존 기록이 있을 때 별도 경고를 표시한다.23 백업은 메모·횟수·연결을 함께 복원한다.
- 기존 설정에 필드가 없으면 빈 기록으로 시작한다. 명시된 잘못된 메모/횟수·0 ID·개수 초과는 유효한 데이터로 취급하거나 잘라 덮어쓰지 않는다. 일반 로딩은 원본을 보존하고 백업은 적용 전에 거절한다.
- 이 기능은 수동 입력 정보다. 수집 관찰·낚시 기록을 삭제하거나 추측으로 보완하지 않으며 알림 예약·네이티브 지원 범위도 확대하지 않는다.
