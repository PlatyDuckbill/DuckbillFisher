# 남은 작업과 우선순위

갱신: 2026-11-06. 기존 낚시 도구의 완성도를 우선한다. 새 기능 후보·완료 기능·검증 이력을 섞지 않으며 **현재 TODO는 아래4개만** 유지한다. 구현된 기능은 [PRODUCT](PRODUCT.md), 현재 대표 확인과 다음 한 작업은 [STATUS](../STATUS.md), 자료의 출처/부족 범위는 [DATA-SOURCES](../development/DATA-SOURCES.md)를 따른다.

## 다음 확인과 후속 후보

| 순서 | 남길 작업 | 완료 기준/경계 |
|---|---|---|
| 1 | 최근 개발본 대표 실기와 발견한 오류 수정 | 내부 탭·최소 획득력·납품 대상/구간·일반/먼바다 수량, 먼바다 Beta와0.8.0.0 직감/회차 기록의 핵심 동선을 확인한다. 확인되지 않은 이전 범위를 완료로 바꾸지 않는다. 세부 확인 항목은 STATUS와 해당 검증 기록이 담당한다 |
| 2 | UI 마감 | 기존 디자인/그라파이트의 메인·상세·타이머·필터/프리셋에서 읽기·클릭 구분·정렬·줄바꿈을 마감한다. 좁은 폭/확대/한영의 대표 조합과 나머지 테마의 기본 표시를 확인한다. 새로운 전면 개편/배치 시안은 추가하지 않는다 |
| 3 | 필요한 어종부터 자료 보완 | 조사·반영 완료: 핵심11종 중 직감8종·요에콰 시간/날씨·낚아채기, 선행 수량5종을 보완했다. 근거 부족2종와 기존 최소 획득력 미확인은 유지한다. 전수 완성·획득력별 보장 수량은 범위 밖이다. [근거](../development/DATA-SOURCES.md#필요한-어종-보완과-먼바다-조건-2026-11-06) |

## 이번 정리에서 TODO에서 제외한 항목

나머지는 재지시 때 별도로 판단하며, 목록에 남아 있다는 이유로 자동 착수하지 않는다.

| 제외 항목 | 이유 |
|---|---|
| 추천의 준비 시간·보관 계획·점수 최적화 | 개인 준비 상태·보관 적격성·순서와 가정을 추가해야 한다. 현재의 일정/조건 중심 추천을 유지한다 |
| 먼바다 목표 어종/업적 공략·점수 최적화 | 현재 Beta의 일정/항로·기본 미끼 안내보다 범위가 훨씬 크다. 조건으로 후보를 좁히는 작업까지만 남긴다 |
| 작살 전용 상세와 특수 납품 확장 | 별도 데이터/화면·조건 체계를 요구한다. 이번 일반 낚시 중심 범위에서 제외한다. 기존 자료의 미확인 자체는 지우지 않는다 |
| 획득력별 이중/삼중 보장 수량과 모든 어종 자료 전수 완성 | 신뢰할 수 있는 전수 원본이 없어 끝이 불명확하다. 확인된 수량/범위·최소 획득력을 표시하고 필요한 어종부터 보완한다 |
| 새 메뉴/타일 등 추가 전면 디자인과 자동 준비/재준비 안내 | 현재 화면의 사용성을 마감하는 데 집중한다. 합의해 제외한 복잡한 설명/입력/보상표도 추가하지 않는다 |
| 완료 기능·종료된 조사·예전 버전별 재업데이트 확인 | 직감 버프/진행도·일정표·미끼 준비·수집·추천·상세 데이터 연결은 구현 범위다. 종료된 외부 도구 비교와 예전 배포 확인은 기능 TODO에서 빼고 기존 기록에 보존한다 |

## 명시적 보류

- **입질 초 통계:** 사용자 보류를 유지한다. 현재 TODO에서 제외하며 재지시 전 조사/구현하지 않는다.
- **공식 저장소 등록:** 최종 채널에 대한 기존 결정과 후순위 상태를 유지한다. 지금 구현할 TODO가 아니며 재개 시 [전용 계획](GLOBAL-AND-OFFICIAL-REPO.md)을 따른다. KR·글로벌 지원 유지보수는 계속한다.

## 검증 기록과의 관계

- 이미 구현됐다는 사실과 실제 확인 완료는 별개다. 과거 미확인을 삭제하거나 완료로 바꾸지 않는다.
- 예전 버전·친구 PC·다른 캐릭터·전수 조합의 미확인은 [검증 색인](../verification/README.md)과 관련 기록의 한계로 보존한다. 모든 옛 확인을 매번 새 작업 목록으로 되살리지 않는다.
- 재현되는 오류·저장 손실/상태 오판정·새 게임 패치의 계약 실패는 기능 후보와 별개인 유지보수 대상이다. 현재 문제의 재현 근거부터 확인한다.
- 예전 제안의 채택/제외 이력은 [터주작 제안 정리](TROPHY-FISHING-PROPOSALS.md)에 두며 현재 TODO는 이 문서에서만 관리한다.
