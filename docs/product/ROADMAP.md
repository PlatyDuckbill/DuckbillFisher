# 남은 작업과 우선순위

현재 관심은 **터주작**이다. 다음 표는 구현 상태와 후보를 구분하며, 기록된 후보 자체가 착수 지시는 아니다. 실제 대표 확인/미확인 범위는 [STATUS](../STATUS.md)에만 갱신한다.

## 제공 중인 범위

| 단계 | 제공 범위 | 현재 한계/근거 |
|---|---|---|
| ENV-01~03 | KR 환경 확인·공개 API/네이티브 관찰 | 검증한 게임/배포판 조합만 허용. [호환성](../verification/native/NATIVE-RUNTIME-DAL4KR.md) |
| MVP-01 | 목록·상세·지도·필터·프리셋·간이 목록 | 전 어종/모든 폭·언어 조합의 전수 확인은 아님. [제품 계약](PRODUCT.md) |
| MVP-02 | 타이머·낚시터 목록·기록 관리·일반/생미끼 관찰 | 검증한 로그/시전 전이만 연결. [설계](CASTING-TIMER.md) |

## 다음 확인과 후속 후보

- 어종별 개인 메모·수동 도전 횟수·타이머 프리셋 연결과 JSON/ZIP 백업은 개발본에 구현했다. [검수](../verification/configuration/FISH-PERSONAL.md) 후 버전 업데이트·업데이트 노트·배포를 진행한다. 자동 시전/어획 통계나 보류한 입질 초 통계를 구현한 것은 아니다.

- 후보의 목적/기존 기능과의 차이는 [터주작 제안](TROPHY-FISHING-PROPOSALS.md)을 따른다.
- 미확인 데이터의 전체 이름·ID·이유는 [잔여 보고서](../verification/data/reports/fishing-data-2026-10-17/remaining.md)에 있다. 선택 메타데이터 355종·먼바다 259종·작살 115건도 구분한다.
- 다른 캐릭터 실기는 사용할 캐릭터가 없어 보류했다. 기존 캐릭터의 재접속 결과를 다중 캐릭터 확인으로 확대하지 않는다.
- 버전별 구현 순서와 과거 대기 기록은 [검증 색인](../verification/README.md)에 보존한다. 현재 문서에 버전별 회고를 다시 쌓지 않는다.
