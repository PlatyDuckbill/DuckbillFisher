# 남은 작업과 우선순위

현재 관심은 **터주작**이다. 다음 표는 구현 상태와 후보를 구분하며, 기록된 후보 자체가 착수 지시는 아니다. 실제 대표 확인/미확인 범위는 [STATUS](../STATUS.md)에만 갱신한다.

## 제공 중인 범위

| 단계 | 제공 범위 | 현재 한계/근거 |
|---|---|---|
| ENV-01~03 | KR 환경 확인·공개 API/네이티브 관찰 | 검증한 게임/배포판 조합만 허용. [호환성](../verification/native/NATIVE-RUNTIME-DAL4KR.md) |
| MVP-01 | 목록·상세·지도·필터·프리셋·간이 목록 | 전 어종/모든 폭·언어 조합의 전수 확인은 아님. [제품 계약](PRODUCT.md) |
| MVP-02 | 타이머·낚시터 목록·기록 관리·일반/생미끼 관찰 | 검증한 로그/시전 전이만 연결. [설계](CASTING-TIMER.md) |
| MVP-03 | 일반 시간/날씨 예측·남은 시간 정렬·즐겨찾기 로컬 알림 | 개인 조건이나 어획 성공 보장 아님. Toast 제거 |
| MVP-04 | 도감 대조·자동 수집/미수집·수동 우선 필터 | 미조회/실패는 Unknown. 다른 캐릭터 실기 별도 |
| SHARE-01 | 커스텀 저장소 설치·업데이트 | 첫 친구 설치/업데이트 확인 완료. 새 배포의 확인 범위는 별도 |
| F09/F14 | 미끼 준비·소지 수량·게임 UI 칸/페이지 표식 | 0.3.0.0 배포 완료. 모든 테마·친구 새 기능 확인은 별도 |
| 데이터 확장 | 일반 상세 1,258/1,258 연결 | 시간/날씨 전체 확인 1,256종, 부분 확인 2종. 모든 필드 완성 아님 |
