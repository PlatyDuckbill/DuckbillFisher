# 터주작 제안 정리

갱신: 2026-11-06. 초기 제안의 채택/제외 이력이다. **현재 TODO가 아니며**, 실제 작업 목록은 [ROADMAP](ROADMAP.md)에서만 관리한다. 당시의 미구현·미확인 설명을 현재 지시로 사용하지 않는다.

## 초기 다섯 제안의 현재 상태

| 번호 | 제안 | 현재 상태 |
|---|---|---|
| 1 | 미끼 준비 확인 | 구현·배포. 소지 수량·부족한 미끼·미끼 찾기는 [미끼 준비](BAIT-PREPARATION.md)를 따른다 |
| 2 | 출현 일정표 | 구현·배포. 시간축·월 달력·날짜별 회차는 [일정표](SPAWN-SCHEDULE.md)를 따른다 |
| 3 | 즐겨찾기 그룹 | 사용자 결정으로 향후 계획에서도 제외. 기존 즐겨찾기/필터 프리셋을 사용하며 그룹별 저장·필터·알림 체계를 추가하지 않는다 |
| 4 | 실시간 직감 상태 | 구현됨. 캐스팅 타이머의 버프 활성/남은 시간과0.8.0.0의 선행 어종 진행도를 사용한다. [타이머](CASTING-TIMER.md). 대표 확인/미확인 경계는 STATUS를 따른다 |
| 5 | 터주작 진행 현황 | 구현·배포. 지역/확장팩·먼바다 진행과 클릭 목록은 [제품 계약](PRODUCT.md)을 따른다 |

## 이후 논의의 정리

- 터주작 추천은0.6.0.0에 지금 노릴 어종/밑작업/출현 드문 순으로 구현했다. [현재 추천 계약](NEXT-FISH-RECOMMENDATION.md)을 따르며 준비 시간·보관 최적화·점수 계산은 현재 TODO에서 제외한다.
- 현재 낚시터 출현 알림과 로컬 채팅/상세 링크도 구현했다. [알림 계약과 확인 범위](../verification/alerts/SPAWN-ALERTS.md#현재-낚시터-출현-알림-0600-2026-10-25)를 따른다. 이전 설정 위치·최초 인식·중복 방지·채널/소리 제안을 다시 구현할 작업으로 취급하지 않는다.
- 먼바다는 승인한 Beta의 일정/항로·현재 해역/시간·기본 미끼·일반/환해류 목록을 사용한다. 목표/업적 공략·점수 최적화와 작살 전용 상세는 현재 확장 계획에서 제외한다.
- 기존 어종 상세는 최소 획득력·소장품 납품 대상/구간·확인된 이중/삼중 수량을 연결했다. 도시/보상표/직접 입력·준비/재준비 설명·상세의 실시간 직감 진행도는 추가하지 않는다.
- 폐기한 추천 계산과 초기 조사 원문은 [과거 기록](../archive/design/NEXT-FISH-RECOMMENDATION-INVESTIGATION.md), 버전별 실제 검증은 [검증 색인](../verification/README.md)에 보존한다. 구현 완료로 게임 실기·모든 조합 확인까지 완료했다고 간주하지 않는다.

## 현재 낚시터 출현 알림 논의 (2026-10-24)

이 제목은 과거 검증/조사 문서의 링크를 보존한다. 당시 논의한 로컬 채팅·현재 낚시터 알림·중복 방지는 이후0.6.0.0에 구현했으며 현재 계약은 [알림 구현/검수](../verification/alerts/SPAWN-ALERTS.md#현재-낚시터-출현-알림-0600-2026-10-25)를 따른다. 과거 문서의 ‘미구현/다음 작업’을 새 TODO로 되살리지 않는다.
