# 제품 범위와 확정 동작

한국 서버에서 사용자가 직접 낚시하며 어종·조건·수집 상태·미끼·출현 예측·기록을 확인하는 정보 플러그인이다. 이 문서는 현재 합의한 동작을 정의한다. 실제 확인 범위는 [STATUS](../STATUS.md), 남은 후보는 [ROADMAP](ROADMAP.md)을 따른다.

## 수집·필터·정렬

- 수집 숨김은 Caught만 제외하고 Unknown을 유지한다. 미확인은 미수집이 아니다. 수동 상태는 캐릭터별, 즐겨찾기는 공통 저장한다.
- 확인한 수집/미수집 상태와 마지막 저장 UTC는 캐릭터별 로컬 설정에 보관한다. 현재 관찰이 Unknown일 때만 백업을 사용하고 저장 배지와 동기화 안내의 저장 시각으로 구분한다. 실패/빈 조회로 기존 미수집 백업을 지우지 않으며 신규 등록은 수집됨만 보완한다. 수동 지정은 별도로 보존한다. [저장·확인 절차](../verification/collection/GUIDE-SNAPSHOT.md#수집-상태-로컬-백업-개발본-2026-10-23).
- 신규/기본값 복원은 남은 시간순·수집 숨김·도감 어종·먼바다 제외·시간제만·터주(왕 포함)다. 기존 저장 선택은 유지한다. 코드 기준은 CatalogSettings다.
- 남은 시간순은 출현 중 종료순 → 출현 예정 시작순 → 시각 미확인 → 상시다. 동률은 이름/ID로 안정화한다. 현재 지역은 필터이며 정렬 우선순위에 넣지 않는다. [세부 정렬](LIST-SORTING.md).
- 필터 팝업에서 출현 중 최소 잔여 시간·출현까지 최소/최대 시간을 실제 분으로 지정한다. 세 입력 모두 빈칸이면 해당 제한을 해제한다. 잔여는0도 해제, 예정0은 실제0분으로 구분한다. 최소만/최대만/범위/양쪽 빈칸을 지원한다. 메인/간이 목록·현재 목록 대상 미끼 준비/일정표가 공유하고 상시/시간 미확인은 유지한다. 저장·정확한 경계는 [목록 시간 필터](LIST-SORTING.md#정렬과-표시)를 따른다.
- 필터 도구 모음의 물고기의 눈 아이콘은 시작/재로드·기본값 복원 시 OFF다. 전환하면 남은 시간순으로 바꾸고 선택 기준의 시간을 표시한다. ON으로 시간 제한이 없어지는 어종은 종료가 있는 출현 중 다음·예정 앞에 둔다. 일반적으로 상시인 어종의 기존 순서는 유지한다. 이 모드는 세션 공통이며 프리셋/캐릭터 설정에 저장하지 않는다. 간이 목록도 같은 기준을 사용한다.
- 시간제는 대상 또는 직감 선행 어종의 알려진 ET·현재/직전 날씨 제약이다. 제한 미확인은 시간제만에서 제외한다. 등급 전체는 등급 제한만 해제한다.
- 지역/확장팩은 각 그룹 내 OR, 서로 다른 필터는 AND다. 같은 낚시터가 지역·확장팩·현재 지역 조건을 함께 만족해야 한다. 확장팩은 어종 도입 패치가 아닌 낚시터 소속이며 ID 0도 유효하다.
- 지역/확장팩 선택 없음은 해당 제한만 해제한다. 선택 충돌은 빈 결과로 유지한다. 가려진 지역 선택을 자동 삭제하지 않고 안내/해제를 제공한다.
- 현재 지역 또는 특정 지역/확장팩 선택 시 먼바다·위치 미확인은 제외한다. 지역을 읽지 못하면 임의 대체하지 않는다.
- 전체 보기는 검색/일반 필터를 풀고 정렬은 유지한다. 기본값 복원과 구분한다. 진단용 확인 불가 행은 포함하지 않는다.
- 이름 프리셋은 최대 20개, 필터+정렬을 저장한다. 검색/진단은 제외하고 불러올 때 해제한다. [저장 계약](../verification/catalog/FILTER-PRESETS.md).

## 화면과 상호작용

- 어종 상세의 이름/상태 아래 ‘메모·캐스팅 타이머 관리’ 접힘 영역에서 개인 메모·도전 횟수·캐스팅 프리셋 연결을 관리한다. 저장된 기록은 캐릭터 공통이며 JSON/ZIP 백업에 포함한다. 메모는 명시적 저장이며 ‘메모 비우기’에는 확인1회를 둔다. 횟수는 직접 조절하며 용도는 마우스 오버로 안내한다. 프리셋은 명시적 적용이며 상세 선택만으로 타이머를 바꾸지 않는다. [제한·저장·연결/삭제·백업 동작](FISH-PERSONAL.md).

- 즐겨찾기 관리는 ‘즐겨찾기 / 출현 알림 설정 / 발송 기록’ 순서의 세 탭이다. 출현 알림 켜기는 가운데 탭 최상단의 테두리/배경·큰 체크박스 영역에 두며 탭 바깥 사용 스위치와 톱니는 제거했다. 기본 사전 시간·로컬 표시 채널은 각각 라벨과 입력을 한 줄로 정렬하고 소리 선택/미리 듣기도 한 줄로 묶는다. 대상/자동 해제 옵션·SE/WAV는 같은 탭에서, 어종별 사전 시간은 즐겨찾기 목록에서 조절한다. 메인 일반 설정에는 출현 알림 설정을 중복 배치하지 않는다. 캐스팅 알림 채널은 타이머 설정에서 독립적으로 지정하며 입질·터주·터주왕은 소리만 출력한다.

- 수집 현황의 일반 낚시 합계는 지역 표 위의 큰 요약 블록으로 표시하며 좁은 폭에서는 세 수치를 세로로 배치한다. 지역 표의 막대는 가용 폭에 맞춰 줄어들고 수치가 길면 축약하되 툴팁에는 전체 수치·진행률·수동/Unknown을 유지한다. 진행률 구간별 색상을 구분하되 색상 기준 문구는 표시하지 않는다. 합계 옆에는 확장팩/지역/해역 클릭 안내를 항상 표시하며 좁으면 다음 줄로 넘긴다. 상세 수집 규칙은 화면 하단의 기본 접힘 항목이다.
- 클릭 목록은 확장팩·지역·해역별 막대만 지원하며 일반 낚시/도감/먼바다 전체 합계에는 제공하지 않는다. 클릭한 전체/터주(왕 포함)/터주왕 범위를 독립 목록1개에 재사용하고 전체↔수집한 어종 숨기기를 전환한다. Unknown은 숨기지 않는다. 어종 상세 열기·메인 닫기·다른 곳 클릭으로 목록을 닫지 않으며 직접 닫아야 한다. 다른 범위를 선택하면 대상/표시 캐시를 교체하고 닫으면 해제한다. Framework에서 선택 범위의 배열만 준비하고 보이는 행만 렌더링하며 전체 도감 목록 복사본은 만들지 않는다.

- 수집 현황은 메인 목록 필터와 독립적으로 표시 가능한 어류도감 대상 전체를 집계한다. 일반 낚시는 확장팩을 펼쳐 지역별 수집 수/전체 수·진행률을 비교한다. 전체 보기에서는 전체·터주(왕 포함)·터주왕을 나란히, 터주/터주왕 보기에서는 해당 수치만 표시한다. 먼바다는 별도 구역에서 전체 합계와 게임 시트의 해역 ID별 현황을 표시한다. 일반/환해류 낚시터는 같은 해역에 합치며 등급 보기와는 독립적이다. 같은 어종은 각 지역/확장팩 안에서 한 번만 세고 일반/도감 전체 합계도 고유 어종 기준이다. 여러 지역에 서식하면 지역별 합의 단순 합은 전체와 다를 수 있다. 확장팩은 낚시터 소속이며 검증된 거주구 보정은 DATA-SOURCES의 근거를 따른다. 위치가 없으면 위치 미확인, 등급 미확인은 전체에 포함하고 터주 수치에서 제외한다. 수동 우선·세션 격리를 유지하며 미확인은 별도 숫자와 툴팁으로 구분한다. 대상0종은 완료가 아니며 모든 대상이 Caught일 때만 완료를 표시한다. 집계는 Framework 갱신에서 자료/수집/설정 변경 시 수행하고 Draw는 snapshot만 표시한다.

- 설정 → UI 배율에서 80/90/100/110/125/150/175/200%를 선택하고 100%로 복원한다. 기본100%이며 Dalamud 배율에 곱해 모든 플러그인 화면의 글자·아이콘·버튼·간격과 최초/최소 크기를 조절한다. 현재 화면 크기는 필요하면 직접 조절한다. 배율은 캐릭터 공통으로 저장하고 재로드/한영 전환 후 유지한다. 게임 미끼 UI 위의 위치 표식은 게임 좌표를 따른다.
- 일반 설정은 화면 설정/백업/출처 순서를 유지하고 언어·배율·개발자 도구·업데이트 내역을 라벨/입력 행으로 정렬한다. 배율 복원은 선택기 옆 아이콘, 업데이트 내역은 같은 입력 열의 보기 버튼이다. 백업 내보내기/가져오기와 복원/취소는 아이콘·동일 폭 버튼으로 묶는다. 긴 백업 범위·주의사항과 정상 데이터 출처는 기본 접힘이며, 오류와 복원 시 교체 안내는 계속 표시한다.
- 설정 백업은 공통 UI/필터·즐겨찾기·프리셋·알림·타이머를 JSON으로 내보내며, 기본으로 WAV까지 ZIP 하나에 담는다. 가져오기 검증과 사용자 복원 확인을 거치며 캐릭터 수집/기록·발송 기록은 보존한다. WAV 선택은 전용 폴더의 용도별 영어 고정 파일을 교체하고 원본 이동과 독립적으로 재생한다. [범위·음원·이전 백업 호환성](SETTINGS-BACKUP.md).
- 메인은 어종 목록/수집 현황/즐겨찾기 관리/낚시 기록/설정이 중심이며 목록 선택은 오른쪽 상세를 갱신한다. 상세 상단의 ‘별도 화면으로 보기’는 등급·별·수집 상태와 같은 줄에 두고 좁은 폭에서는 툴팁을 가진 아이콘으로 표시한다. 기존 독립 상세1개를 재사용하며 메인에서 다른 어종을 선택해도 따로 연 상세를 유지하고 다시 버튼을 누를 때 바꾼다. 진단은 개발자 도구를 켰을 때만 노출한다.
- `/dbfs` 또는 `/duckbillfisher`는 메인, `cl`/`compact` 인자는 간이 목록, `ct`/`timer` 인자는 캐스팅 타이머를 열고 닫는다. 메인 상단의 간이 목록·타이머 버튼도 각각 열기/닫기 토글이다. 인자는 대소문자를 구분하지 않는다. 단축 명령어가 다른 플러그인과 충돌하면 기존 명령어는 유지하고 충돌을 로그에 남긴다.
- 업데이트 안내는 처음 설치하거나 확인한 버전보다 새 버전을 로드한 뒤 메인을 처음 열 때 독립 화면으로 한 번 표시한다. 로드만으로 미리 띄우지 않으며, 같은 버전의 개발판에서 확인한 이력은 배포판에서도 유지한다. 최근 공개 릴리스 최대10개를 최신순으로 나열하며 최신 내역만 기본 펼침, 나머지는 버전별로 펼쳐 본다. 각 기능은 별도 항목/줄로 표시한다. 배포‘배포 시각 미기록’으로 표시한다. 중간 개발 버전은 제외하고 설치된 버전은 별도로 표시한다. 본문이 표시된 뒤 확인 버튼/제목의 닫기로 닫으면 다음 Framework 갱신에서 공통 설정에 확인 버전을 저장한다. 캐릭터/언어 변경은 확인 상태를 초기화하지 않으며 설정 → 업데이트 내역에서 다시 열 수 있다. 접어 두기/언로드만으로 확인 처리하지 않는다. 저장 실패 시 재로드 후 다시 표시될 수 있고 기존 설정은 보존한다. 본문은 내장 한영 리소스, 설치 화면 내역은 배포 메타데이터다.
- 간이 목록은 즐겨찾기 여부를 제외한 메인 일반 필터를 공유한다. 상단 별 버튼/옵션의 ‘즐겨찾기만’은 간이 목록 전용이며 메인의 즐겨찾기 필터를 바꾸지 않는다. OFF면 즐겨찾기 여부로 제한하지 않고 ON이면 공유 필터를 통과한 즐겨찾기만 보여준다. 선택은 공통 설정에 저장하며 최초 이전 시 종전 메인의 즐겨찾기 필터를 이어받는다. 출현 예정 범위는 별도이며 알림 대상은 바꾸지 않는다. 선택하면 독립 상세 하나를 재사용한다. 메인 열기 버튼은 토글이다.
- 타이머는 현재 낚시 기록과 중단 후5분간의 최근 기록을 보여준다. 지역을 이동해도 유지하며 새 낚시/캐릭터 전환/재로드/만료 때 교체하거나 비운다. 메인 낚시 기록은 지역·낚시터/날짜/총 낚시 시간/시전·성공 횟수 요약 → 같은 탭 상세 → 목록 복귀, 묶음/전체 확인 삭제다.
- 타이머 설정은 입질/터주/터주왕의 개별SE·커스텀 WAV를 제공한다. 소리는 기본 없음이며 터주/터주왕은 기본으로 실제 도감 최초 등록 시에만 울린다. 옵션 해제 시에는 확인된 어획마다 울린다. 낚시터 목록의 전체/수집 숨김 필터는 플러그인·게임 재시작 후에도 최근 선택을 유지한다. [세부 동작](CASTING-TIMER.md).
- 타이머의 어종 보기는 독립 낚시터 목록 하나를 열고 같은 버튼을 다시 누르면 닫는 토글이다. 어종 상세 선택·다른 곳 클릭·타이머 닫기로 목록을 닫지 않는다. 기존 어종 행과 전체↔수집 숨김 버튼 하나를 사용한다. 수집 상태는 문구와 함께 배경·테두리가 있는 배지로 강조하며 수집됨=녹색·미수집=붉은색·미확인=회색이다. 수동 우선 판정을 따른다. 낚시 종료 후 마지막 낚시터는 유지하지만 새 시전에는 이전 위치를 비운다. 본인 시전 로그가 미지의 낚시터를 가리키면 이를 명시하고 어종 보기를 비활성화한다. 미지임을 확인하지 못한 경우에는 ‘낚시터 확인 중’으로 구분한다. 발견/등록 정보와 해당 시전의 본인 어획이2초 안에 함께 확인되고 지역+이름이 낚시터 하나에 대응하면 목록을 갱신한다. 식별 전에는 안내 툴팁을 제공한다. 메인의 다른 필터와 독립이며 열림 여부는 언로드 후 복원하지 않는다.
- 미끼 준비는 직접 닫기 전까지 유지되는 독립 화면이다. 준비 화면에는 찾기 버튼을 두지 않는다. 첫 미끼 선택지가 여러 개면 각 미끼에 대상이 포함될 수 있다는 짧은 안내만 둔다.
- 아이콘은 툴팁을 제공하고 좁은 폭에서도 정보에 접근할 수 있게 한다. 어종 아이콘은 오른쪽 정보와 세로 중앙 정렬한다. 전승록은 상세에서만 표시한다. 고정된 물고기의 눈 미사용 안내는 삭제했다. 상세는 두 기준의 상태/시작/종료/미확인 이유가 달라질 때만 일반·물고기의 눈 예측을 함께 표시한다. 지원이 확인된 대상/선행 어종의 ET 제한만 해제하며 날씨/직감은 유지한다. 지원 미확인 값으로 시간 제한 해제를 추측하지 않는다. 실제 기술 사용·GP·버프 남은 시간은 관측하지 않는다.
- 하루 이상 남은 시간/툴팁·상세·하루 이상 경과는 `일:시:분:초`(예: `01:05:00:00`)로 표시하고 하루 미만 형식은 유지한다. 상세의 첫 미끼 수량 안내는 하나의 툴팁으로 통합한다. 일반 미끼/전승록은 아이템 링크 동작을 유지하고, 상세가 있는 생미끼/직감 선행 어종을 누르면 비교 상세를 연다.
- 비교 상세는 사용자 합의에 따라 독립 상세와 별개로 **1개만 재사용**한다. 원래 화면/선택을 보존하고 비교 안에서 이동하면 최대32단계 뒤로 돌아갈 수 있다. 외부에서 새 비교를 시작하면 이동 이력을 비우며 캐릭터 전환도 이력을 비운다. 로컬 상세 탐색은 게임 로그인 없이 가능하며 게임 링크 출력은 기존 캐릭터 경계를 따른다.
- 직감 조건 어종은 목록 시간에 `직감` 표식을 표시하고 툴팁에는 계산 범위만 짧게 안내한다. 선행 어종의 순차 구간·직감 지속 시간을 반영하며, 실제 선행 어획/버프/준비 소요 시간은 관측하지 않는다. 사용자 요청으로 지속 시간 null은 **175초를 가정**해 예측하고 상세의 직감 구역에 경고한다. 원본 null과 가정 여부는 별도로 보존한다. 모든 선행 어종이 상시이면 지속 시간 없이도 대상 조건으로 예측할 수 있다. 일반1,258종 전체에 공통 계산을 적용하며 먼바다/작살 전용 범위는 F11과 데이터 후속을 따른다.
- 직감 계산 구역은 **기본 접힘**이며 어종/화면별로 열고 닫는다. 펼치면 아이콘·역할·시간을 표로 나누고 최종 결과를 강조한다. 선택 기준과 최종 예측에 대응하는 대상 자체 시간/날씨 구간·선행 어종별 구간/마릿수·계산 지속 시간을 제공한다. 현재 직감 버프와 별개인 예상임을 보조 문구 하나로 설명한다. 최종 구간을 못 찾으면 각 어종의 개별 출현임을 알린다. 175초 가정 경고는 접힌 상태에서도 상세에 남는다.
- 도감 미조회 안내에는 어류도감 열기 버튼을 제공한다. 호환성 차단과 단순 미조회를 구분한다. 큰 화면 구조 변경은 사용자에게 먼저 질의한다.

## 알림·기록 정책

- 알림은 켜기/끄기, 기본/어종별 0~60분이며 새 설정의 기본은 꺼짐/0분이다. 기존에 저장한 시간은 유지한다. 0분은 미리 예약한 출현 시작을 통과한 첫 표본에서1회 알리며, 이미 출현한 뒤 켜거나 재로드한 경우에는 소급하지 않는다. 표본은 약1초 간격이며 출현 종료 뒤에는 발송하지 않는다.
- 출력은 로컬 표시 채널22개와 소리 없음/SE.1~16/커스텀 WAV다. 커스텀은 로컬 파일 선택·미리 듣기·재불러오기·중지, 최대10MB/30초이며 Windows 음량을 따른다. 메시지는 어종 아이템 링크·분 단위 올림 남은 시간(0분은 ‘출현 시작’)·위치 링크, 기록은 한 줄 로그다. Toast는 제거했다.
- 커스텀 WAV 파일/재생 오류여도 채팅 알림은 유지한다. 한 묶음당 재생 요청1회이며 기록의 ‘재생 요청됨’은 작업 큐 접수를 뜻한다. 원본 수정 후 재불러오기로 반영하고, 파일/소리 종류·캐릭터 전환/언로드 때 이전 재생을 정리한다. [범위·확인 대기](../verification/alerts/CUSTOM-SOUND.md).
- 전체 즐겨찾기 알림은 수집 여부로 제외하지 않는다. 미수집만 모드에서는 최종 Uncaught만 포함하고 Unknown은 제외한다.
- 알림 예약과 즐겨찾기 관리 행은 일반 예측 기준을 유지한다. 물고기의 눈 버튼은 탐색/정렬 기준이며 예약·발송 기록을 바꾸지 않는다.
- 새 도감 등록 시 자동 즐겨찾기 해제는 기본 켜짐이다. 도감 초기 조회·수동 지정·반복 어획은 자동 해제 트리거가 아니다.
- 로그인·캐릭터 전환·재로드·절전 복귀에서 소급/중복/폭주를 방지한다. 시간·날씨 알림을 개인 준비 완료로 표현하지 않는다.
- 시전 시작 미끼는 이후 미끼 변경/소모와 무관하게 보존한다. 성공·명시적 실패·취소·중단·미확인을 구분한다. 미검증 결과나 수량은 추정하지 않는다.
- 기록은 진행 중 묶음을 보관 개수 정리에서 보호하고 총 횟수와 보관 행 수를 구분한다. 이전 형식 가져오기와 삭제/복원은 [타이머·기록 설계](CASTING-TIMER.md)를 따른다.

범위 밖: 자동 게임 조작·미끼 변경·입력 대행·서버 채팅·런타임 외부 조회·호환성 가드 우회. 입질 초 통계, 복수 어획, 먼바다/작살 확장 등은 [로드맵](ROADMAP.md)의 후속/보류 상태를 따른다.
