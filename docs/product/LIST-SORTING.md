# 목록 정렬 개선안

상태: 0.1.18.0 구현/별도·정규 빌드 통과 · 정렬 사용자 대표 확인 통과 · 2026-10-16

0.3.4.0 확장: 필터 줄 물고기의 눈 전환 시 선택 기준의 남은 시간순으로 정렬한다. ON으로 시간 제한이 없어지는 어종은 종료가 있는 Open 뒤·Upcoming 앞에 두고, 원래 Always인 어종은 맨 아래를 유지한다. 일반/물고기의 눈 캐시는 별개이며 시간제 필터는 원본 조건으로 분류한다. 현재0.3.5.0의 하루 이상 표시는 `일:시:분:초`다. 아래 기존 정렬 대표 확인을 이번 확장의 실기 확인으로 확대하지 않는다.

## 확정 요구와 현재 동작

- 남은 시간 정렬은 필수다. 사용자가 지정한 순서는 현재 열린 제한 창(종료까지 짧은 순) → 예정 창(시작까지 짧은 순)이다. 출현순/종료순을 별도 메뉴로 나눌 필요 없이 하나의 ‘남은 시간순’으로 제공한다.
- 상시 어종은 선두에 두지 않는다. 맨 아래 표시를 기본안으로 두고, 숨기기는 기존 ‘시간제만’ 필터와 결합한다. 후자는 모든 비시간제 어종을 제외하는 필터이며 시간 정렬 자체가 어종을 제거하지는 않는다.
- 현재 지역은 기존 ‘현재 지역만’ 체크박스로 켜고 끄는 필터다. 지역을 정렬 기준이나 동률 기준에 넣지 않으며, 현재 지역 우선 정렬/추가 체크박스/지역별 묶음을 만들지 않는다.
- 0.1.17.0까지는 Open/Always를 함께 맨 앞에 두고 Upcoming을 다음 시작 시각으로 정렬했다. 0.1.18.0은 Core의 `FishingWindowOrdering.Key`로 그룹과 경계를 정하고 Plugin에서 이름/ID 동률을 적용한다.
- 남은 시간은 ET/날씨 창 기준 실제 시간이다. 직감·전승록·생미끼 등 개인 준비 완료나 낚시 성공을 뜻하지 않는다. 먼바다 방문 시간대를 어종별 출현 창으로 대신 계산하지 않는다.

## 정렬과 표시

- 개발 후보의 필터 팝업에는 최소 잔여 시간과 출현까지 최대 시간(실제 분, 각각0~43,200)을 제공한다. 최소 잔여 시간은 Open의 종료까지 n분 미만만 숨기고 Upcoming에는 적용하지 않는다. 출현까지 최대 시간은 Upcoming의 시작까지 n분 초과만 숨기고 Open에는 적용하지 않는다. 각각0은 제한 해제다. 상시·경계 미확인·예측 불가를 임의로0분으로 처리하지 않고 유지한다. 다른 일반 필터와 AND이며 물고기의 눈의 선택 예측 기준을 따른다.
- 공통 설정schema18/이름 프리셋에 저장하고 전체 보기·기본값 복원은 두 값을0으로 되돌린다. 메인·간이 목록과 현재 목록 대상 미끼 준비/일정표에 적용하며 즐겨찾기 대상·알림에는 적용하지 않는다. 간이 목록은 자체 예정 범위와 출현까지 최대 시간 중 더 짧은 제한을 적용한다. UTC 경계/예측 변경 때 다시 필터링하며 남은 시간의 초 표시만으로 매 프레임 전체 목록을 재검색하지 않는다. [검사·실기 대기](../verification/catalog/UI.md#목록-최소-잔여최대-예정-시간-2026-10-22).

| 선택 | 기준과 화면 표시 |
|---|---|
| 남은 시간순 | 열린 제한 창은 종료까지 짧은 순 → 예정 창은 시작까지 짧은 순. 각각 ‘종료까지 3분’ / ‘시작까지 12분’처럼 기준을 표시 |
| 이름순 / 어종 ID순 | 기존 기본 탐색 기준 유지 |

- 세부 그룹은 종료 시각이 있는 Open → 시작 시각이 있는 Upcoming → 시각 미확인(경계 없는 Open/Upcoming / NotFound / Unknown / 먼바다) → Always 순이다. 상시를 맨 아래에 두되 미확인을 0초나 상시로 취급하지 않는다. 시각 미확인은 이유를 구분해 표시한다.
- 남은 시간 동률은 어종명→FishParameter ID로 안정적으로 정리한다. 다른 지역 이름순을 별도 기준으로 추가할 필요는 없다.
- 0.1.23.0 사용자 요청으로 시작 기본 선택은 ‘남은 시간순’(Sort=2)이다. 이름순/ID순/즐겨찾기 우선도 선택할 수 있다. 현재 신규/복원 필터는 먼바다 제외/시간제만/터주(왕 포함)/수집한 어종 숨기기이며 시간순의 내부 순서 자체는 유지한다.
- 0.1.26.0부터 실제 시작 선택은 마지막 저장된 일반 필터/정렬/지역·확장팩이다. 저장값이 없는 초기 설정과 기본값 복원 버튼은 위 기본값을 사용한다. 검색어/선택 어종/진단용 두 체크는 저장하지 않는다. [저장/복원 범위](../verification/catalog/CATALOG-SETTINGS.md)를 따른다.

## 지역 필터와 정렬의 분리

- 사용자는 지역을 정렬에 섞는 대신 별도 체크박스 필터로 유지하기로 했다. 기존 ‘현재 지역만’을 켜면 해당 지역의 어종만 남기고, 끄면 지역 제한 없이 다른 필터가 허용하는 어종을 표시한다.
- 두 경우 모두 남은 시간순의 그룹/시간 기준은 같다. 예: 체크 해제 시 타 지역 종료 1분 → 현재 지역 종료 10분, 체크 시 현재 지역 종료 10분만 남는다. 체크 전환은 선택한 정렬을 바꾸지 않는다.
- 즐겨찾기 우선은 기존 기능을 유지한다. 시간순과 결합하는 새로운 즐겨찾기 옵션이나 복잡한 다중 정렬 편집기는 이번에 추가하지 않는다.
- 검색·수집·등급·시간제·지역/확장팩 필터는 포함 여부를 결정한다. 정렬은 포함된 결과의 순서만 바꾸며 어종을 추가/제외하지 않는다.

## 구현 시 지킬 기준과 확인 항목

- 복수 낚시터 어종은 현재 지역/지역·확장팩 필터를 같은 낚시터에서 충족하는 후보 중 대표 표시 위치를 고른다. 시간 정렬에 지역 키를 추가하지 않고 중복 행을 만들지 않는다.
- 추천 낚시터와 대표 지역이 다른 경우 기존 조건·예측 위치 안내를 유지한다. 지역을 바꾸었다는 이유로 그 지역의 시간 창을 새로 계산했다고 표시하지 않는다.
- 남은 초 숫자 대신 시작/종료 UTC 시각을 정렬 키로 사용한다. 매 프레임 전체 재정렬/장기 예측을 하지 않는다. 예측·창 경계·필터/선택 변경 때 순서를 갱신한다. 지역 이동은 기존 ‘현재 지역만’ 필터를 켠 경우 결과에 반영한다.
- 동률은 고정 ID까지 정리한다. 초 단위 카운트다운 갱신만으로 행이 흔들리지 않게 하고 선택·상세·언어 상태를 보존한다.
- 열린 창 여러 개/예정 창 여러 개/상시/미확인/범위 내 미발견/먼바다, 현재 지역만 필터 전후의 시간순 유지, 지역 이동과 복수 낚시터를 확인한다. 예측 자체의 게임 ET/날씨 동시 대조는 별도 미확인으로 유지한다.
- 빌드·리소스 검사와 인게임 확인 범위는 [구현 기록](../verification/catalog/REMAINING-TIME-SORT.md)을 따른다.

구현 진입점: Core FishingWindowOrdering의 정렬 키와 Plugin CatalogQuery/CompactFishObserver의 적용 경로. 현재 기본값은 [PRODUCT](PRODUCT.md), 확인 범위는 [STATUS](../STATUS.md)를 따른다.
