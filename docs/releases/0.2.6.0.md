# DuckbillFisher 0.2.6.0

## Fixed

- Support the inspected **dal4kr build of KR Dalamud 15.0.3.7**, alongside the previously supported wasdcxz builds. These distributions share a version number but use different module identities.
- Check all inspected builds for a version and require a complete matching module combination. This addresses the collection sync, direct fish-guide opening, casting timer, and sound block reported with the dal4kr distribution.

The KR game build remains **2026.10.06.0000.0000 / API 15**. Existing collection decisions, manual overrides, filters, alerts, and fishing records are unchanged. Unknown runtime combinations remain disabled.

Update DuckbillFisher through Dalamud using the existing custom repository URL. No launcher or framework file replacement is required by this plugin update.
