# DuckbillFisher 0.3.9.0

## New

- Read release notes in the plugin installer.
- Browse Korean/English notes for the latest five releases in the plugin. The newest version is expanded by default; expand older versions individually.
- The update screen appears on first load or after a version upgrade. Closing it marks that version as read. Reopen it from Settings → What's new at any time.

The installed version is shown separately from the release history. Intermediate development versions are omitted. Notes are bundled with the plugin; no runtime network requests are added.

Existing favorites, character records, filters, alert settings, and WAV paths are preserved. Read status is shared across characters on the same PC. If settings cannot be saved, the screen may reappear after reloading. This version writes settings schema 13; older versions do not support that schema.

Update through the existing custom repository. Supported KR client/runtime profiles and Dalamud API 15 are unchanged; global runtime support remains unverified.
