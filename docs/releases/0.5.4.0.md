# 0.5.4.0 — Personal fish records and portable backups

## Notes, attempts and cast alert presets

- Open **Notes and casting timer** in a fish's details to save a personal note of up to 1,000 characters. Unsaved drafts stay available when you browse other fish. Clear note asks once before clearing the saved note and draft; attempt counts and preset links are kept.
- Record an attempt count for each fish using minus, plus or direct number entry. These are personal, manually maintained counts shared across your characters.
- Link a saved cast alert preset to a fish and choose **Apply to timer** when you want to use it. Browsing fish or selecting a link does not change the active alerts. Applying replaces the cast alert list while keeping the chat channel and fishing sound settings.
- Open **Manage presets** directly from fish details. Updating a linked preset is reflected the next time you apply it; deleting a preset removes its links without deleting fish notes or counts.

## Settings backups and managed WAV files

- In **Settings → Settings backup**, export one JSON with settings and sound paths, or one ZIP with settings and selected custom WAV files. Saved fish notes, attempt counts and preset links are included alongside favorites, filters, interface settings, alerts and timer presets.
- Open a backup to validate it and preview its date and contents before choosing **Restore settings**. The preview includes the number of fish with personal records. Character collection choices, collection snapshots, fishing history and sent-alert records are kept outside this backup and are preserved when restoring.
- Existing backup formats remain readable. **Restoring an older backup without personal records clears current notes, attempt counts and preset links**; a warning is shown before applying it. Unsaved note drafts are not part of a backup.
- Selecting a custom WAV now saves a managed copy under a stable name for that sound. Moving or deleting the original does not break the managed copy. To import changes made to the original, select it again; Reload reads the managed copy.
- ZIP backups include files only for sound choices currently set to custom WAV. Remembered paths under None or built-in sound effects are excluded. WAV limits remain 10 MB and 30 seconds per file, with playback support determined by Windows waveaudio.

## Clearer alerts and settings

- Find **Favorites / Spawn alert settings / Delivery history** together in Favorites management. Spawn alert settings has a prominent enable control at the top, followed by aligned fields for the default lead time, local display channel and sound.
- Choose a **cast alert chat channel independently of spawn alerts** in the existing timer settings. Bite, big fish and legendary fish notifications remain sound-only.
- Saving a cast preset with an existing name asks once before overwriting it. Cancelling preserves the saved preset; confirming keeps its identity and existing fish links.
- Preset and alert headings show current/maximum counts, such as 3/20 and 2/32. Limits and the 1–3600-second range are available in tooltips near the controls instead of repeated explanatory paragraphs.
- General settings uses aligned fields, grouped icon buttons and expandable backup/source details. Restore warnings and errors remain visible.

Settings migrate to schema 23 while preserving existing supported settings and fishing history. Verified runtime support remains limited to the supported Korean client and Dalamud module combinations. This update adds no automated fishing actions or runtime network synchronization.
