# 0.5.4.0 — Fish notes and settings backups

Keep personal fish records and back up your settings and sounds.

- Save a personal note for each fish.
- Track your attempts for each fish manually.
- Link a cast alert preset to a fish and apply it from fish details.
- Back up and restore settings and saved fish records as JSON, or include WAV files in a ZIP.
- Keep custom sounds working after moving or deleting the original WAV file.

Other improvements:

- Manage spawn alerts in the new Spawn alert settings tab in Favorites management.
- Choose a cast alert chat channel separately from spawn alerts.
- Confirm before overwriting a preset with the same name.
- Find settings more easily with tidier controls and shorter help.

Notes:

Settings backups exclude collection data and fishing history.
