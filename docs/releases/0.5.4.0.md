# 0.5.4.0 — Fish notes and settings backups

- Save personal notes and track attempts for each fish.
- Link a cast alert preset to a fish and apply it directly from fish details.
- Back up settings, favorites, presets and saved fish records as JSON, or include custom WAV files in a ZIP.
- Preview a backup before restoring it.
- Keep custom sounds working even after moving or deleting the original WAV file.
- Manage spawn alerts in the new **Spawn alert settings** tab in Favorites management.
- Choose a cast alert chat channel separately from spawn alerts.
- Use tidier settings, with confirmation before clearing notes or overwriting presets.

**Before restoring:** Collection data and fishing history are excluded from settings backups. Restoring an older backup without personal records clears current fish notes, attempt counts and preset links; a warning is shown before you continue.
