# 0.5.2.0 — Cast alerts and presets

Set cast-time reminders and reuse named timer presets.

- Add multiple cast-time alerts with names, individual times and built-in sound effects.
- Edit alerts with + / − in a separate timer settings screen, and save or load named presets.
- See time since a new lure-effect stack was observed, alongside the existing cast timer. Reusing a lure restarts its elapsed timer when the stack increases.

Other improvements:

- Keep collection states in a per-character local backup. Saved states fill unknown current observations; manual choices still take priority.
- Open timer settings with the stopwatch shortcut beside the fish-list button and its fish icon.
- Support the verified KR Dalamud 15.0.3.9 module combination with the existing exact compatibility checks.

Notes:

Settings use schema 20. Existing favorites, manual collection choices, filters and fishing history are preserved. New cast alerts start with an empty list. No fishing actions are automated and no runtime network synchronization is added.
