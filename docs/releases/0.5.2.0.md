# 0.5.2.0

- Add multiple cast-time alerts with optional names, individual times, enabled states and built-in sound effects. Alerts remain active when the timer screen is closed and stop when the cast is hooked or ended.
- Save and load named alert presets in a separate timer settings screen. Use + and − to add or remove alerts.
- See lure elapsed time beside the existing cast timer. Timing starts when a new lure-effect stack is observed, restarts on an observed stack increase, and remains unknown when its start was not observed.
- Keep a per-character local backup of verified collection states. Manual choices take priority, followed by current game observations and then the saved backup. Saved states are labeled and may omit newer registrations until synchronization resumes.
- Open timer settings with the stopwatch shortcut beside the fish-list button, which now includes a fish icon.
- Support the verified KR Dalamud 15.0.3.9 module combination while retaining the exact runtime compatibility checks.

Settings use schema 20. Existing favorites, manual collection choices, filters and fishing history are preserved. New cast alerts start with an empty list. No fishing actions are automated and no runtime network synchronization is added.
