# DuckbillFisher 0.3.10.0

- Added `/dbfs` as a short command. Use `/dbfs cl` for the compact list and `/dbfs ct` for the casting timer. `/duckbillfisher` and the full `compact` / `timer` arguments remain supported with either command.
- Fishing-spot fish now open in a separate view that stays open while inspecting fish details, clicking elsewhere, or closing the casting timer.

Korean and English UI. Verified Korean client/Dalamud support remains unchanged. Does not automate fishing.
