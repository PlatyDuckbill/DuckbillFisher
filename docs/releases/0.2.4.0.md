# DuckbillFisher 0.2.4.0

**Let Duckbill guide your next catch.**

The first custom-repository release of DuckbillFisher, a Dalamud fishing companion for **FFXIV Korea**.

## Included

- Fish catalog with collection, region, expansion, grade, and time-condition filters, plus named presets.
- Baits and mooch chains, weather/time conditions, map markers, and availability forecasts.
- Favorites with local chat alerts and optional sound effects.
- A quick list for fish available now or coming up soon.
- A casting timer and character-specific fishing records, including confirmed mooch bait and observed failures.
- Korean and English UI, with game names supplied by the client.

## Install and open

Add this URL to Dalamud's custom plugin repositories, then search for **DuckbillFisher** in the plugin installer:

```text
https://raw.githubusercontent.com/PlatyDuckbill/DuckbillFisher/main/repo/pluginmaster.json
```

Open with `/duckbillfisher`. Future updates use the same repository. If collection data is not ready, open the in-game fish guide's fishing tab when prompted.

## Supported environment

Built for **Dalamud API 15**. Representative checks use **KR game 2026.10.06.0000.0000** and **XIVLauncherKR Dalamud 15.0.3.6**. Global and other regional clients are not verified. Native observations require the inspected game/DLL versions and can become unavailable after an update.

## Known limits

- Time/weather forecasts do not confirm personal prerequisites or guarantee a catch. Some condition and fishing-spot mappings are incomplete.
- Ocean and spearfishing coverage is partial. Special outcomes, stored bait, multiple catches, and additional history recovery cases need further confirmation.
- Unconfirmed results remain unknown. Manual collection overrides take priority.
- No gameplay automation, server chat transmission, or runtime HTTP requests.

This is an initial release with representative checks, not exhaustive coverage of every outcome and environment. Third-party data notices are embedded in the plugin and available in the source repository.
