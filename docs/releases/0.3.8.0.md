# DuckbillFisher 0.3.8.0

**Let Duckbill guide your next catch.**

## New since 0.3.0.0

- Use a local WAV as your alert sound, with file selection, preview, reload, and stop controls. WAV files are limited to 30 seconds / 10 MB and use Windows output volume. Existing game SE choices remain available. Audio failures do not cancel chat alerts; no sound files are bundled.
- Switch Fish Eyes on or off when browsing and sorting forecasts. The default is off. Details compare both forecasts when their displayed availability differs; alert scheduling continues to use the normal forecast.
- Browse availability up to 30 real days ahead, including Intuition preparation windows. Details show target and prerequisite times in an expandable calculation table. Missing Intuition durations use a clearly marked 175-second assumption.
- Open related mooch fish in a separate comparison detail view with back navigation.
- Read countdowns longer than a day as days:hours:minutes:seconds.

## Reliability and maintenance

- Validate embedded fishing data and isolate incomplete or incompatible records.
- Replan alerts after clock changes or long observation gaps, and rotate planning work across large favorite lists.
- Reuse unchanged forecasts, inventory counts, and alert-list snapshots; avoid unrelated list recalculation when an alert reservation is saved.
- Improve development-path configuration and build compatibility checks without weakening KR native runtime guards.

Supported environment remains Korean client **2026.10.06.0000.0000 / Dalamud API 15** with the inspected KR runtime profiles. Global game runtimes are not verified. Forecasts model time/weather and preparation opportunities; they do not establish the character's active Intuition buff or guarantee a catch. Incomplete data remains marked as unverified.

Update through your existing custom repository URL. Existing settings and character records are preserved; custom WAV paths are local to each PC. This version writes settings schema 12; older plugin versions do not support that schema.
