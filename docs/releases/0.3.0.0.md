# DuckbillFisher 0.3.0.0

**Let Duckbill guide your next catch.**

## New

- Open a persistent bait preparation view for favorites or the full filtered fish list. See first baits, inventory counts, and their target fish; fish with unverified first-bait data appear separately.
- Find an owned bait from fish details. A marker points to its page in the game's bait UI, followed by a prominent, gently animated outline around the bait. Change pages and select the bait manually. Highlight colors follow the game UI with contrasting outlines.

## Also included since 0.2.6.0

- More reliable fishing-record saves, reloads, ordering, and deletion handling.
- Record the observed stored live bait used for a cast.
- Expand regular fish details from 903 to 1,258 entries and fill supported missing fields. Incomplete conditions remain unverified; ocean-fishing and spearfishing gaps remain.

Korean client **2026.10.06.0000.0000 / Dalamud API 15** and the existing inspected KR runtime profiles remain the supported environment. New bait guidance does not automate bait changes or fishing. Inventory counts cover normal inventory only; unread counts remain unknown. Preparation can list the same fish under multiple baits.

Update through Dalamud using your existing custom repository URL. No source build or launcher file changes are required.
