# DuckbillFisher 0.3.11.0

- Adjust the plugin UI scale from 80% to 200%, with a reset to 100%. The setting is preserved across reloads.
- Show favorites only in the compact list with an independent star toggle. Other filters follow the main catalog.
- Open the selected fish in a separate view using the button beside its grade and collection status.
- See collection status more clearly with colored badges in fishing-spot lists.
- New casts clear the previous fishing spot. Undiscovered spots are labeled, and the name and fish list update when discovery and your catch are confirmed.
- Click View fish again to close the fishing-spot list.

Korean and English UI. Verified Korean client/Dalamud support remains unchanged. Does not automate fishing.
