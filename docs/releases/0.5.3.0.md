# 0.5.3.0

- Choose individual built-in sound effects or custom WAV files for bites, big fish and legendary fish. Bite sounds play once when a bite is observed; trophy fish sounds play when the fish is identified.
- Play big and legendary fish sounds only on first fish guide registration by default. Disable first acquisition only to play on every confirmed catch, including fish already collected. Manual collection marks do not determine first registration. All three sound choices start with no sound selected.
- Keep the fishing-spot list's all fish / hide caught filter after closing the list or restarting the plugin or game.
- Use separate cast alert and fishing sound tabs in timer settings. Icons, short bullet explanations and grouped controls make settings easier to scan. Common output settings stay at the upper right while each tab's content scrolls independently.

Custom sounds use local WAV files up to 10 MB / 30 seconds and follow Windows volume. Choose, preview, reload or stop each sound individually. Cast-time alert presets retain their existing scope.

Settings use schema 21. Existing favorites, manual collection choices, filters, cast alerts, presets and fishing history are preserved. No fishing actions are automated and no runtime network synchronization is added. Verified runtime support remains limited to the supported Korean client and Dalamud module combinations.
