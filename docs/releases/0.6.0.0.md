# 0.6.0.0 — Big-fish recommendations

Choose your next big-fish target in the new **Recommendations** tab.

- **Fish to target now** shows fish available now or within 30 minutes.
- **Prep work** brings together mooch and Intuition requirements with prerequisite schedules.
- **Least frequent** orders candidates by their appearances over 30 days and shows the next appearance.
- Set a search range and filters, then refresh the list when you want updated recommendations.

Other changes:

- Get local chat alerts when uncaught big or legendary fish appear at your current fishing hole.
- Set spawn alerts for the start of an appearance or up to 120 minutes beforehand.
- Open fish details from spawn alerts and see the time remaining.
- Refresh collection status with the Fish Guide shortcut available across all main tabs.
