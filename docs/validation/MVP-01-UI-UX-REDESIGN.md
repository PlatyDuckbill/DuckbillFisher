# 0.1.27.0 UI/UX 개편과 간략 창

갱신: 2026-10-17 · 별도/정규 빌드 완료 · 인게임 검증 대기

## 사용자 합의와 범위

- 0.1.26.0은 사용자 대표 확인을 통과했다. 이번 작업 중 큰 화면 구조는 먼저 질문하도록 지침을 추가했고, 사용자는 이후 최대 세 창 구성을 명시적으로 승인했다.
- 메인: 어종 목록/즐겨찾기 관리/설정. 어종 클릭은 같은 창 오른쪽 패널을 갱신한다.
- 간략: 즐겨찾기 기본, 현재 출현 중과 30분 이내 예정 표시. 전체 어종으로 전환하거나 예정 범위를 1~180분으로 변경 가능하다. 메인 필터/수집 숨김/알림 대상과 독립이다.
- 독립 상세: 간략 창에서 클릭한 어종만 표시한다. 인스턴스 하나를 재사용하며 메인 창을 열지 않는다. 각 창의 닫기는 다른 창의 정보 요청이 아니다.
- 메인 `간략 창 열기` 또는 `/duckbillfisher compact`로 간략 창을 연다. 간략 창의 목록 아이콘으로 메인을 열 수 있다. 새 명령은 플러그인 창 토글만 수행한다.

## 현재 코드에서 발견한 문제와 대응

| 문제 | 구현한 대응 |
|---|---|
| 진단 탭이 즐겨찾기보다 먼저 노출, 언어/도움말이 항상 목록 공간 사용 | 메인 탭 순서를 목록/즐겨찾기/설정으로 변경. 언어/개발자 옵션/알림 설정/출처는 설정 탭으로 이동 |
| 상단 접는 영역이 길어져 목록 높이 감소 | 검색/정렬/수집/초기화는 상단 유지, 추가 필터는 팝업. 진단도 개발자 모드의 팝업으로 제공 |
| 숨겨진 진단 필터가 계속 적용될 가능성 | 개발자 모드 해제 시 확인 불가 행/상세 조건만 체크를 해제. 일반 필터는 유지 |
| 도감 안내가 일반 설명과 구분되지 않음 | 경고 아이콘·배경·동작 안내를 함께 표시. 기존 세션의 GuideState.Complete 뒤 사라짐 |
| 미끼/날씨/시간 문장 반복 | 공통 행에 게임 아이콘·시계·짧은 시작/종료 시간을 표시. 상세 이름과 의미는 툴팁/정보 아이콘에 제공 |
| 수집 버튼 3개와 자동/수동 결과 중복 | 현재 상태를 보여주는 메뉴 하나 + 수동일 때만 복귀 버튼. 자동 접미사는 제거하고 수동 접미사는 유지 |
| 즐겨찾기를 색상만으로 구분 | 빈 별/채운 별을 직접 그려 상태를 구분. 버튼 설명은 툴팁 |
| 상세 정보와 버튼 정렬 불일치 | 공통 FishDetailPanel: 제목/동작 → 출현 → 낚시터 → 조건. 조건은 이름/값 2열. 지도는 위치 옆 아이콘 |
| 즐겨찾기의 어종 클릭은 강조만 변경 | 같은 메인 창의 오른쪽 상세 패널에 연결. 개별 사전 분과 삭제는 행에서 유지 |
| 좁은 화면에서 긴 텍스트 넘침 | 행 폭 클리핑+툴팁, 조건 값 줄바꿈, 메인 최소 700×450/간략 300×260/상세 320×300. 실제 배율별 결과는 대기 |

조사 출처와 적용 이유는 [개편 문서](../UI-UX-REDESIGN.md)의 근거 구역을 따른다. NN/g, Microsoft Fluent, W3C, Fish Tracker의 실제 문서를 조회했으며 외부 코드/에셋을 도입하지 않았다. 웹 원칙을 적용한 설계 판단이며 접근성 인증이나 인게임 시각 검증을 뜻하지 않는다.

## 구현 경계와 수명

- `FishRowRenderer`는 기존 목록/즐겨찾기 및 새 간략 창에 사용한다. 미끼 단계는 화살표, 같은 단계 대안은 괄호와 `/`, 직전→현재 날씨는 화살표와 툴팁으로 구분한다. 상세는 이전/현재를 별도 행으로 표시한다.
- 게임 아이콘은 기존 ITextureProvider를 사용하고 소유권을 가져오지 않는다. 실패하면 `?`와 이름 툴팁을 제공한다. 일반 상태 아이콘은 설치 Dalamud의 FontAwesome 및 별 도형을 사용한다.
- `FishDetailPanel`은 캐시된 데이터와 기존 preferences/지도/아이템 링크 요청만 사용한다. 자동 수집과 수동 우선순위·Unknown 구분은 그대로다. 상세 창은 세션 변경 시 선택을 비운다.
- `CompactFishObserver`는 창이 열려 있을 때 Framework에서 단조 시계 기준 1초 간격으로 기존 예측을 필터링한다. Draw에서 전체 검색/파일 읽기/장기 예측을 하지 않는다. 닫을 때 갱신 중지, 재개 때 오래된 표본 초기화, Dispose에서 이벤트 해제.
- 간략 정렬은 열린 창 종료순 → 예정 시작순, 동률 이름/ID. 상시/먼바다/예측 미확인 제외. 데이터 로딩/실패 상태와 빈 결과를 구분한다. 예측 경계의 화면 갱신 지연은 약 1초다.
- 설정 schema v9는 v1~v8을 허용한다. 언어·개발자 모드(기본 꺼짐)·간략 대상/분을 기존 Framework 저장 큐로 병합한다. 기존 v8의 자동 해제 꺼짐 선택을 덮어쓰지 않는다. 저장 실패 시 기존 snapshot/오류를 유지한다.
- preferences/v7에 InterfaceLanguage/DeveloperMode/CompactFavoritesOnly/CompactUpcomingMinutes를 추가했다. summary/v5, collection/v2, alerts/v6는 그대로다. 진단용 체크는 저장하지 않는다.
- UI 리소스 428키(한영). 창/탭/입력은 번역과 분리한 고정 ID. Core·예측 공식·네이티브 조회·등록 계약·알림 예약/전송은 수정하지 않았다. 런타임 HTTP 없음.

## 인게임 대표 확인 순서

1. 같은 개발 DLL 경로로 0.1.27.0 로드. 기본 탭이 목록/즐겨찾기/설정인지, 도감 조회 전 배너와 조회 완료 뒤 해제를 확인한다.
2. 목록 어종 선택 → 오른쪽 상세. 빈 별/채운 별, 수집 메뉴/수동 복귀, 아이템 링크/지도 핀과 미끼·날씨 툴팁 확인. 기존 필터/즐겨찾기/사전 분이 유지되는지 확인한다.
3. `간략 창 열기` → 메인 닫기 → 간략 어종 클릭. 독립 상세 하나가 열리고 다른 어종 클릭 시 내용만 바뀌는지 확인한다. 세 창을 동시에 열고 각각 닫아 본다.
4. 간략 창에 결과가 없으면 즐겨찾기 체크를 해제하거나 범위를 늘린다. 열린 창 종료순/예정 시작순과 메인 필터 독립, 재오픈 갱신을 확인한다.
5. 설정에서 English/한국어 전환과 개발자 모드 켜기/끄기. 창 선택/스크롤/수집 기록 보존, 껐을 때 진단 탭/체크 숨김 확인. 최소 크기와 평소 글자 배율에서 잘림 확인.

정상 여부와 문제가 있는 화면만 우선 받는다. 로그가 필요하면 개발자 도구를 켜고 목록의 짧은 진단을 받으며 전체 로그는 기본 요청하지 않는다.
