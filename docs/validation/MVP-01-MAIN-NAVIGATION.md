# 메인 탐색 줄과 간이 목록 명칭

2026-10-17 · Plugin0.2.4.0 정규 반영/변경 배치 사용자 대표 확인 완료.

## 사용자 확인과 결정

- 0.2.3.0의 생미끼/실패 기록·빈 어획 아이콘은 사용자 ‘나머진 정상 동작’으로 대표 확인을 받았다. 모든 실패 유형/보관 생미끼/저장·재로드 확인으로 확대하지 않는다.
- 실제 사진에서 메인 우측 바로가기가 탭보다 한 줄 위에 배치된 점을 확인했다. 사용자는 탭과 같은 줄을 요청했다.
- 이름 후보를 먼저 질문했고 사용자가 ‘간이 목록’을 선택했다. 화면 제목/메인 버튼/설정 툴팁/명령 도움말을 ‘간이 목록’, 영어를 ‘Quick list’로 통일했다. `/duckbillfisher compact`와 내부 클래스/고정 ID는 그대로다.
- 사용자가 이번 변경 전에 직접 ‘언로드 완료했으니 빌드까지’ 요청했다. 이 확인을0.2.4.0 정규 반영에 사용했으며 다음 교체에는 새 확인이 필요하다.

## 구현

- 메인 탐색 줄은 좌측 탭 영역과 우측 간이 목록/캐스팅 타이머 버튼으로 구성한다. 현재 폰트/번역 이름/프레임 여백으로 버튼 폭을 측정하여 같은 줄에 미리 확보한다.
- 공개 ImGui API의 별도 작은 헤더 컨테이너에 탭만 그려 폭을 제한하고, 선택 페이지 본문은 그 아래 부모 영역에 그린다. 내부 ImGui 구조를 직접 수정하지 않는다.
- 폭이 좁거나 개발자 탭이 많으면 좌측 탭만 FittingPolicyScroll로 스크롤한다. 우측 버튼은 같은 줄에 유지한다. 설정 화면 직접 열기/개발자 탭 숨김/언어 변경은 기존 정책을 유지하고 페이지 ID는 번역과 분리한다.
- 간이 목록 열기/캐스팅 타이머 토글 동작은 유지한다. 생미끼/실패 판정/기록 보관/필터/알림/네이티브 접근을 바꾸지 않았다.

## 실행한 검사

- 직접 별도 출력 `dotnet build --no-restore -c Debug` 후 이미 받은 언로드 확인으로 정규 빌드: 각각 경고0/오류0. 한영555키/형식 인자 검사 통과. 테스트는 추가하거나 실행하지 않았다.
- 정규 Plugin1,167,360바이트/0.2.4.0, Core56,320바이트/1.0.0.0, ko52,736바이트/0.2.4.0. manifest DuckbillFisher/0.2.4.0/API15 확인. 네 출력 파일 모두 별도/정규 SHA256 일치.
- `git diff --check`와 변경 문서/코드의 비의도 문자 검사 통과. 푸시/릴리스 없음. 빌드는 실제 화면 배치 검증을 대신하지 않는다.

## 사용자 결과와 남은 확인

- 사용자 ‘확인 완료’로0.2.4.0 같은 줄 배치/간이 목록 명칭/바로가기의 대표 확인을 받았다. 전체 화면 크기·언어·설정 진입 조합까지 확인했다고 확대하지 않는다.
- 개발자 도구 켜기/끄기, 폭 축소, 한국어/English 조합의 겹침·탭 스크롤·설정 직접 열기와 명령 도움말은 확장 확인 대상으로 남긴다.
- 결과 기록만 갱신했으며 소스/버전/정규 DLL은 변경하지 않았다. 빌드·리소스 검사·테스트를 재실행하지 않았다.
