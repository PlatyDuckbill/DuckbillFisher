# 0.1.34.0 실제 화면 피드백 반영

갱신: 2026-10-17 · 정규 빌드 완료 · 인게임 확인 대기

사용자는 도감 열기 버튼 정규 반영 전에 [사진 개선 제안](../UI-UX-REDESIGN.md#사진-기반-개선-근거) 1~7번도 함께 진행하도록 승인했고 언로드 완료를 확인했다. 별도 빌드 후 이 작업에 대한 확인으로 정규 DLL을 교체했다. 새 화면 구조나 자동화는 도입하지 않았다.

## 구현

1. 미끼 경로는 상세의 전체 폭을 사용한다. 단계는 화살표, 같은 단계 대체 미끼는 /로 구분하고 폭이 부족하면 다음 묶음을 줄바꿈한다. 중간 어종 이름 옆에 낚아채기/입질, 공간이 되면 ET를 표시한다. 생략된 조건은 바로 옆 툴팁으로 제공한다. 아이템 링크 동작은 유지한다.
2. 날씨는 한 행에 직전 후보 / 후보 → 현재 후보 / 후보로 표시한다. 직전 제약이 없으면 현재 조건만 표시한다. 각 아이콘의 역할과 OR/전환 의미는 툴팁에 유지한다. 좁으면 묶음 단위로 줄바꿈한다.
3. 수집 선택은 어종 이름 바로 아래를 유지하고 현재 상태 문구/화살표에 필요한 폭만 사용한다. 수동 지정 시 복귀 버튼 공간을 예약한다.
4. 목록의 정보 아이콘은 내용이 잘리거나 다른 지역 예측 안내가 필요할 때 표시한다. 노출된 아이콘/문자는 자체 툴팁을 유지한다. 전승록/갈고리/루어도 토큰으로 표현해 정보 아이콘 제거로 요구 조건이 사라지지 않게 했다. 중간 어종 조건의 정보 버튼도 인접 배치하며 추가 정보가 있을 때만 표시한다.
5. 메인 상단은 검색 → 정렬/수집/필터/기본값 복원 → 결과 수/이동의 구조다. 반복 제목 줄을 제거하고 복원은 툴팁 있는 아이콘으로 상시 노출한다. 부족한 폭에서는 컨트롤 묶음이 줄바꿈한다. 간략 열기는 탭 바 우측 아이콘으로 옮겨 독립된 한 줄을 줄였다.
6. 세 화면의 배경 불투명도는 공통 0.94로 설정하고 기존 테마 색을 유지한다. 출현 중 행의 녹색 배경은 약하게 하고 왼쪽 표시선/남은 시간 강조를 병행한다. 상세 출현 배경도 채도를 낮췄다. 상태 문구는 유지한다.
7. 넓은 목록의 3줄 배치 기준을 폰트 36배에서 28배로 조정했다. 미끼는 실제 필요한 폭을 기준으로 최대 55%를 쓰고 조건을 옆에 배치한다. 좁은 메인 목록은 4줄, 좁은 간략 목록은 기존 3줄을 유지한다. 높이 산식은 렌더링/클리퍼/예정 이동에서 공유한다.

0.1.33.0의 [어류도감 열기 버튼](MVP-01-GUIDE-OPEN.md)도 정규 0.1.34.0에 포함한다. 수집/수동 우선/필터 저장/예측 공식/알림 정책/원본 자료/게임 접근 계약은 이번 디자인 변경에서 바꾸지 않았다. 사진의 종료 1초 표본은 오류로 확정하지 않았으며 별도 재현이나 계산 변경을 수행하지 않았다.
