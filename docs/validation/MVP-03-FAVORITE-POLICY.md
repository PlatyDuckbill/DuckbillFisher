# MVP-03 즐겨찾기 관리·알림 대상과 목록 기본값

날짜: 2026-10-16 · Plugin 0.1.23.0 · 인게임 검증 대기

## 사용자 결정과 구현

- 탭 이름은 `즐겨찾기 관리 / Favorites management`로 변경했다. 기존 TabAlerts 리소스 키와 고정 ImGui ID는 유지한다. 아이콘/5줄 요약·개별 시간·전체 81개 로컬 채널·SE·아이템/지도 링크·한 줄 발송 기록은 보존한다.
- 알림 대상은 기본 `AllFavorites`다. 수집됨/미확인도 수집 여부를 이유로 제외하지 않는다. 미확인을 미수집으로 재분류하지 않으며, 캐릭터 준비·호환되는 시간/날씨 예측·미래 제한 창은 여전히 필요하다. 상시/먼바다/미지원 조건에 임의 창을 만들지 않는다.
- `미수집 어종만 알림` 체크는 `UncaughtOnly`를 적용한다. 기존 최종 판정/수동 우선/Unknown 제외를 사용한다. Core의 동일한 typed 정책을 후보 구성·시간 통과·제외 이유에 적용한다. 대상 변경으로 이미 지난 알림을 소급하지 않는다.
- `새 어종 도감 등록 시 즐겨찾기 자동 해제`는 기본 꺼짐이며 알림 활성화와 별개다. 공통 즐겨찾기에 적용하고 개별 시간/수동 기록/발송 이력/영속 중복 기록은 지우지 않는다.
- 자동 해제는 기존 KR LogMessage 1114의 계약·숫자 Item→어종 매핑·호환성·현재 세션·5초 이내 표본 확인 뒤에만 호출한다. 이벤트 수신 당시 옵션을 켰는지와 처리 시점의 옵션/세션을 모두 확인한다. 옵션을 켜기 전 대기 중이던 등록 이벤트를 소급 적용하지 않는다.
- 도감 조회/초기 전체 수집 집합/수동 수집 지정/과거 어종 재어획으로 자동 해제하지 않는다. 반복 어획 감지를 새로 구현했다고 표현하지 않는다. 새 등록 직후 Framework에서 즐겨찾기 삭제를 저장/게시하여 이후 알림 판정이 삭제된 집합을 읽게 한다. 저장 실패는 기존 즐겨찾기를 유지하고 기존 오류 안내를 표시한다.
- 각 즐겨찾기 행에 삭제 버튼을 추가했다. 성공한 저장 뒤 목록에서 제외하고 미래 예약도 취소한다. UI는 설정 revision과 현재 즐겨찾기 집합을 확인하여 다음 1초 서비스 표본까지 삭제된 행이 남지 않도록 한다. 다른 행/스크롤을 초기화하지 않는다.
- 목록 시작 기본값: 남은 시간순(Sort=2), 먼바다 제외, 시간제만 켬, 등급 전체, 수집한 어종 숨기기. 수첩 포함은 기존처럼 켬이며 지역/확장팩 제한과 즐겨찾기만은 꺼짐이다. 기본 숨김은 Unknown을 유지한다. 목록 표시 필터는 즐겨찾기 알림 대상과 별개다.
- 확인 불가 행 표시와 상세 조건 있는 어종만 체크는 기존 `상세 진단` 접힘 영역 안으로 이동했다. 기본은 둘 다 꺼짐이며 접어도 선택한 값은 유지한다. 목록 선택은 기존 세션 메모리 방식으로 유지하고, 재로드하면 새 기본값으로 시작한다.
- 설정 schema v5는 v1~v4의 기존 저장을 보존한다. 새 대상은 전체, 자동 해제는 꺼짐으로 시작하며 이후 사용자 선택을 저장한다. 예측 공식/SDK/데이터/네이티브 게이트는 변경하지 않았다. 알림 진단은 `alerts/v4`에 Audience/RemoveOnRegistration을 추가한다.

## 첫 인게임 확인

1. 재로드 직후 목록의 새 기본값과 상세 진단 안의 두 체크를 확인한다. 즐겨찾기 관리의 기본은 미수집만 해제/자동 해제 꺼짐이어야 한다.
2. 전체 알림에서 수집됨 또는 미확인 즐겨찾기에 미래 예약이 생기고, 미수집만을 켜면 해당 어종은 제외되는지 확인한다. 수동 상태가 바뀌거나 Unknown이 미수집으로 표시되어서는 안 된다.
3. 즐겨찾기 관리에서 한 행 삭제 후 목록/예약에서 제외되는지 확인한다. 다시 추가하면 개별 시간은 복원되고 기존 발송 기록은 유지되어야 한다.
4. 자동 해제는 도감 열기/수동 상태 변경으로 발동하지 않아야 한다. 켠 뒤 다음 실제 새 어종 도감 등록에서 즐겨찾기가 해제되는지 확인한다. 신규 어종 확인은 자연스럽게 다음 등록 때 진행해도 되며 반복 어획 검증으로 대신하지 않는다.

문제 시 해당 화면과 즐겨찾기 관리의 짧은 알림 진단만 받는다. 전체 로그/Teamcraft 자료/이미 통과한 수집 판정 검사를 반복 요청하지 않는다.
