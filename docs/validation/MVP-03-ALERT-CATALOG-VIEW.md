# MVP-03 즐겨찾기 뷰·아이템 링크·전체 채널·한 줄 기록

날짜: 2026-10-16 · Plugin 0.1.22.0 · 인게임 검증 대기

## 피드백과 구현

- 0.1.21.0은 사용자 ‘기능은 정상 작동함’으로 대표 동작 확인을 받았다. 모든 채널·시간 경계·절전 조합 확인으로 확대하지 않는다.
- 즐겨찾기 기본 뷰를 기존 어종 목록과 동일하게 제공한다. 아이콘/등급/어종명, 수집 상태·낚시터, 출현/종료까지 남은 시간, 미끼 경로, 조건 요약과 열린 제한 창의 녹색 배경을 표시한다. 개별 시간 설정과 알림 제외 이유도 유지한다. 다음 알림 시각은 제외 이유/상태에 마우스를 올려 확인한다.
- `FishRowRenderer`를 두 화면이 공유하여 행 표시·긴 줄 툴팁·수집 문구·카운트다운·배경 판정이 따로 바뀌지 않게 한다. 이 추출은 요청한 동일 뷰를 제공하기 위한 범위다. 원본 목록의 검색/필터/선택/정렬과 스크롤 보존 정책은 유지한다.
- 즐겨찾기 snapshot은 관리 Row/현재 카탈로그 창을 참조한다. 알림 예약의 다음 창과 구분하며, 현재 열린 창의 남은 시간도 표시한다. 화면에 보이는 행만 렌더링하고 언어/행 참조가 바뀌면 요약 캐시만 갱신한다. Draw에서 시트/파일/날씨 장기 예측을 읽거나 계산하지 않는다.
- 채팅의 어종명은 캐시한 실제 Item ID의 `SeString.CreateItemLink`로 출력한다. 기존 미끼 링크와 같은 공개 API다. 일반 아이템 링크를 클릭하면 해당 어종의 아이템 정보를 연다. 메시지 순서는 아이템 링크/다국어 남은 시간/기존 지도 위치 링크다.
- 채널은 설치된 Dalamud `XivChatType`의 전체 정의 81개를 제공한다. 채널 없음(None=0)만 제외하며 임의 ID는 허용하지 않는다. 링크셸 1~8/CWLS1~8/일반·귓속말·파티·자유부대·시스템·전투/기타 정의 채널을 포함한다. 각 선택은 본인에게 표시되는 유형이며 서버 송신을 하지 않는다. 실제 표시 여부는 게임 채팅 필터와 채널 렌더링에 따른다.
- 81개 채널 이름은 한영 resx 키로 제공하며 숫자 값을 복사한 별도 목록 대신 SDK enum을 사용한다. 향후 미지원 정의의 이름은 기본 리소스 fallback으로 표시한다. 채널 이름은 플러그인 UI 번역이며 게임 시트의 공식 채널 이름을 읽었다고 표현하지 않는다.
- 설정 schema v4는 v1~v3의 즐겨찾기/수동 상태/개별 시간/SE/창별 중복 기록을 보존한다. 이전 세 값의 채널 enum을 실제 XivChatType ID로 변환해 시스템/일반/CWLS1 선택을 유지한다. 과거 필드는 역직렬화 migration에만 쓰며 현재 설정은 채널 ID 한 곳을 사용한다.
- 발송 기록은 `HH:mm:ss · 어종명 · 당시 남은 시간 · 채널 · SE` 한 줄이다. 지도 버튼/위치 표시/추가 상세 줄/구분선을 제거했다. 긴 줄은 마우스를 올려 전체 내용을 본다. 캐릭터 세션 최근 200건/최신순/로그아웃·재로드 초기화는 유지한다. 알림 메시지의 지도 링크와 일반 상세 지도 버튼은 유지한다.
- 짧은 알림 진단은 `alerts/v3`이다. 실제 enum 채널 코드/전체 선택 수를 기록한다. 자동 수집·알림 대상/기존 시간·날씨 공식/SE 네이티브 게이트는 변경하지 않았다. Teamcraft 후속 조사도 재개하지 않았다.

## 첫 인게임 확인

1. 즐겨찾기 탭에 기존 목록과 같은 아이콘/남은 시간/미끼·조건 요약이 보이고 개별 시간 설정도 유지되는지 확인한다. 기존 목록의 행 선택/스크롤도 대표 확인한다.
2. 기존 표시 채널/개별 시간/SE 선택 복원과 전체 채널 목록(예: CWLS8/파티)을 확인한다. 알림 한 번의 어종명 클릭으로 실제 아이템 정보가 열리는지 확인한다. 다른 플레이어에게 전송되지 않는 로컬 표시다.
3. 발송 기록이 지도 버튼 없이 한 줄로 보이는지, 언어를 바꿔도 기록/개별 시간이 유지되는지 확인한다. 메시지의 위치 링크는 계속 사용할 수 있어야 한다.

문제 시 해당 화면과 짧은 알림 진단만 받는다. 전체 로그/Teamcraft 자료와 과거 통과한 수집 검사를 반복 요청하지 않는다.
