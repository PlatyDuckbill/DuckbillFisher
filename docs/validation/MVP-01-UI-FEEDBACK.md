# 0.1.28.0 UI 피드백 반영

갱신: 2026-10-17 · 별도 빌드/리소스 검사 통과 · 정규 교체 및 인게임 확인 대기

## 사용자 결정과 변경

- 세 창 구조는 유지한다. 사용자에게 필터 공유 범위를 질문했고, `메인 필터 전체 공유, 검색어·예정 범위는 별도`를 선택했다. 0.1.27.0의 독립 즐겨찾기 필터 정책을 대체한다.
- 메인과 간략은 `CatalogFilter`로 수집·지역·확장팩·현재 지역·등급·시간제·즐겨찾기·도감 포함 조건을 공유한다. 수동 우선/Unknown 구분은 기존 CollectionFilter를 사용한다. 간략은 기존처럼 열린 창→예정 창 순서이며 상시/예측 미확인/먼바다는 제외한다. 메인의 검색어·진단 체크·정렬 선택은 공유하지 않는다.
- 간략 창의 독립 즐겨찾기 체크를 제거하고 `메인 필터 적용`을 표시한다. 메인 필터를 공유한다는 툴팁과 기존 예정 분 설정을 제공한다. 표시 낚시터도 선택 지역에 맞추고, 외부 지역 예측 안내를 유지한다.
- 간략 창의 메인 열기 버튼을 실제 메인 Toggle에 연결했다. 새 창 생성이나 다른 창 닫기는 수행하지 않는다.
- 공통 목록 행은 폭이 글자 크기 36배 이상이면 3줄 가로 배치, 그보다 좁으면 기존 세로 배치(메인 5줄/간략 4줄)를 쓴다. 메인/즐겨찾기/간략의 클리퍼가 같은 높이 계산을 사용한다.
- 메인/간략에 `출현 예정으로 ↓`와 `맨 위로 ↑` 버튼을 추가했다. 메인은 현재 정렬에서 첫 예정 어종으로, 간략은 예정 섹션으로 스크롤한다. 예정 대상이 없으면 이동을 비활성화한다.
- 목록 직감 텍스트는 실제 직감 상태 아이콘으로 바꿨다. 물고기의 눈 지원 어종도 아이콘을 표시한다. 이는 지원/요구 조건이며 현재 버프 상태를 자동으로 관찰한 표시가 아니다.
- 상세 상단에 물고기의 눈 지원 여부, 출현 표시 아래에 접지 않은 보라색 직감 영역(대상·수량·지속 시간)을 둔다.
- 상세의 `시간·날씨 기준 · 개인 준비 조건 별도` 문장을 제거했다. 출현 중은 녹색 배경과 `출현 중`, 남은 시간으로 표시한다. 시각은 `오늘 13:06 – 13:29`, 날짜가 바뀌면 `오늘 23:50 → 내일 00:15` 형식이다. 전체 현지 날짜는 툴팁으로 확인한다. 예측 공식/지원 범위는 바꾸지 않았다.
- 생미끼의 전체 상세를 재귀적으로 펼치던 부분을 없앴다. 각 미끼/직감 대상에 연결된 자료가 있으면 낚아채기·입질·필요한 ET/날씨/기술만 짧게 표시한다. 중간 미끼 자료가 없으면 `낚아채기 정보 미확인`을 유지한다. 대상 어종 조건을 중간 미끼에 복사하지 않는다.
- 중복 `추가 정보`/추천 낚시터를 제거했다. 기존 낚시터 목록·지도 기능은 유지하며 조건 하단에는 `Patch 3.0` 형태로 출처 패치만 표시한다. 전승록 요구는 유지한다.
- 추가 피드백으로 즐겨찾기 관리의 공통 행 요약 별을 제거하고 N분 전 옆 삭제 별 버튼만 유지했다. 메인/간략의 즐겨찾기 표시와 별도 상세의 상태 변경 버튼은 유지한다.
- 한국어 리소스에서 `창`을 모두 제거했다. 시간은 출현/종료, UI는 화면, 채팅 영역은 채팅으로 표현하며 AGENTS에 용어 규칙을 추가했다. 게임 데이터의 고유 이름은 바꾸지 않는다.

## 데이터/API 근거와 유지보수

- 설치 KR 빌드 2026.10.06.0000.0000의 시트를 개발 중 읽기 전용으로 조사했다. Status 568 = 어부의 직감/Icon 211101, Action 4105 = 물고기의 눈/Icon 1112/어부 Job 18/플레이어 스킬을 확인했다. 작살꾼의 직감 Status 2891은 이번 표시에 사용하지 않는다.
- 캐시된 FishingDetailView에 Intuition/FishEyes 표시 참조를 추가한다. 기존 빌드 대조와 Action 스킬 검증을 통과한 데이터만 사용하며, 게임 시트 접근은 FishCatalog 로딩에서 수행한다. 렌더링 시 시트/파일 읽기를 추가하지 않는다.
- 기존 고정 외부 원본과 라이선스는 변경하지 않았다. 새 외부 코드/데이터/의존성 없음. 중간 미끼 정보는 현재 RelatedDetails에 있는 범위만 제공하므로 모든 경로의 낚아채기 정보가 채워진 것은 아니다.
- schema v10은 v1~v9를 읽는다. v9의 간략 예정 분은 보존하고 독립 FavoritesOnly 속성은 사용하지 않는다. 기존 메인 필터/즐겨찾기/수동 기록/자동 해제 선택/알림 설정을 유지한다.
- preferences/v8에 `CompactFilters=SharedCatalog`를 기록하며 CompactFavoritesOnly는 메인 값을 표시한다. summary/v5/collection/v2/alerts/v6는 유지한다.
- 예측 날짜/표시 책임은 FishingWindowPanel로 분리했다. 자동 수집 판정·네이티브 메모리 조회·등록 계약·예약·알림 출력·실제 기술 적용은 변경하지 않는다. 원격 통신/서버 송신 없음.

## 인게임 확인 순서

1. 도감을 조회한 뒤 메인에서 수집 숨김/지역/등급/즐겨찾기를 바꾸고 간략에도 같은 조건이 적용되는지 확인한다. 간략 갱신 지연은 약 1초이며 예정 범위 밖 대상과 상시 어종은 나오지 않는다.
2. 간략에서 메인 버튼을 두 번 눌러 메인이 열림→닫힘인지 확인한다. 상세/간략은 계속 유지되어야 한다.
3. 메인과 간략에서 예정 이동/맨 위 이동, 가로 폭을 바꿀 때 행 높이/스크롤/클릭 어종이 맞는지 확인한다.
4. 직감 대상 어종의 목록 아이콘과 상세 강조 영역, 상단 물고기의 눈, 오늘/내일 시간 범위를 확인한다.
5. 생미끼 경로에서 아이템 링크/낚아채기 표시/미확인 대체를 확인한다. 중복 추가 정보와 반복 추천 낚시터·설명 문장이 없어야 한다.

정상 여부와 문제 화면을 우선 받는다. 필요한 경우에만 개발자 옵션의 짧은 진단을 받으며 전체 반복 로그는 기본으로 요청하지 않는다.
