# MVP-03 알림 채널과 시간 표시 간소화

날짜: 2026-10-16 · 소스 수정 · 빌드/인게임 검증 대기

## 결정과 변경

- 사용자 요청으로 로컬 표시 채널을 81개에서 22개로 줄인다: 시스템, 자신에게 말하기, 일반, 파티, 연합, 자유부대, LS 1~8, CWLS 1~8. 전투/오류/운영자/제작 등의 채널은 선택 목록에서 제외한다. 서버로 전송하지 않는다.
- 기존 설정의 알려진 채널 ID는 계속 읽는다. 제외된 채널은 시스템으로 대체하고 즐겨찾기/캐릭터 기록/개별 시간/영속 중복 기록은 보존한다. 기존 발송 기록의 채널 이름을 표시할 수 있도록 번역 키는 유지한다.
- 알림 메시지와 한 줄 발송 기록의 남은 시간에서 초를 제거한다. 실제 남은 시간을 분 단위로 올림하여 발송 지연으로 5분 알림이 4분으로 보이거나 1분 미만이 0분으로 보이지 않게 한다. 1시간 이상은 시간/분으로 표시하며 한영 리소스를 사용한다.
- 목록/상세의 실시간 카운트다운, 사전 분 설정, 예약 시점, 예측 공식은 변경하지 않는다.

- `pwsh -NoLogo -NoProfile -File scripts/check-localization.ps1`: 한영 375키/형식 인자 일치. `git diff --check` 통과.
- 다음 빌드 후 채널 22개/제외 채널 저장값의 시스템 대체/아이템·지도 링크와 분 단위 메시지를 확인한다. 다음 구현은 선택형 Toast와 목록·즐겨찾기 UI 정리다.
