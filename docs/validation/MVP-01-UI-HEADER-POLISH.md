## 사용자 피드백 반영

- 상세 제목은 왼쪽 어류 아이콘, 오른쪽 어종 이름/Patch와 그 바로 아래 등급·즐겨찾기·수집 선택으로 구성한다. 조작 줄을 아이콘 아래 전체 폭에 두던 배치를 수정했다. 메인/독립 상세는 같은 컴포넌트를 사용한다.
- 낚시터 연결 누락 31행은 큰 배경 안내 영역 대신 작은 ‘예측 정보 없음’ 문구를 사용한다. 구체적인 누락 이유는 마우스 오버에서만 제공한다. 예측 미확인을 상시로 표시하지 않는다.
- 지도 버튼의 파랑 배경·금색 직접 그리기를 제거했다. 기존 UI 아이콘 글꼴의 지도+위치 표시(MapMarkedAlt), 평상시 투명 배경과 테마의 호버/누름 색상을 사용한다. 글자 라벨은 없다. 목록/간략/상세에 같은 버튼을 사용한다.
- 간략 상단의 ‘메인 필터 적용’ 글자를 제거했다. 한 줄 왼쪽에 출현 예정 이동/맨 위 이동, 오른쪽에 메인 화면 토글/간략 설정을 둔다. 맨 위 이동은 화살표 아이콘이며 기존 문구를 툴팁으로 유지한다. 필터 공유 설명은 설정 팝업에 유지한다.
- 시간·날씨 계산, 수집·수동 우선, 필터 저장, 알림 정책, 게임 접근, 원본 데이터는 변경하지 않았다.

## 인게임 확인 순서

1. 메인/독립 상세에서 등급·별·수집 선택이 어종 이름 바로 아래, 어류 아이콘 오른쪽에 있는지 확인한다. Patch는 우측을 유지한다.
2. 멜토르 망둥이 등 자료의 위치 연결이 없는 어종에서 큰 경고 배경 없이 ‘예측 정보 없음’만 보이고, 마우스 오버로 원인을 확인할 수 있어야 한다.
3. 목록/간략/상세의 지도 아이콘에 글자나 색상 배경이 없고, 호버/클릭 시 테마 강조와 기존 지도 표시가 동작해야 한다.
4. 간략 상단은 좁은 기본 폭과 넓은 폭에서 모두 한 줄이어야 한다. 예정/맨 위 이동, 메인 토글, 설정 팝업 동작을 확인한다.

위 배치와 상호작용은 인게임 검증 대기다. 설정 콜백 경고 해제 확인도 아직 대기 상태다.
