# MVP-03 알림 관리와 즐겨찾기 스크롤 수정

날짜: 2026-10-16 · Plugin 0.1.21.0 · 인게임 검증 대기

## 사용자 피드백과 변경

- 0.1.20.0은 사용자 ‘잘 동작하는듯 함’으로 알림 대표 동작 확인을 받았다. 모든 경계/재로드/절전 조합 확인으로 확대하지 않는다.
- 즐겨찾기 클릭 시 최상단 이동 원인: FishListPanel이 preferences revision 변경도 검색/필터 입력과 같은 `resetScroll`로 처리했다. 상태 갱신과 명시적인 목록 범위 변경을 구분하여 즐겨찾기/수동 상태/자동 수집/알림 기록 저장 시 스크롤을 초기화하지 않는다. 즐겨찾기 우선 정렬의 순서 변경과 결과 감소 시 스크롤 범위 조정은 정상 동작이다.
- 출현 알림의 즐겨찾기 탭은 수집됨/Unknown/상시/먼바다/자료 없는 어종도 모두 표시하고 제외 이유를 보여준다. 이름/ID 검색과 화면에 보이는 행 위주 렌더링을 사용한다. 실제 알림 대상은 기존 즐겨찾기+최종 Uncaught이며 수동 우선순위를 보존한다.
- 기본 시간과 어종별 개별 시간은 실제 1~60분이다. 개별 체크 해제는 기본값으로 복귀한다. 공통 설정으로 저장하며 즐겨찾기를 해제해도 개별 시간은 보존한다. 개별 시간 변경은 해당 어종만 다시 계획하고 다른 어종의 예약은 유지한다. 이미 지난 시각은 소급하지 않는다.
- 채널 선택: 시스템/일반 대화/CWLS1. 모두 본인 채팅창의 표시 유형이며 다른 플레이어에게 전송하지 않는다. 기본은 시스템이다. 게임의 채널별 표시 필터가 적용된다.
- 효과음은 사용자 선택에 따라 없음/게임 SE.1~16과 미리 듣기를 제공한다. 기본 없음, 묶음당 1회. 미리 듣기는 접속 중 명시적 클릭만 처리하고 초당 1회로 제한한다. `Silent=true`로 채널 기본 소리와 중복되지 않게 한다.
- 메시지는 `{어종명} {실제 남은 시간} {클릭 가능한 지도 위치 링크}`다. 한 메시지에 최대 3종을 담고 나머지 개수는 기록으로 안내한다. 예측/개인 준비의 차이는 탭 안내에 보존한다.
- 남은 시간은 발송 직전 UTC 차이의 초를 올림하여 한국어/영어 resx로 표시한다. UI 언어를 따르며 게임 이름/지도 링크 이름은 클라이언트 데이터 언어를 따른다. 미지원 번역은 영어 기본 리소스 fallback이다.
- 발송 기록 탭은 현재 캐릭터 세션 최근 200종을 최신순으로 표시한다. 시각/당시 남은 시간/선택 채널/SE 호출 여부/창 시작과 클릭 지도 버튼을 제공한다. 로그아웃·캐릭터 변경·재로드 때 비운다. 영속 중복 방지 기록과 별개다.

## 설계·API·실패 처리

- Core의 예약 키는 어종별 `(창 시작, 적용 사전 분)`이다. 다른 어종의 시간 변경으로 전체 예약을 리셋하지 않는다. 기존 시간·날씨 공식/JSON은 수정하지 않았다.
- 설정 schema v3는 v1/v2의 즐겨찾기/수동 상태/알림 활성화·기본 시간/캐릭터별 창 기록을 보존한다. 채널·SE·개별 시간은 공통이며 발송 기록 UI는 세션 메모리다. 손상/알 수 없는 schema/범위 오류는 기존 저장 보호 정책을 따른다.
- public `IChatGui.Print(XivChatEntry)`와 `SeString.CreateMapLink` 사용. 설치 Dalamud 15.0.3.6의 메타데이터에서 Say=10/CrossLinkShell1=37/SystemMessage=57, Silent 및 nice 좌표 지도 링크 오버로드를 확인했다. API enum을 사용하며 숫자 채널을 직접 넣지 않는다.
- 게임 SE는 설치된 KR FFXIVClientStructs(MVID `f13b1f1f-fd4a-441a-bdac-b3c5abb3675f`)의 `UIGlobals.PlayChatSoundEffect(uint)`를 읽기 전용 IL로 확인했다. 인자는 1~16이며 바인딩 내부에서 실제 효과음 호출로 변환한다. 새 시그니처/오프셋/스캔은 추가하지 않았다.
- `SpawnAlertOutput`에 게임 접근을 격리한다. 기존 `NativeFishCollectionReader.IsCompatible`의 정확한 KR 게임 빌드+Dalamud/Structs/Interop DLL MVID/SHA 게이트 결과를 재사용하고 Framework/접속/해결된 정적 PlaySoundEffect 주소를 확인한다. 게이트 불일치/주소 미준비면 소리만 생략한다. 네이티브 주소/포인터를 캐시하지 않으며 try/catch로 잘못된 주소를 안전하게 만든다고 가정하지 않는다.
- 채팅 저장 예약 성공 후 출력 정책을 유지한다. 효과음의 관리 API 예외는 이미 큐에 넣은 채팅의 발송 기록을 취소하지 않는다. SE 호출 성공과 실제 청취/게임 음량은 구분한다. 저장이 10초 넘게 지연되거나 시각이 역행하면 해당 묶음의 뒤늦은 출력을 생략한다.
- 게임의 명령 입력/서버 송신/자동 지도 열기/낚시 행동/런타임 HTTP는 추가하지 않았다. Framework 구독과 미리 듣기 요청은 Dispose 때 해제/폐기한다. Teamcraft 후속 조사는 재개하지 않았다.

## 첫 인게임 확인

1. 목록을 아래로 스크롤하고 어종 선택 후 즐겨찾기 켜기/끄기: 최상단으로 이동하지 않는지 확인한다. 검색/필터 변경은 기존처럼 위에서 시작한다.
2. 출현 알림 → 즐겨찾기에서 전체 즐겨찾기/제외 이유와 한 어종의 개별 시간 변경·기본값 복귀를 확인한다. 다른 어종의 예약 시각은 유지되어야 한다.
3. 채널과 SE를 선택하고 미리 듣기 후, 일반 제한 창의 실제 알림 한 번에서 담백한 메시지/지도 링크 클릭/효과음 1회/발송 기록을 확인한다. 링크 클릭 전에는 지도가 자동으로 열리지 않아야 한다.
4. 한국어/English 전환 시 남은 시간/설명만 바뀌고 선택/개별 시간/기록이 유지되어야 한다. 재로드 후 개별 시간/채널/SE 저장은 복원되고 세션 발송 기록은 비워져야 한다. 같은 창의 중복 방지 기록은 유지한다.

문제 시 짧은 알림 진단(`alerts/v2`)과 해당 화면만 받는다. 과거 지도/수집 검사를 반복하거나 Teamcraft 로그를 요청하지 않는다.
