# 신생 에오르제아 상세 조건 확대

날짜: 2026-10-16 · 대상: 0.1.11.0 · 인게임 검증 대기

## 범위와 근거

- 상세 조건 10→140종(+130). 고정 Fish Tracker revision의 patch 2 이상/3 미만 155행을 대상으로 했다. 추천 낚시터가 없는 보조 어종 15행은 제외하고 사유를 감사 JSON에 기록한다. 나머지 후보 대조 실패는 조용히 건너뛰지 않고 전체 생성을 실패시킨다.
- 출처/고정 revision/원본 SHA-256/지원 KR 빌드는 `data/fishing-source.json`, 가공 절차는 `data/README.md`, MIT 고지는 `THIRD-PARTY-NOTICES.txt`를 따른다. 원본 재다운로드와 기존 캐시의 SHA-256 일치 확인.
- 개발용 `tools/FishingDataImport`가 실제 한섭 정적 시트와 대조한다. 외부 HTTP·네이티브 접근·프로세스 읽기·새 패키지·자동 게임 행동은 추가하지 않았다.
- 현재 모델의 단일 추천 미끼 경로·시간/날씨·직감 요구만 확대한다. 생미끼 물고기 자체의 선행 조건까지 합성해 완전한 어획 가능 시간으로 표현하지 않는다. 물고기의 눈 적용과 개인 준비 상태는 예측에 반영하지 않는다.
- UI 문자열/리소스는 변경하지 않았다. 짧은 진단 summary/v2에 Dataset/Details(연결 수/내장 수)/BuildMatch 한 줄을 추가했다. catalog/v3은 상세 표본 최대 20종(선택 우선)으로 제한해 데이터 증가가 반복 로그 증가로 이어지지 않게 했다.

## 실행 결과

- `dotnet run --project tools/FishingDataImport ...`: 140종 생성, 추천 낚시터 없는 15행 제외, 참조/형태 대조 실패 0. 낚시터 107곳·링크 아이템 58종·날씨 15종. 직감 7종·직전 날씨 12종·추천 경로 최대 4단계.
- 기존 10종의 모든 규칙 필드를 비교해 변경 없음 확인. 스키마 v1 유지, dataset 버전 `kr-arr-2026-10-16`.
- 별도 출력 `.cache/arr-details-build/`의 Plugin Debug 빌드 성공(경고·오류 0). 한영 리소스 181키/형식 인자 검사 통과. 테스트 추가/실행 없음.
- 정규 DLL 교체와 확대 어종의 인게임 표시는 대기다. 기존 개발 DLL은 0.1.10.0이다.
- 재현 산출물 `.cache/fishing-expanded-audit.json`은 기계별 로컬 감사 자료로 추적 제외한다. 입력 해시와 변환 도구로 재생성할 수 있다.

## 게임 확인 순서

1. 0.1.11.0 로드 후 검색·즐겨찾기·수집 필터를 해제하고 ‘상세 조건 있는 어종만’을 켠다. 결과 140종, 짧은 진단 `Details=140/140; BuildMatch=True`가 기대값이다. 도감을 열 필요는 없다.
2. 엔도세라스(FishParameter 278)를 선택한다. ET 20:00~04:00, 직전 쾌청/맑음 → 현재 안개/흐림/바람, 미끼→보름정어리 경로와 지도 버튼을 확인한다. 시간/날씨만의 예측임을 유지한다.
3. 쿠노(285)를 선택한다. 3단계 추천 경로·직감 선행 어종 1마리/1400초가 보이고 아이템 링크가 동작해야 한다. 긴 경로·날씨·직감 표시에서 오류/눈에 띄는 끊김이 없어야 한다.
4. 결과는 `Details=140/140` 한 줄과 화면 이상 여부로 충분하다. 문제가 있을 때만 짧은 진단을 받고, 전체 보고서를 반복 요청하지 않는다.

신규 어종의 실제 어획·게임 ET/날씨 동시 대조는 별도 미확인이다. 다른 확장팩/복합 조건·입질 초 수는 이번 범위에 포함하지 않았다.
