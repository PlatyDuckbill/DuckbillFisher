# MVP-01 목록 행 요약

날짜: 2026-10-16 · Plugin 0.1.13.0 · 사용자 대표 확인 통과

## 동작과 범위

- 목록에서 상세 선택 없이 미끼·현재/다음 시간 창·주요 조건을 읽는다. 이름 / 수집 상태·낚시터 / 시간·날씨 창 / 미끼 경로 / 조건의 고정 5줄이다.
- 행 높이와 clipper 간격을 함께 변경했다. 아이콘은 3줄 높이로 제한하고 긴 문구는 열 경계에서 잘라 표시하며 마우스를 올리면 줄 전체를 감싼 툴팁으로 표시한다.
- 미끼는 실제 캐시 Item 이름을 쓴다. 단계는 `→`, 한 단계 안의 대체 선택지는 `(A / B)`로 보존한다. 아이템 링크 동작은 기존 상세 패널에 있다.
- ET 시간대·현재/직전 날씨·직감/전승록 필요·갈고리 낚시/루어·인내 사용 시 낚아채기를 확인된 값만 요약한다. 직감 달성/전승록 습득 여부나 낚을 준비 완료를 판정하지 않는다.
- 미끼/조건 자료가 없으면 미확인으로 표시한다. 먼바다는 해역 안내를 유지하고 일반 창 예측 미적용과 어종별 조건 미확인을 표시한다.
- 목록과 상세가 같은 시간 창 문구 생성 함수를 사용한다. UTC 현재 시각은 목록 렌더링마다 한 번 읽고, 기존 예측에서 남은 시간을 계산한다. 장기 예측/시트/파일 읽기를 렌더링에 추가하지 않았다.
- 정적 요약은 보이는 행부터 캐시하고 목록 참조/언어 변경 때 비운다. 언어 변경이 선택·검색·필터·수집 상태를 초기화하지 않는다.
- 원본 데이터/네이티브 접근/수집 로직/진단 형식은 변경하지 않았다. 현재 지역/F12 분류 필터는 이번 범위 밖이다.

## 재현 순서

1. 같은 개발 DLL 경로로 0.1.13.0 로드. 황금나비어(194) 검색: 수집·장소/시간·날씨 창/미끼 경로/ET·낚아채기 요약이 표시되고 상세와 일치해야 한다. 도감 관찰 전 수집 미확인은 정상이다.
2. 청린핵(1081) 또는 긴 경로가 있는 행을 좁혀 보고 긴 줄 위에 마우스를 올린다. 대체 미끼는 같은 단계 괄호 안에 남고 전체 문구를 툴팁으로 읽을 수 있어야 한다.
3. 검색을 지우고 목록 중간/끝까지 스크롤한다. 행 겹침/빈 간격/선택 위치 어긋남이 없어야 한다. 선택 후 한영을 전환해 선택·검색·필터가 유지되고 요약 문구만 바뀌는지 확인한다.
4. 먼바다 어종은 표지와 해역·일반 예측 미적용을 보여야 한다. 확인되지 않은 어종별 조건을 무제한이나 현재 출현으로 표시하지 않아야 한다.
5. 기본 회신은 ‘정상’ 또는 문제 화면 한 장이다. 이상이 있을 때만 짧은 진단을 요청하며 전체 데이터 연결 수/도감 검증을 반복하지 않는다.
