# 짧은 진단과 먼바다 필터

날짜: 2026-10-16 · 대상: 0.1.8.0

## 결정

- 기본 ‘짧은 진단 복사’는 summary/v1과 기존 preferences/v2·collection/v1을 출력한다. 선택 어종 ID/수집 상태와 필터를 포함한다.
- 상세 예측 10종·확인 불가 47행을 매번 붙이지 않는다. 기존 catalog/v2 전문은 ‘상세 진단 → 전체 진단 복사’에 유지한다.
- ‘먼바다 어종 포함’은 기본 켜짐이며 끄면 먼바다 어종을 제외한다. 다른 검색·수집·즐겨찾기·상세 필터와 함께 적용한다. 이 체크는 창 상태이며 영구 저장하지 않는다.
- 분류 근거는 실제 설치 KR 클라이언트의 FishParameter.OceanStars>0이다. IKDFishParam.Fish의 서로 다른 259종과 정확히 일치하며 차집합은 양쪽 모두 0종이다. 지역 이름/ID 범위 추측은 사용하지 않는다.
- 조회 환경: 게임 2026.10.06.0000.0000, 설치 Lumina/Excel 참조. 진단용 콘솔로 정적 시트만 조회했으며 게임 캐릭터 상태를 읽지 않았다.
- 미수집 Unknown은 이번에 변경하지 않는다. False는 ‘데이터 없음’과 ‘미수집’을 구별할 준비 완료 근거가 아직 없다. ‘수집한 어종 숨기기’는 Unknown을 계속 보여 주고 ‘미수집만’은 수동 기록 기준이다.

## 컨텍스트 운영

- STATUS/HANDOFF의 기존 전문을 docs/history에 보관하고 현재 사실과 다음 작업으로 줄였다. 새 완료 항목마다 과거 설명을 복제하지 않는다.
- 기본은 짧은 진단과 필요한 구역 조회다. 전체 로그를 대화에 재전송하는 대신 필요한 경우 파일로 받는다.
- 호스트가 지원하는 수동 /compact는 [공식 안내](https://developers.openai.com/blog/mastering-codex-remote-for-engineering)를 따른다. 새 대화는 짧은 STATUS/HANDOFF에서 재개한다.
- 자동 압축 임계값 model_auto_compact_token_limit은 [공식 설정 문서](https://learn.chatgpt.com/docs/config-file/config-reference)에 있다. 현재 호스트 적용 여부는 변경/검증하지 않았으며 전역 설정도 수정하지 않았다. 임계값 변경이 반복 로그 자체를 줄이지는 않는다.

## 실행 기록

- 별도 경로와 정규 Debug 빌드 모두 경고·오류 0. 사용자 언로드 확인 후 기존 개발 DLL 경로에 반영했다.
- 실제 주 DLL 159744바이트/어셈블리 0.1.8.0, Core DLL 25088바이트, ko 리소스 DLL 19968바이트와 manifest를 확인했다. 한·영 리소스 172키/형식 인자 검사를 통과했다.
- 사용자 보고에서 0.1.8.0/Rows=2512/CatalogLoaded와 15줄의 summary/v1을 확인했다. 포함 켜짐에서 Displayed=2였으며 사용자가 해제 시 사라진다고 확인했다. 해제 상태의 보고서는 받지 않았지만 실제 제외 동작은 사용자 확인으로 기록한다.
- Caught=0/Scans=0/GuideVisible=False/등록 0건은 이번 로드 후 자동 관찰 표본이 없는 상태다. 전체 미수집 1517종을 뜻하지 않는다.
- 일반 어종 유지·다른 필터 조합·한영 전환은 별도 미확인이다. 이번 결과 반영은 문서만 변경했고 빌드·테스트를 실행하지 않았다.

## 게임 확인 순서

1. ‘상세 조건 있는 어종만’을 끄고 ‘갈라디온’을 검색한다. 먼바다 포함 켜짐에서 보이고 끄면 사라져야 한다.
2. 황금나비어 등 일반 어종은 먼바다 포함을 꺼도 남아야 한다. 수집/즐겨찾기 필터와 함께 적용된다.
3. ‘짧은 진단 복사’는 약 20줄 이내이며 Detail:/미해석 행 목록이 없어야 한다. 이번에는 이 짧은 결과만 전달한다.
4. 한·영 전환 후 체크/선택을 유지한다. 전체 진단은 문제 조사 때만 사용한다.
