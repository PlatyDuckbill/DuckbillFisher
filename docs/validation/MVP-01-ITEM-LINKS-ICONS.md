# 미끼 아이템 링크와 스킬·날씨 아이콘

날짜: 2026-10-16 · Plugin 0.1.10.0 · 인게임 검증 대기

## 동작과 경계

- 상세 조건의 미끼·중간 생미끼는 순서 번호/아이콘/이름으로 표시한다. 아이콘이나 이름을 클릭하면 실제 NQ 게임 아이템 링크를 내 채팅창에 출력한다. 채팅의 링크를 누르면 게임 아이템 정보를 확인할 수 있다.
- 직감에 필요한 어획 대상도 아이콘/필요 수량/아이템 링크를 제공한다. 어획 달성 여부는 자동 추론하지 않는다.
- 낚아채기는 해당 Action 아이콘과 게임 시트 이름, 현재/직전 날씨는 각각 Weather 아이콘과 이름을 표시한다. 날씨 목록은 OR 조건임을 문구에 명시한다. 무제한 조건은 기존 안내를 유지한다.
- 링크는 공개 SeString.CreateItemLink(uint, bool, string)와 IChatGui.Print(SeString, tag)만 사용한다. 채팅 입력창 삽입·명령 실행·서버 채팅 전송·추가 네이티브 호출은 없다. 직접 아이템 창을 여는 공개 API는 확보하지 못해 게임 표준 채팅 링크 경로를 사용한다.
- 링크 클릭은 현재 세션과 함께 대기시켰다가 Framework.Update에서 처리한다. 로그아웃/캐릭터 변경 때 이전 요청은 실행하지 않는다. Dispose에서 구독과 대기를 해제한다.
- 아이콘 로드 실패 시 자리와 텍스트를 유지한다. 공유 게임 텍스처는 Dalamud 소유라 직접 해제하지 않는다.

## 한섭 근거

- 게임 2026.10.06.0000.0000, 설치 KR Dalamud 15.0.3.6의 Mono.Cecil 메타데이터와 Lumina 실제 시트를 조사했다. 게임 파일/캐릭터 메모리는 변경하지 않았다.
- 공개 API의 서명과 의미는 설치 Dalamud.dll/Dalamud.xml의 CreateItemLink 및 IChatGui.Print에서 확인했다. 원래 아이템 링크 payload와 이름을 사용한다.
- Action 4103=강력한 낚아채기/Icon 1115, 4179=섬세한 낚아채기/Icon 1116. 둘 다 ClassJob=18/IsPlayerAction=True다. 실행 시 Action 시트에서 이름과 아이콘을 읽고 직업/플레이어 스킬 조건을 확인한다. 이 ID를 동작 실행에 사용하지 않는다.
- 초기 10종 조건에 사용된 Weather는 1/2/3/4/5/7/8/14의 8종이며 아이콘/이름이 모두 존재한다. 미끼 경로와 직감 대상의 서로 다른 Item 15종도 이름/아이콘 누락이 0건이다.
- 아이콘 번호는 제품 코드에 고정하지 않는다. 실제 한섭 Item/Action/Weather 시트의 참조를 캐시한다. 조건 데이터와 예측 알고리즘은 변경하지 않았다.

## 유지보수와 문자열

- FishingDetailView는 이름 배열 대신 ID/이름/아이콘이 함께 있는 참조를 보관한다. FishCatalog가 Framework에서 시트를 읽으며 Draw는 시트 조회나 링크 메시지 출력을 직접 하지 않는다.
- 조건 표현은 FishingConditionPanel, 명시적 링크 요청/게임 접근은 FishingItemLinkService로 분리했다. 기존 목록/수집 상태/예측의 책임은 유지한다.
- 한영 리소스와 고정 위젯 ID를 사용하며 표시 이름을 상태 판정에 사용하지 않는다. Item/Action/Weather 이름은 게임 클라이언트 언어를 따른다.
- 기본 짧은 진단은 늘리지 않았다. 이번 시각적 변경은 성공 여부와 필요한 화면만 확인한다.

## 실행 결과

- 별도 경로 및 사용자 언로드 후 정규 Debug 빌드 경고·오류 0. 한영 리소스 181키/형식 인자 검사 통과.
- 실제 주 DLL 176128바이트/어셈블리 0.1.10.0, Core 25088바이트, ko 리소스 21504바이트, manifest 0.1.10.0/API 15 확인.
- 이번 구현에서 테스트를 추가/실행하지 않았다. 실제 채팅 링크의 표시/아이템 정보 열림·아이콘/레이아웃·언어 전환은 인게임 확인 대기다.

## 확인 순서

1. 같은 개발 DLL 경로로 0.1.10.0 로드. 상세 조건 어종만 켜고 황금나비어 선택 → 미끼 이름 또는 아이콘 클릭 → 내 채팅의 링크를 눌러 같은 아이템 정보가 표시되는지 확인.
2. 헬리코프리온(290)의 2단계 미끼/생미끼와 낚아채기·현재 작열파/직전 안개 또는 흐림 아이콘·이름을 확인한다. 중간 물고기도 같은 방식으로 링크가 열려야 한다.
3. 넵토드래곤(276)의 직감 필요 어획 이름/개수/아이콘과 링크를 확인한다. 한영 전환 후 선택은 유지되고 UI 문구만 바뀌어야 한다.
4. 이상이 없다면 짧은 성공 응답이면 충분하다. 문제가 있으면 해당 화면과 증상만 보내며 전체 진단은 요청하지 않는다.
