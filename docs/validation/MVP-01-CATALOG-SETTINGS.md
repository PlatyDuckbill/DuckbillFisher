# 목록 설정 저장·기본값 복원·도감 안내

날짜: 2026-10-16 · 소스 0.1.26.0 · 정규 교체/인게임 확인 대기

## 사용자 동작과 저장 범위

- 정렬, 수집 표시, 시간제, 등급, 즐겨찾기만, 현재 지역만, 먼바다 포함, 수첩 포함과 지역/확장팩 ID 선택을 공통 설정에 저장한다. 캐릭터를 바꿔도 같은 선택을 사용하며 실제 현재 지역과 수집 관찰은 새 캐릭터/지역 상태를 따른다.
- 검색어/선택 어종/확인 불가 행 표시/상세 조건만 체크는 저장하지 않는다. 진단용 두 체크는 기존 상세 진단 안에 유지한다. 이름 붙인 프리셋 관리 기능은 이번 범위에 추가하지 않았다.
- `목록 필터 → 필터·정렬 기본값 복원`은 남은 시간순/수집한 어종 숨기기/시간제만/등급 전체/먼바다 제외/수첩 포함/지역·확장팩 무제한/즐겨찾기만과 현재 지역만 꺼짐으로 되돌린다. 검색어와 진단용 두 체크도 비운다. 즐겨찾기·수집 기록·알림 설정은 바꾸지 않는다.
- 기본값은 `CatalogSettings` 한곳에 두고 UI의 정렬/수집/등급 선택 순서와 저장 enum을 명시적으로 매핑한다. 지역/확장팩은 숫자 ID를 중복 제거/정렬하여 저장하며 확장팩 0은 신생으로 허용한다. 모르는 저장 지역은 임의로 지우지 않고 기존 범위 밖 선택 안내를 사용한다.
- UI는 최초 표시 때 한 번 복원하고 입력 변경만 Framework의 저장 큐에 전달한다. 렌더링 중 파일을 읽거나 저장하지 않으며, 같은 값/접기/언어 변경/관찰 갱신은 설정 저장을 유발하지 않는다. 다른 즐겨찾기 변경으로 필터/스크롤을 다시 초기화하지 않는다.
- 큐는 최신 목록 설정 하나만 보관하고 기존 알림/즐겨찾기/수동 변경과 한 후보 설정으로 합쳐 저장한다. 저장 실패는 이전 설정과 기존 오류 안내를 유지한다. 화면의 새 선택은 임시로 남을 수 있으나 저장 완료로 표시하지 않는다. Dispose 때 대기 설정을 해제한다.

## 기본 자동 해제와 도감 안내

- 새 어종 도감 등록 시 자동 해제는 기본 켜짐으로 바꾼다. 요청한 기본값을 기존 설치에도 적용하도록 schema v1~v7을 읽을 때 켜짐을 적용한다. v8로 저장한 뒤 사용자가 끈 선택은 다음 로드에도 보존한다. 현재 수집 집합을 조회하여 기존 즐겨찾기를 소급 삭제하지 않는다.
- 자동 해제의 실제 입력은 기존 검증된 KR 새 어종 등록 이벤트뿐이다. 도감 조회/수동 상태 변경/이미 등록한 어종 재어획은 해제하지 않는다. 개별 분과 이력/중복 기록을 유지한다.
- 목록과 즐겨찾기 관리에서 현재 캐릭터가 있고 현재 세션의 `GuideState != Complete`이면 도감의 낚시 탭을 열어 달라는 안내를 표시한다. 다른 세션과 NotSampled는 최초 조회 안내, 나머지 불완전/실패 상태는 대조 재시도 안내로 구분한다.
- Complete는 기존 전체 목록/비트 대조가 성공한 상태다. 수집 개수/창 표시/IsLoaded/등록 한 건으로 완료를 추론하지 않는다. 완료 후 도감을 닫아도 상태가 Complete이면 안내하지 않는다. 로그아웃/재접속·목록 교체·조회 실패로 상태가 초기화되면 안내가 다시 나타난다.
- UI 안내만 추가하며 채팅/Toast 발송, 추가 폴링/네이티브 접근, Unknown→미수집 변경은 없다. 미접속 때는 이 안내를 표시하지 않는다.

## 로드 후 대표 확인

1. 정렬/수집/일반 필터와 지역/확장팩을 몇 개 바꾼 뒤 잠시 기다렸다 재로드하여 같은 선택이 복원되는지 확인한다. 검색어/진단 체크는 초기화돼야 하며 범위 밖 지역 경고는 유지돼야 한다.
2. 기본값 복원 후 재로드해도 기본 목록 선택이 유지되고 즐겨찾기/알림 설정은 유지되는지 확인한다.
3. 자동 해제가 처음 켜져 있는지 확인한다. 필요하면 끈 뒤 재로드하여 꺼짐이 유지되는지 확인하고 다시 원하는 값으로 둔다. 실제 해제는 다음 자연스러운 신규 등록 때 확인한다.
4. 재로드/재접속 후 도감 조회 전 안내, 낚시 탭 조회 완료 후 안내 사라짐, 도감 닫힘 후 미표시를 확인한다. 다른 캐릭터 실기 확인은 사용 가능한 캐릭터가 없어 계속 보류한다.

문제 시 해당 화면과 짧은 진단만 받는다. 이미 통과한 어종별 수집 판정을 반복 요청하지 않는다.
