# 0.1.29.0 목록·상세 배치 조정

갱신: 2026-10-17 · 별도/정규 빌드 완료 · 인게임 확인 대기

## 사용자 피드백과 반영

- 상세 Patch를 이름 오른쪽의 전용 열에 우측 정렬하고 조건 하단의 중복 표시는 제거했다. 원본 패치가 없는 어종에는 값을 추측하지 않는다.
- 물고기의 눈 지원 문장을 별도 한 줄로 표시하지 않는다. 즐겨찾기/수집 상태와 같은 동작 줄의 작은 아이콘으로 표시하며, 미지원은 흐린 아이콘+사선, 지원/미지원과 기술 이름은 툴팁으로 제공한다. 목록에서는 제거했다.
- 생미끼/직감 대상은 이름 왼쪽·낚아채기/입질/ET 오른쪽의 한 행으로 묶는다. 긴 날씨/추가 기술/미확인 설명은 오른쪽 정보 아이콘 툴팁에 항목별로 표시한다. 기존 정보의 범위와 미확인 구분은 유지한다.
- 목록의 조건 정보 아이콘 툴팁을 문장 사이 구분점 대신 항목별 줄바꿈으로 변경했다. 미끼 경로 툴팁은 기존 순서/대안 표현을 유지한다.
- 공통 목록 첫 줄은 이름/등급과 수집 상태, 둘째 줄은 핀/위치와 출현 또는 종료 남은 시간이다. 목록의 물고기의 눈은 제거하고 직감 아이콘은 어류 아이콘 오른쪽 위 안에 배경을 둬 겹쳐 표시한다.
- 메인·간략·즐겨찾기 공통 행에서 지도 핀을 직접 누를 수 있다. 메인/간략은 현재 지역 필터 범위에 맞는 표시 낚시터를 사용한다. 위치 없음/캐릭터 없음은 비활성화하고 핀 클릭은 상세 선택/열기와 구분한다.
- 상세 출현의 남은 시간과 실제 시간 범위는 `종료 00:05:00 | 오늘 13:06 – 13:29`처럼 같은 줄에서 구분한다. 좁은 화면에서 잘리는 내용과 전체 현지 날짜는 툴팁으로 확인한다. 출현 상태/배경은 유지한다.

## 유지보수와 경계

- FishRowRenderer는 캐시된 어종/낚시터와 기존 FishingMapService만 사용한다. 클릭 시 Request로 전달하고 실제 지도 처리는 기존 Framework 어댑터가 수행한다. 새로운 네이티브 조회/게임 명령/입력은 없다.
- Pin 버튼은 행 내부의 별도 고정 ID이고, 그 위에서 발생한 클릭은 행 선택 결과에서 제외한다. 같은 위치에 보이는 어종 선택을 지도 동작으로 오해하지 않게 한다.
- 목록 높이는 공통 GetHeight로 계산한다. 넓은 행/간략 3줄, 좁은 메인 4줄이며 클리퍼/예정 이동/즐겨찾기 추가 설정 행 모두 같은 높이를 사용한다.
- 조건 옆 표시가 좁으면 잘린 정보는 툴팁으로 제공한다. 미끼의 낚아채기·입질·시간을 대상 어종에서 추측 복사하지 않는다. 기존 RelatedDetails 범위만 사용한다.
- 설정 schema v10/preferences/v8, 필터 공유/Unknown/수동 우선/알림 정책/예측 계산/데이터 버전은 바꾸지 않았다. 새 리소스 WindowInline은 문장 전체와 형식 인자를 한영으로 제공한다. UI 고정 ID 유지.
