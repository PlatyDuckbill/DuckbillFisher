# 0.1.31.0 상세 조작·목록 아이콘 정리

갱신: 2026-10-17 · 정규 빌드 완료 · 인게임 검증 대기

## 변경과 경계

- 물고기의 눈 표시를 제거하고 등급·즐겨찾기·수집 상태 선택을 같은 줄에 배치했다. 원본 지원 데이터와 기존 예측 계산은 유지한다.
- 수집 선택 메뉴를 ‘수집됨으로 수동 지정’/‘미수집으로 수동 지정’으로 명확히 했다. 수동 우선순위와 해제 동작은 그대로다.
- 직감 배지의 별도 배경을 제거하고 크기를 늘렸다. 게임 텍스처는 실제 종횡비를 유지해 정사각 영역 중앙에 표시한다. 텍스처 소유권은 바꾸지 않는다.
- 메인/간략 목록의 지도 버튼은 배경과 선명한 지도 표시 모양을 가진 벡터 아이콘만 사용한다. 사용자 요청으로 ‘핀’ 글자는 넣지 않았다. 클릭 시 기존 지도 표시 요청만 수행하며 행 선택과 구분한다.
- 0.1.30.0의 OpenConfigUi 등록 수정도 이번 정규 DLL에 포함한다. [콜백 근거](CONFIG-UI-CALLBACK.md).

## 조건 미확인 안내의 범위

- 현재 고정 자료 `data/fishing.kr.v2.json` 903행 중 ConditionsKnown=false인 31행은 모두 FishingSpotId=0이다. 나머지 기본 예측 대상 872행과 구분한다.
- 설치 KR 클라이언트 Item 시트를 읽기 전용으로 대조한 예: 멜토르 망둥이(4/4869), 얼룩망둥이(6/4927), 바다구름해파리(12/4872), 항만청어(15/4874), 아발라시아 빙어(24/4937), 검투어(31/4942). 괄호는 FishParameter/Item이다.
- 이들은 조건 자료의 계산 기준 낚시터 연결이 빠진 항목이다. 클라이언트에서 읽은 낚시터 목록이 보이는 것과 조건 자료의 위치 연결은 별개다. 상세 자료 자체가 없는 어종이나 캐릭터 수집 미확인과도 구분한다.
- 표시 문장: ‘조건 자료에 낚시터가 연결되어 있지 않아 출현 시간을 계산할 수 없습니다.’ 툴팁에서 클라이언트 낚시터 목록과 계산 기준 연결의 차이를 설명한다.
- 자료를 보완하려면 원본 조건과 실제 낚시터/날씨 기준을 대조하는 별도 데이터 작업이 필요하다. 첫 후보 낚시터를 임의 선택하거나 미확인을 상시로 바꾸지 않았다. 데이터 파일·예측 공식 변경 없음.

## 인게임 확인 순서

1. 정규 DLL을 다시 로드하고 Dalamud 설정 버튼이 메인 설정 탭을 여는지, 콜백 경고가 사라졌는지 확인한다.
2. 터주/터주왕 상세에서 등급·별·수집 선택이 같은 줄인지 확인한다. 수동 지정 메뉴 이름과 수동 해제 동작을 확인한다.
3. 직감 필요 어종의 목록 배지가 찌그러지지 않고 별도 배경 없이 표시되는지 확인한다. 메인/간략 지도 아이콘 클릭은 지도만 표시해야 한다.
4. 멜토르 망둥이 등 위치 연결이 없는 자료에서 새 안내 문장과 툴팁을 확인한다. 기존 시간·날씨 예측 어종의 상태는 바뀌지 않아야 한다.

위 화면과 상호작용은 사용자 인게임 확인 대기다.
