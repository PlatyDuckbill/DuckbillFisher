# 0.1.35.0 목록 폭 대응·기본 등급

갱신: 2026-10-17 · 별도 빌드 완료 · 정규 반영/인게임 확인 대기

## 사용자 확인과 합의

- 0.1.34.0의 넓고 좁은 간략 보기 사진에서 좁을 때 조건 줄 전체와 접근 표시가 사라지는 문제를 확인했다.
- 넓으면 3줄/좁으면 4줄, 넘침은 …+전체 툴팁, 전승록은 상세에만 유지, 신규/복원 기본 등급은 터주 이상, 아이콘은 크기를 유지한 세로 중앙 정렬로 합의했다.
- 후속 사진 피드백으로 한 줄 배치의 폭 기준 완화와 목록의 ‘7일 범위에서 찾지 못함’ 설명이 여러 줄을 점유하는 문제도 같은 작업에서 처리했다.

## 변경

- 공통 행 높이는 화면 폭에 따라 3줄/4줄이다. 간략만 조건을 생략하던 분기를 제거했다. 높이 산식은 간략/메인/즐겨찾기 클리퍼와 예정 이동에서 공유한다.
- 미끼·대상 낚아채기·입질을 한 묶음, 날씨·ET·기타 조건을 다른 묶음으로 표시한다. 좁은 화면에서는 두 묶음이 각각 셋째/넷째 줄이며 생략된 토큰과 긴 대체 문구는 … 툴팁으로 확인한다. 개별 아이콘 툴팁도 유지한다.
- 한 줄 전환 기준을 폰트 28배에서 23배로 낮췄다. 줄 수를 바꾸는 기준은 동일 폭의 행에서 고정해 클리퍼를 유지한다. 너비 배분은 미끼/조건의 실제 아이콘·문자·간격을 측정하며, 모두 들어가면 임의 55% 제한을 적용하지 않는다. 부족하면 두 묶음에 최소 공간과 넘침 표시를 보장한다.
- 전승록은 목록 토큰과 목록 툴팁에서 제거했다. 상세의 필요 전승록/아이템 링크와 원본 사실은 유지한다.
- 어류 아이콘은 기존 모드별 크기를 늘리지 않고 오른쪽 전체 정보 묶음의 세로 중앙에 둔다. 직감 배지는 아이콘 우측 상단을 따라 이동하고, 즐겨찾기 별은 아이콘 좌측 하단에 두어 행 아래로 넘치지 않게 했다.
- 신규 CatalogSettings와 기본값 복원의 Grade는 BigIncludingLegendary다. 저장된 명시적 Grade=All/다른 등급은 덮어쓰지 않는다. 저장 스키마/수집 판정/기타 필터/알림 정책 변경 없음.
- 목록 시간은 짧은 상태를 사용한다. NotFound는 ‘7일 내 예측 없음’이며 자세한 문장은 기존 전체 툴팁에 유지한다. 목록 문자에는 한 줄 높이/클립/히트 영역을 명시해 긴 설명이 행 높이를 바꾸지 않게 했다. 실제 7일 예측 계산이나 검색 범위는 바꾸지 않았다.

## 인게임 확인 순서

1. 간략/메인/즐겨찾기 목록 폭을 좁히고 넓혀 4줄/3줄 전환, 미끼/낚아채기/날씨/ET와 … 전체 툴팁을 확인한다. 긴 생미끼 경로와 날씨 전환 어종을 포함한다.
2. 정보 묶음과 어류 아이콘의 세로 중앙/직감/즐겨찾기 배지가 행 안에 맞는지 확인한다. 예정 이동/스크롤과 지도 클릭도 유지되어야 한다.
3. 전승록 아이콘/문구는 목록과 목록 툴팁에 없고 해당 어종 상세에는 유지되어야 한다.
4. 저장해 둔 등급은 재로드 후 유지한다. 기본값 복원 시 터주 이상(왕 포함)으로 바뀌고 기존 시간제/수집/지역 조건과 함께 적용되어야 한다.
5. 7일 내 출현을 찾지 못한 어종의 목록 시간은 한 줄이며 마우스 오버로 기존 긴 설명을 확인할 수 있어야 한다. 작은/큰 폭과 한영 조합의 실제 확인은 대기다.
