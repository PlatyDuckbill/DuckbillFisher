# 제품 범위와 수용 기준

## 목표

한국 서버 플레이어가 인게임에서 미수집 터주, 출현 조건, 미끼·생미끼 단계, 입질 시간 안내, 지도 위치를 확인한다. 사용자가 직접 플레이하며 플러그인은 정보를 제공한다.

최소 배포 목표는 친구가 커스텀 저장소 URL 하나를 등록하여 설치·업데이트하는 것이다. 장기 목표는 공식 저장소 등록이다. 배포 구조는 [배포 안내](DISTRIBUTION.md)를 따른다.

## 요구사항

| ID | 기능 | 완료 판단 |
|---|---|---|
| F01 | 어류 수첩 연동 | 수첩 조회 시 현재 캐릭터의 수집 상태 자동 반영, 새 어종 습득/수첩 등록 시 자동 갱신, 실패 시 Unknown |
| F02 | 미수집/수동 필터 | 자동 수집 상태와 수동 override를 별도 보존, 초기화 가능 |
| F03 | 검색과 정렬 | 이름 검색, 확장팩·지역·현재 지역만·즐겨찾기·수집 상태 필터, 이름순·즐겨찾기 우선과 필수 남은 시간 정렬(열린 창 종료순→예정 창 시작순, 상시 후순위), 현재 지역 우선·안정적인 동률 정렬. 상세 정책은 [개선안](LIST-SORTING.md) 참고 |
| F04 | ET/날씨 예측 | 시간·현재 날씨·직전 날씨 교집합, 자정 경계, 다음 창 시작/종료와 남은 실제 시간, 미충족 개인 조건 구분 |
| F05 | 즐겨찾기 알림 | 즐겨찾기이며 미수집으로 판정된 어종의 창마다 설정된 실제 시간 X분 전 1회 |
| F06 | 내장 정보 | 권장/대체 미끼·생미끼 단계, 출현 조건, 섬세/강력한 낚아채기·입질 강도, 미끼/스킬 조건별 입질 초 범위·표본/출처 |
| F07 | 입질 타이머 | 수동 시전의 관찰 시점부터 경과 표시, 취소·종료·로그아웃 시 초기화 |
| F08 | 지도 연동 | 낚시터의 지도 버튼 클릭 시 해당 지도를 열고 좌표에 핀 표시. 복수 낚시터는 각각 선택 가능 |
| F09 | 미끼 안내 | UI에서 미끼 표시. 게임 미끼창 하이라이트는 후속 확장 |
| F10 | 전체 어종 목록 화면 | 아이콘·이름·낚시터·미끼를 행으로 표시, 전체 목록 스크롤, 상세 데이터 미확인 표시, 화면에 보이는 행 위주 렌더링 |
| F11 | 먼바다 안내 | 목록/상세에서 먼바다임을 명시, 확인된 해역·시간대·특수 조건 표시. 빠진 필드만 미확인으로 남기고 일반 낚시의 시간/날씨 예측을 그대로 적용하지 않음 |
| F12 | 어종 분류 필터 | 시간제만 체크 + 전체/터주(터주왕 포함)/터주왕만 선택. 수집 여부 등과 별도로 선택하고 함께 적용 |

알림 채널은 Toast, 본인 로컬 채팅창, 선택 가능한 소리다. 파티/서버 채팅 송신은 하지 않는다. Unknown은 미수집 확정 알림에서 제외하되 목록에는 상태를 표시하고 수동 설정을 허용한다.

0.1.15.0의 수집 필터 계약: `전체 / 수집한 어종 숨기기 / 수집됨만 / 미확인만`. 사용자 요청에 따라 UI의 ‘미수집만’을 제거했다. 수집 숨김은 수집됨만 제외하며 Unknown을 유지한다. Unknown을 미수집으로 재분류하지 않는다. 즐겨찾기는 공통, 수동 상태는 캐릭터별로 저장하고 수동 지정 해제 시 자동 관찰값으로 돌아간다. 자동 관찰 전에는 Unknown이다. 새 UI 조합은 인게임 검증 대기다.

### 어종 분류 필터 (0.1.15.0)

- 사용자 선택에 따라 ‘시간제만’ 체크와 `전체 / 터주(터주왕 포함) / 터주왕만` 단일 선택을 분리했다. 기본은 시간제 체크 해제와 등급 전체다.
- 시간제는 ET 시간대 또는 현재/직전 날씨 제약이 확인된 어종이다. 현재 출현 중/개인 준비 완료 여부는 별도이며, 제약 미확인은 시간제만에서 제외한다.
- 터주 선택 안에서는 터주 또는 터주왕을 포함한다. 등급과 시간제, 검색/현재 지역/수집/즐겨찾기/먼바다 포함/상세 자료 필터 사이는 모두 함께 충족해야 한다(AND).
- 등급 ‘전체’는 등급 제한만 해제한다. 다른 선택 상태는 유지한다. 등급 미확인은 전체에서는 유지하고 특정 등급에서는 제외한다. 시간제 체크는 별도로 유지한다.
- KR 설명의 명시적 분류를 개발 중 검수한 ID 자료와 연결한다. bigFish 하나나 패치 번호로 터주왕을 추측하지 않는다. [데이터 근거](../data/README.md)의 지원 빌드/ID 쌍 일치가 필요하며 실행 중 UI 문자열로 판정하지 않는다.
- 먼바다는 일반 터주/터주왕이나 시간제 어종으로 추측하지 않는다. 등급 전체/시간제 해제 시 기존 먼바다 포함 필터를 따르며, 현재 지역만은 계속 일반 낚시터 기준이다.
- 지역/확장팩 복수 선택은 아래 계약을 따른다. 런타임 분류 335/왕 36/시간제 443과 터주왕+수집됨 조합 표본은 확인했으며 한영/모든 선택의 화면 확인은 남아 있다.

### 지역·확장팩 필터 (0.1.16.0)

- 사용자 선택에 따라 지역(지도 구역)과 확장팩은 각각 복수 선택한다. 확장팩은 어종 도입 패치가 아닌 낚시터 TerritoryType.ExVersion 기준이며 이름은 클라이언트 시트에서 읽는다. 신생의 ExVersion ID 0은 유효하다.
- 같은 그룹 안에서는 하나라도 해당하면 된다(OR). 같은 낚시터가 선택한 지역과 확장팩, 켜져 있다면 현재 지역만 조건을 모두 만족해야 한다(AND). 한 어종의 서로 다른 낚시터가 각 조건을 따로 만족하는 것으로 합치지 않는다.
- 그룹의 선택 없음/‘전체’는 해당 제한만 해제한다. 다른 그룹·검색·수집·등급·시간제·즐겨찾기 등의 선택은 유지하며 함께 적용한다. 충돌하는 선택은 빈 결과로 남기고 자동으로 다른 선택을 지우지 않는다.
- 특정 지역/확장팩 선택 시 먼바다·위치 미확인은 제외한다. 두 그룹 모두 전체이고 현재 지역만도 꺼져 있으면 기존 먼바다 포함 설정을 따른다. 확인되지 않은 확장팩을 신생 ID 0으로 바꾸지 않는다.
- 지역 검색과 접은 상태의 선택 요약을 제공한다. 언어 전환/목록 재조회는 ID 선택을 유지한다. 선택은 다른 목록 필터처럼 현재 플러그인 UI 수명에 속하며 새 영속 저장은 추가하지 않는다. 0.1.16.0의 필터 기능은 사용자 대표 확인을 통과했다.
- 0.1.17.0 UI 개선: 확장팩은 패널에 체크박스로 직접 표시한다. 지역 후보는 선택한 확장팩으로 좁히고 확장팩별로 묶는다. 확장팩 체크가 없으면 전체 후보를 표시한다. 지역 팝업은 검색/해제 버튼을 고정하고 목록 하나만 스크롤한다.
- 확장팩 변경으로 가려진 지역 선택은 자동으로 지우지 않는다. 범위 밖 선택의 수·이름 안내와 해당 선택만 해제하는 버튼을 제공하며 검색으로 가려진 체크도 유지한다. 0.1.17.0의 선택 UI는 사용자 대표 확인을 통과했다.

0.1.7.0은 MVP-04의 첫 단계로 수첩 조회와 새 어종 등록에서 수집됨을 자동 반영하도록 구현했다. 자동 미수집 판정은 아직 없으며 나머지는 Unknown이다. 수동 지정은 계속 우선한다. 이 버전의 자동 수집 필터·등록 이벤트는 인게임 검증 대기다.

## 첫 사용자 버전

사용자 우선순위: 입질 초 수 통계는 후속으로 미룬다. 0.1.5.0은 낚시터/지도 핀·초기 10종 미끼/낚아채기/조건과 기본 시간·날씨 창 카운트다운을 구현했다. 한섭 10종 연결과 황금나비어 상세/지도 핀, 고정 원본 기준 예측 계산 대조는 통과했고 실제 게임 ET/날씨 동시 대조는 남아 있다. 출현까지 남은 시간은 입질 초 수와 별개이며 MVP-03 중 이 부분을 먼저 구현한다. 자동 수집 필터·알림·캐스팅 타이머가 함께 완료된 것은 아니다.

전체 어종을 담을 수 있는 스크롤 목록과 검색·기본 정렬·수동 수집 상태·즐겨찾기 필터를 MVP-01에서 만든다. 게임 시트에서 확인한 전체 어종을 표시할 수 있게 하되 조건·미끼·지도 상세 정보는 검증된 5~10종부터 채운다. 알 수 없는 지역·조건·미끼를 추측해 채우지 않고 미확인으로 표시한다. 기본 전체 목록에는 수집 상태 Unknown인 어종도 포함한다.

출현 시간순 정렬은 MVP-03의 ET/날씨 계산과 함께, 게임 수집 상태 자동 필터는 MVP-04에서 연결한다. 캐스팅/수첩 읽기 가능성은 먼저 짧게 조사하되, 전체 기능을 네이티브 연동 성공에 종속시키지 않는다. 전체 확장팩의 검증된 상세 데이터는 데이터 구조와 검수 절차가 안정된 뒤 확장한다. 단계별 범위는 [로드맵](ROADMAP.md)을 따른다.

## 명세에서 보완할 부분

- 0.1.14.0의 ‘현재 지역만’은 이름 대신 Territory ID를 대조하며 복수 일반 낚시터 중 하나가 현재 지역이면 포함한다. 검색·수집·즐겨찾기 등 기존 필터와 함께 적용하고 다른 선택을 초기화하지 않는다. 먼바다·위치 미확인 어종은 제외하며 지역을 확인할 수 없으면 안내와 빈 결과를 유지한다. 지역 이동/필터 조합의 사용자 대표 확인을 통과했다. F12 분류끼리의 결합 규칙은 별도 논의한다.
- 목록 행에도 미끼·현재/다음 시간 창·주요 조건 등 유용한 정보를 간단히 요약한다. 0.1.13.0의 고정 5줄 요약과 긴 줄 툴팁은 사용자 대표 확인을 통과했다. 개인 준비 완료와 시간·날씨 창을 구분하고, 상세 안내의 전체 문장을 행마다 반복하지 않는다.
- 먼바다는 기존 시트/검수 가능한 외부 원본에서 최대한 정보를 확보한다. 목록의 명시적 먼바다 표지와 확인된 해역/시간대 안내를 우선하고, 상세 부족을 수집 여부 Unknown과 섞지 않는다. 일반 상세 원본에 없다는 이유로 먼바다 정보를 일괄 미확인으로 취급하지 않는다.
- 소장품 후속 후보는 게임 소장품으로 획득 가능한 어종 여부와 소장가치별 납품 조건/보상/납품처 안내다. 도감의 수집됨/미수집 상태와 별개이며, 모든 소장품 어종이 모든 납품처에서 교환된다고 안내하지 않는다. 값과 보상은 한섭 시트/실제 대상에 맞게 검수한다.
- 후속 상세 UI: 미끼와 생미끼 경로의 모든 중간 물고기를 실제 Item ID의 게임 아이템 링크로 연결한다. 섬세한/강력한 낚아채기는 해당 스킬 아이콘, 현재/직전 날씨 조건은 해당 날씨 아이콘과 이름을 함께 표시한다. 이번 예측 검증에는 구현하지 않으며, 공개 API 확인과 클릭/툴팁·다국어 검증을 별도 작업으로 진행한다.
- 상세 정보의 출처/조회 계획은 [DATA-SOURCES.md](DATA-SOURCES.md)를 따른다. Teamcraft 통계와 Fish Tracker 조건 데이터의 역할을 구분하고, 개발 시 검수한 데이터를 내장하며 런타임 외부 조회는 추가하지 않는다. 다음 창 예측/시간순 정렬은 MVP-03, 지도 핀은 MVP-01 범위다.
- '시간/날씨 창이 열림'과 '지금 낚을 모든 조건이 충족됨'을 구분한다. 직감, 선행 어종·마릿수, 생미끼 연쇄 등은 데이터 검증 대상이다. 미지원 조건이 있는 어종은 완전 지원처럼 표시하지 않는다.
- 입질 최소/최대 시간은 측정 조건이 붙는 안내값이다. 시전/생미끼 종류, 적용 버프·스킬, 측정 시작 기준, 표본/출처를 기록하고 어종 확정 판별이나 성공 보장으로 표현하지 않는다.
- 내장 JSON은 네트워크 의존성을 없애지만 패치별 데이터 정확성이나 네이티브 메모리 호환성을 보장하지 않는다. 지원 KR 빌드/데이터 revision을 표시한다.
- 어종 이름/지역/미끼 같은 정적 시트와 캐릭터의 실제 수집 상태는 다른 데이터다. 시트만으로 수집 여부를 알 수 있다고 가정하지 않는다.
- 공식 Dalamud 저장소 등록과 한국 배포판 등록은 대상·호환성·절차를 각각 확인한다. 자동화 배제는 여러 심사 조건 중 하나다.
