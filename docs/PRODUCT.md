# 제품 범위와 확정 동작

한국 서버에서 사용자가 직접 낚시하며 어종·조건·수집 상태·미끼·출현 예측·기록을 확인하는 정보 플러그인이다. 이 문서는 현재 합의한 동작을 정의한다. 실제 확인 범위는 [STATUS](STATUS.md), 남은 후보는 [ROADMAP](ROADMAP.md)을 따른다.

## 기능 계약

|---|---|---|
| F01 | 어류도감 연동 | 현재 세션의 도감 전체 대조 후 자동 미수집 확정, 검증한 신규 등록 이벤트로 수집 반영. 읽기 실패는 Unknown |
| F02 | 수동 상태·수집 필터 | 수동 상태가 자동보다 우선. 해제하면 자동 상태 사용. 전체/수집 숨김/수집됨/미확인 선택 |
| F03 | 검색·정렬·필터 | 이름/ID/낚시터 검색, 지역·확장팩·현재 지역·즐겨찾기·수집·등급·시간제 조건. 필터 저장과 이름 프리셋 |
| F04 | ET/날씨 예측 | 알려진 ET·현재/직전 날씨 조건의 교집합. 현재/다음 출현과 실제 남은 시간. 개인 준비나 성공 보장 아님 |
| F05 | 즐겨찾기 관리·알림 | 전체 즐겨찾기 기본, 미수집만 선택 가능. 미래 출현마다 설정한 실제 X분 전 1회. 개별 시간·로컬 채널·SE·발송 기록 |
| F06 | 내장 조건 | 확인한 첫 미끼·생미끼 연쇄·직감·낚아채기·입질 강도·날씨·전승록·출처. 없는 값은 추측하지 않음 |
| F07 | 캐스팅 타이머 | 시전 UTC/ET·단조 경과·현재 낚시터/미끼. 낚아채기 관찰에서 대표 경과 정지. 정확한 낚시터를 지역만으로 추측하지 않음 |
| F08 | 지도 | 사용자가 선택한 낚시터의 지도·좌표 표시 |
| F09 | 미끼 찾기 | 상세 조건 제목의 버튼에서 대상 선택. 게임 미끼 UI의 해당 칸/다른 페이지 번호 강조. 페이지 이동·미끼 선택은 사용자 직접 수행 |
| F10 | 목록·상세 | 메인/간이 목록의 공통 어종 행, 아이콘·툴팁·실제 아이템 링크, 상세 패널/재사용 상세 화면 |
| F11 | 먼바다 | 먼바다 구분·확인된 해역/시간대 안내. 일반 낚시 예측을 어종별 특수 조건의 대용으로 쓰지 않음 |
| F12 | 등급·시간제 | 시간제 체크와 전체/터주(왕 포함)/터주왕 선택을 분리. 현재 출현 여부와 독립 |

| F14 | 미끼 준비 | 즐겨찾기 기본/현재 메인 결과 전체의 첫 실제 미끼 집계·일반 소지품 수량·관련 어종·미확인 목록. 독립 보조 화면 |

## 수집·필터·정렬

- 수집 숨김은 Caught만 제외하고 Unknown을 유지한다. 미확인은 미수집이 아니다. 수동 상태는 캐릭터별, 즐겨찾기는 공통 저장한다.
- 신규/기본값 복원은 남은 시간순·수집 숨김·도감 어종·먼바다 제외·시간제만·터주(왕 포함)다. 기존 저장 선택은 유지한다. 코드 기준은 CatalogSettings다.
- 남은 시간순은 출현 중 종료순 → 출현 예정 시작순 → 시각 미확인 → 상시다. 동률은 이름/ID로 안정화한다. 현재 지역은 필터이며 정렬 우선순위에 넣지 않는다. [세부 정렬](LIST-SORTING.md).
- 시간제는 알려진 ET 또는 현재/직전 날씨 제약이다. 제한 미확인은 시간제만에서 제외한다. 등급 전체는 등급 제한만 해제한다.
- 지역/확장팩은 각 그룹 내 OR, 서로 다른 필터는 AND다. 같은 낚시터가 지역·확장팩·현재 지역 조건을 함께 만족해야 한다. 확장팩은 어종 도입 패치가 아닌 낚시터 소속이며 ID 0도 유효하다.
- 지역/확장팩 선택 없음은 해당 제한만 해제한다. 선택 충돌은 빈 결과로 유지한다. 가려진 지역 선택을 자동 삭제하지 않고 안내/해제를 제공한다.
- 현재 지역 또는 특정 지역/확장팩 선택 시 먼바다·위치 미확인은 제외한다. 지역을 읽지 못하면 임의 대체하지 않는다.
- 전체 보기는 검색/일반 필터를 풀고 정렬은 유지한다. 기본값 복원과 구분한다. 진단용 확인 불가 행은 포함하지 않는다.
- 이름 프리셋은 최대 20개, 필터+정렬을 저장한다. 검색/진단은 제외하고 불러올 때 해제한다. [저장 계약](validation/MVP-01-FILTER-PRESETS.md).

## 화면과 상호작용

- 메인은 어종 목록/즐겨찾기 관리/낚시 기록/설정이 중심이며 목록 선택은 오른쪽 상세를 갱신한다. 진단은 개발자 도구를 켰을 때만 노출한다.
- 간이 목록은 메인 일반 필터를 공유한다. 검색어와 출현 예정 범위는 별도이며 알림 대상은 바꾸지 않는다. 선택하면 독립 상세 하나를 재사용한다. 메인 열기 버튼은 토글이다.
- 타이머는 현재 낚시의 기록만 보여주고 완전히 접으면 비운다. 메인 낚시 기록은 지역·낚시터/날짜/시전·성공 횟수 요약 → 같은 탭 상세 → 목록 복귀, 묶음/전체 확인 삭제다.
- 현재 낚시터 목록은 기존 어종 행을 재사용하며 전체↔수집 숨김 버튼 하나다. 메인의 다른 필터와 독립이다.
- 미끼 준비는 직접 닫기 전까지 유지되는 독립 화면이다. 준비 화면에는 찾기 버튼을 두지 않는다. 첫 미끼 선택지가 여러 개면 각 미끼에 대상이 포함될 수 있다는 짧은 안내만 둔다.
- 아이콘은 툴팁을 제공하고 좁은 폭에서도 정보에 접근할 수 있게 한다. 어종 아이콘은 오른쪽 정보와 세로 중앙 정렬한다. 전승록은 상세에서만, 물고기의 눈은 현재 UI에서 표시하지 않는다.
- 도감 미조회 안내에는 어류도감 열기 버튼을 제공한다. 호환성 차단과 단순 미조회를 구분한다. 큰 화면 구조 변경은 사용자에게 먼저 질의한다.

## 알림·기록 정책

- 알림은 켜기/끄기, 기본/어종별 1~60분, 로컬 표시 채널 22개와 선택 SE.1~16이다. 메시지는 어종 아이템 링크·분 단위 올림 남은 시간·위치 링크, 기록은 한 줄 로그다. Toast는 제거했다.
- 전체 즐겨찾기 알림은 수집 여부로 제외하지 않는다. 미수집만 모드에서는 최종 Uncaught만 포함하고 Unknown은 제외한다.
- 새 도감 등록 시 자동 즐겨찾기 해제는 기본 켜짐이다. 도감 초기 조회·수동 지정·반복 어획은 자동 해제 트리거가 아니다.
- 로그인·캐릭터 전환·재로드·절전 복귀에서 소급/중복/폭주를 방지한다. 시간·날씨 알림을 개인 준비 완료로 표현하지 않는다.
- 시전 시작 미끼는 이후 미끼 변경/소모와 무관하게 보존한다. 성공·명시적 실패·취소·중단·미확인을 구분한다. 미검증 결과나 수량은 추정하지 않는다.
- 기록은 진행 중 묶음을 보관 개수 정리에서 보호하고 총 횟수와 보관 행 수를 구분한다. 이전 형식 가져오기와 삭제/복원은 [타이머·기록 설계](CASTING-TIMER-HISTORY.md)를 따른다.

범위 밖: 자동 게임 조작·미끼 변경·입력 대행·서버 채팅·런타임 외부 조회·호환성 가드 우회. 입질 초 통계, 복수 어획, 먼바다/작살 확장 등은 [로드맵](ROADMAP.md)의 후속/보류 상태를 따른다.
