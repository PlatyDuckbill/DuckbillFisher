# 전체 원본 도입과 일부 조건 표시

날짜: 2026-10-16 · 대상 0.1.12.0 · 전체 연결 수/사용자 대표 화면 확인 통과

## 도입 범위

- 고정 Fish Tracker revision `d0e1ab5bba62c2b57356e690a73676cd4751b64d`의 1110건 전체를 분류했다. JS/YAML 입력 해시는 `data/fishing-source.json`에 고정했다.
- 일반 도감 대응 903종을 schemaVersion=2의 `data/fishing.kr.v2.json`에 연결한다. 추천 위치가 있는 872종은 기본 시간/날씨 예측 대상이며, 위치 없는 보조 31종도 알려진 미끼/메타데이터를 표시한다. 원본에 없는 일반 도감 355종은 상세 없음으로 유지한다.
- 작살 203건은 SpearfishingItem ID와 함께 별도 보존한다. YAML의 미확인 115건과 gig=UNKNOWN을 유지한다. 작살 화면/자동 수집/출현 예측은 이번에 연결하지 않으며 일반 도감 ID/직감 요구로 바꾸지 않는다.
- 한섭 일반 도감과 대응하지 않는 원본 Item 43903/43905/43904/43906은 제외 사유 NoKRRegularLogEntry로 기록했다. 개별 참조 실패는 조용히 건너뛰지 않고 전체 생성을 실패시킨다.
- sourceName은 대조용 영문 이름이다. 화면의 어종/아이템/날씨/스킬/지역 이름은 클라이언트 시트에서 읽는다. dataset의 kr은 한섭 검수 대상이며 표시 언어가 아니다. 글로벌 호환성 확인을 뜻하지 않는다.

## 모델과 UI

- BaitSteps는 ‘순서대로 진행할 단계’ 배열이며 각 단계 내부는 대체 후보다. 기존 BaitPath는 과거 v1 자료 호환용으로 남기며 신형 UI는 BaitSteps를 사용한다.
- 낚아채기/입질 강도/직감 지속 시간 누락을 개별 미확인으로 표시한다. 추천 장소가 없거나 조건이 미확인이면 제한 없음/Always로 예측하지 않는다.
- KR Action 4100 갈고리 낚시, 37595 소박한 루어, 37594 거대한 루어를 실제 시트에서 확인하고 아이콘/이름으로 안내한다. 스킬 실행은 없다.
- 물고기의 눈 지원 여부·터주·원본 추가 버전·추천 낚시터·실제 전승록 Item 링크를 표시한다. 생미끼/직감 대상의 자료가 있으면 ‘준비 조건 펼치기’로 한 단계만 표시해 순환/무한 재귀를 피한다. 기존 필터/선택을 변경하지 않는다.
- 현재 지역 필터에 쓸 Territory ID는 기존 위치 참조에 보존한다. 목록 행의 미끼·시간/조건 요약은 사용자 요청으로 후속 UI 작업에 기록했으며, 이번 목록 변경은 먼바다 표지와 해역 안내에 한정했다.

## 먼바다

- KR IKDSpot의 Main/Sub FishingSpot과 FishParameter.FishingSpot으로 259/259종을 13개 해역·26개 일반/환해류 장소에 연결했다. IKDRoute의 실제 항로 이름/방문 시점도 캐시한다. 일반 좌표 지도 핀이나 일반 낚시 예측으로 변환하지 않는다.
- 13개 해역 모두 항로 시간 정의 1/2/3의 완전한 순환이 존재함을 확인했다. 화면은 전체 방문 가능 시간대 ‘낮/저녁/밤’을 표시한다. 부분 순환은 미확인으로 남기며 보고용 enum 숫자를 게임 시트 숫자에 직접 대응시키지 않는다.
- 방문 시간대는 어종별 출현 제한이 아니다. 이 점과 어종별 미끼/특수 조건 미확인을 화면에 명시한다. 해역 이름으로도 검색할 수 있다.
- 추가 조사: 기존 고정 Teamcraft revision의 ocean-fishing-time.ts enum과 Lulu의 원본/데이터 설명을 읽었다. 전자는 보고용 enum이므로 게임 값과 동일하다고 가정하지 않았다. 후자는 데이터 재배포 허용 범위를 확인하지 못해 복사하지 않았다. 원본/권한을 확인한 먼바다 어종별 조건 보강은 후속이다.

## 좌표와 계산

- 낚시터 294/295/296(map 855), 327(map 856)의 외부 좌표가 KR 시트 계산과 다르다. map 855의 외부 Y에는 수천만 단위 값도 있다. 외부 좌표를 복사하지 않고 기존 KR FishingSpot/Map 계산으로 핀을 표시한다. 차이 4건은 감사 JSON에 남겼고 해당 지도 핀의 인게임 대조는 대기다.
- 시간/날씨 계산은 Framework에서만 한다. 확정된 절대 창을 시작/종료 경계까지 재사용하고, 탐색 범위 내 창 없음은 분 단위로 재탐색해 전체 원본을 매초 장기 검색하지 않는다. 시스템 시각 역행/자료 재조회 시 다시 계산한다. 렌더링은 남은 시간만 갱신한다.
- 예측 범위는 기존 432 날씨 구간/7일이다. 물고기의 눈·직감·선행 어종 조건의 교집합이나 개인 준비 상태를 계산한 완전한 어획 가능 시간은 아니다.

## 실행 결과

- `dotnet run --project tools/FishingDataImport ...` 성공: Regular=903, WithSpot=872, Spear=203, SpearMissing=115, Excluded=4, CoordinateDifferences=4, Failed=0. 원본 전체를 읽고 개별 Item/날씨/장소/지도/전승록을 실제 KR 시트와 대조했다.
- 별도 Plugin Debug 빌드 `.cache/all-details-build/` 성공: 경고·오류 0. 한영 리소스 208키/형식 인자 검사 통과.
- 별도 DLL 내장 JSON을 읽어 schema=2/일반 903/작살 203 확인. 로컬 시트 감사에서 먼바다 259/259·해역 순환 13/13 확인. 정량적인 실행 성능 측정은 별도 미확인이다.
- 사용자 ‘언로드 완’ 확인 후 정규 Debug 빌드 성공(경고·오류 0). 주 DLL 840192바이트/0.1.12.0, Core 29696바이트, ko 리소스 23552바이트/0.1.12.0, manifest InternalName/버전/API 15 확인. 테스트 추가/실행은 하지 않았다. 과거 예측 검증을 새 전체 원본의 게임 검증으로 확대하지 않는다.
- 짧은 진단 summary/v3에 Details/Forecasts/OceanAreas/SpearStored/SpearUnknown을 추가했다. 전체 catalog/v4의 상세 표본 제한은 20종을 유지한다.

## 인게임 결과

- 사용자 summary/v3에서 Plugin=0.1.12.0/Rows=2512/CatalogLoaded, Details=903/903/BuildMatch=True, Forecasts=872/OceanAreas=259/SpearStored=203/SpearUnknown=115를 확인했다. 런타임 연결 수가 정적 대조와 일치한다.
- 선택 어종은 FishParameter 898/Item 29782/Ocean=True, DetailsOnly=False/IncludeOceanFish=True/Displayed=20이다. Displayed는 그 시점 검색/필터 결과이며 전체 연결 수와 구분한다.
- 사용자 ‘문제 없음’으로 안내한 대표 화면 확인을 통과로 기록한다. 개별 어종의 필드별 캡처는 받지 않았고 모든 어획 조건/창 시각/좌표의 정확성까지 검증했다고 확대하지 않는다.
- GuideVisible=False/Scans=0/GuideState=NotSampled, Caught=0/Uncaught=0/Collection=Unknown은 이번 세션 도감 관찰 전 상태다. 자동 수집 실패나 전체 미수집을 뜻하지 않는다.
- 이번 결과 반영은 문서만 변경했으며 빌드/리소스 검사/테스트를 재실행하지 않았다. 한영 전환 조합·외부 좌표 차이 4곳·실제 게임 ET/날씨 대조는 별도 미확인으로 유지한다.

## 게임 확인

1. 로드 후 일반 목록에서 검색/즐겨찾기/수집 필터 해제, 상세 자료만 켜기: Details=903/903, Displayed=903. 예측 872/먼바다 해역 259/작살 보존 203·미확인 115가 기대값이다.
2. 청린핵(1081)의 같은 단계 대체 미끼, 바위조개(319)의 갈고리 낚시, 오르코 물개구리(1305)의 소박한 루어, 선사거북(411)의 전승록 링크를 확인한다. 빈 기술/입질 값은 미확인이어야 한다.
3. 생미끼/직감 대상의 준비 조건을 펼친 뒤 언어를 바꿔 선택/필터가 유지되는지 확인한다. 확정한 값 외에 자동 플레이나 준비 완료 표시는 없어야 한다.
4. 상세 자료만 끄고 먼바다 포함을 켜 ‘갈라디온’을 검색: 목록의 [먼바다]/해역과 상세의 항로 방문 시간대/범위 설명 확인. 수집 상태는 도감 관찰 전 Unknown이어도 정상이다.
5. 결과는 짧은 진단 1개와 화면 이상 여부로 받는다. 외부 좌표 차이 4곳의 지도 핀과 실제 게임 시간/날씨 대조는 별도 확인 대상이다.
