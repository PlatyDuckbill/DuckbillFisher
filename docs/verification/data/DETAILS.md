# MVP-01 상세 정보와 지도 핀 / 초기 출현 예측

갱신: 2026-10-16. Plugin 0.1.5.0 / KR Dalamud 15.0.3.6 / 게임 빌드 2026.10.06.0000.0000. **정적 대조·빌드·10종 연결·황금나비어 한국어 상세/지도 핀 확인**. 예측 정확성·추가 경계는 별도 미검증이다.

후속 갱신: 고정 원본 기준 예측 계산/경계 대조와 Core 601개가 통과했다. 결과는 [예측 검증 기록](../forecast/FORECAST.md)을 따른다. 아래 초기 구현 당시의 미검증 기록과 구분하며 실제 게임 ET/날씨 동시 대조는 대기다.

사용자 우선순위에 따라 입질 초 수 통계의 Teamcraft API 조사/도입은 후속으로 미뤘다. 이번에는 낚시터·지도 핀·미끼·낚아채기·정적 조건과 초기 시간/날씨 창 예측을 구현했다. 자동 수집 필터·알림·캐스팅 타이머까지 완료한 것은 아니다.

위 10종의 어종/아이템/낚시터 연결과 미끼 ID 존재를 대조했다. 지도 좌표는 `1 + pixel * 41 / 2048 / (SizeFactor / 100)`이며 X/Z는 이미지 좌표다. 단순히 100으로 나누는 방식은 쓰지 않는다. 고정 원본 map_coords와 10종 모두 0.00001 이내 일치했다. 핀은 낚시터의 대표 위치이며 실제 게임 표시 위치는 별도 대조해야 한다.

## 구현 경계

- FishCatalog가 Framework.Update에서 FishingSpot·TerritoryType·Map·WeatherRate를 읽고 아이템 ID와 낚시터를 연결한다. 구역 개요 행(PlaceNameMain이 있는 행)은 실제 낚시터로 취급하지 않는다. 지도/지역 참조가 맞는 위치만 게시한다.
- 조건은 내장 JSON의 게임 빌드·FishParameter/Item/FishingSpot ID와 미끼/날씨/직감 대상 이름이 확인될 때 연결한다. 자료가 없는 어종도 기본 목록과 가능한 낚시터/지도 기능을 사용할 수 있다.
- 목록 선택 시 오른쪽 상세 패널에 지도 버튼·미끼 경로·낚아채기·입질 강도·ET/날씨·직감 요구를 표시한다. 상세 조건 필터, 낚시터/지역 검색, 출현 시간순 정렬을 추가했다.
- 지도 요청은 명시적인 클릭만 큐에 넣는다. FishingMapService가 Framework.Update에서 로그인 여부를 확인하고 공개 `IGameGui.OpenMapWithMapLink(MapLinkPayload)`를 호출한다. 설치 DLL 메타데이터와 Dalamud.xml에서 float 인자가 사람이 읽는 지도 좌표이며 API가 지도+핀을 연다는 설명을 확인했다. 명령 실행·입력 대행·이동은 없다.
- 날씨 계산은 Fish Tracker의 고정 `js/app/weather.js` 목표값 함수를 C# uint 산술로 가공했다. MIT 고지에 원본과 변경을 기록했다. Core는 UTC 입력과 날씨 확률 값만 사용하며 게임 라이브러리에 의존하지 않는다.
- 시간대는 1 ET 시간=175 실제 초, 하루=4200초, 날씨 구간=1400초다. ET 자정 통과, 현재/직전 날씨, 연속 창 병합을 처리하며 최대 432개 날씨 구간(실제 약 7일)으로 탐색을 제한한다. 끝이 탐색 범위를 넘으면 종료 미확인, 다음 창이 없으면 범위 내 미발견으로 표시한다.
- 예측은 Framework에서 초당 한 번 초기 10종만 계산/캐시한다. UI에서는 캐시와 UTC 차이로 남은 시간을 표시한다. OS 시각이 뒤로 바뀌면 캐시를 갱신한다. Draw에서 시트/파일 읽기나 날씨 탐색을 하지 않는다. 목록 검색/정렬 갱신은 입력/원본/정렬에 관련된 예측 변경 때만 한다.
- 예측은 통상 시간·날씨 창이다. 물고기의 눈·직감·개인 준비 상태를 적용하지 않으며 완전한 어획 가능 판정으로 표시하지 않는다. 넵토드래곤은 선행 어종 3마리와 직감 지속 시간을 표시하되 달성을 자동 판정하지 않는다.
- 수집 상태는 목록에 아직 연결하지 않았다. 기존 원시 비트 진단의 네이티브 코드/가드는 변경하지 않았다.
- 목록 보고서는 `MVP-01/catalog/v2`로 올리고 데이터 버전·빌드 일치·상세 연결 수·낚시터 연결 수·예측 UTC·어종별 지도/예측을 추가했다. ContentId는 포함하지 않는다.

## 실제 실행한 빌드와 검사

```powershell
dotnet run --project .cache/detail-audit/detail-audit.csproj
pwsh -NoLogo -NoProfile -File scripts/check-localization.ps1
dotnet build src/DuckbillFisher.Plugin/DuckbillFisher.Plugin.csproj --no-restore -c Debug `
  -p:DalamudLibPath=C:/Users/hyogu/AppData/Roaming/XIVLauncherKR/addon/Hooks/dev/
```

- 별도 Debug 출력과 사용자 언로드 확인 후 정규 Debug 출력: 경고 0 / 오류 0. 정규 DLL 실제 존재·버전 0.1.5.0·한국어 DLL 존재를 확인했다.
- 미완성 UI/리소스 연결 중 한 차례 컴파일 오류가 있었고 연결 후 최종 빌드는 성공했다. 실패 빌드를 게임 확인용으로 전달하지 않았다.
- 한국어/영어 리소스 137개 키와 형식 인자 일치.
- Release는 OutputPath `.cache/mvp01-details-release/`를 지정해 빌드했고 경고 0 / 오류 0. ZIP에 주/Core/한국어 DLL과 manifest가 있음을 확인했다. 게시/배포하지 않았다.
- 빌드 DLL 리소스에서 10종 JSON, 고정 source revision, 저작권/MIT 전문 내장을 확인했다. 임베딩으로 기존 패키지 필수 파일 목록을 늘리지 않는다.
- 테스트는 추가/실행하지 않았다. UTC/날씨 경계와 예측 정확성은 별도 검증이 남아 있다. 컴파일/정적 대조를 한섭 예측 정확성 검증으로 표현하지 않는다.

## 게임 확인 요청

사용자 언로드 후 기존 DLL 경로에 0.1.5.0을 빌드하고 재로드를 요청했다.

1. 상세 조건 필터에서 연결 수 10종 확인. 0종이면 목록 진단의 buildMatch/detailRows와 오류를 확인한다.
2. 황금나비어(194) 선택: 미끼 경로, 섬세한 낚아채기, ET 09:00~14:00. 지도 버튼 클릭 시에만 림사 상층 갑판 X10.3/Y11.3 부근 지도/핀 표시.
3. 헬리코프리온(290): ET 08:00~20:00, 직전 안개/흐림 → 현재 작열파 조건과 생미끼 경로. 넵토드래곤(276): 비/폭우와 선행 어종 3마리 조건. 실제 이름은 설치본 시트를 따른다.
4. 시간순 정렬과 현재/다음 창을 고정 Fish Tracker의 예측 및 게임 ET/날씨와 대조한다. 시간·날씨 창이 열려 있어도 직감이 없으면 별도 준비가 필요하다.
5. 언어 전환, 목록 스크롤, 자료 없는 어종의 낚시터/지도, 지도 실패 시 안내와 기존 수첩 진단도 확인한다. 화면 캡처와 목록 진단을 받는다.

- 시간·날씨 창 열림과 종료까지의 카운트다운 문구가 표시된다. 외부 예측/실제 날씨와 시각을 대조한 결과는 없으므로 예측 정확성 검증으로 처리하지 않는다.

남은 항목: 헬리코프리온의 직전 날씨/자정 경계 등 예측 정확성, 넵토드래곤의 직감 상세 표시, 시간순 정렬, 영어 전환과 상태 유지, 자료 없는 어종/다른 낚시터 지도, 지도 실패 경로와 기존 수첩 조회의 회귀 확인. 현재 열린 창의 보고서 start는 현재 날씨 구간에서 탐색한 부분 구간의 시작일 수 있으며 과거부터 이어진 전체 창의 원래 시작을 복원하지 않는다. UI는 열린 창의 남은 종료 시간을 안내한다.
