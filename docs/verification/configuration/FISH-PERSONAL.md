# 어종별 메모·수동 횟수·프리셋 연결 개발본

2026-10-24. 앱 버전0.5.3.0을 유지한 검수용 개발본/schema23이다. 사용자 요청 순서는 **기능 구현 → 사용자 검수 → 버전 업데이트·업데이트 노트 작성·배포**이며 이번 단계에서 공개 ZIP/태그/설치 JSON이나 릴리스 내역을 갱신하지 않는다. [현재 동작](../../product/FISH-PERSONAL.md).

## 구현과 검사

- FishPersonalRecord는 공통 수동 기록만 보관한다. FishPreferences에서 필드별 요청을 Framework에 전달해 메모·횟수·프리셋을 서로 덮어쓰지 않고 저장한다. 세션/복원 세대를 확인하며 마지막 성공본을 유지한다.
- FishPersonalPanel은 공통 상세에 접힘 영역과64개까지의 초안을 둔다. 어종/언어 전환에서 초안을 유지하고 충돌/저장 실패는 메모를 보존한다. 횟수는 수동 증감/입력만, 프리셋은 명시적 적용 버튼만 제공한다.
- 프리셋 연결은 이름이 아닌 저장 ID를 쓴다. 적용은 기존 알림ID를 보존한 목록 복사이며 채널/낚시 효과음을 바꾸지 않는다. 삭제/복원의 없는 연결만 정리하고 메모/횟수는 남긴다. 프리셋 관리는 기존 캐스팅 탭 선택/상단 스크롤로 연결한다.
- CommonSettingsBackup의 선택 필드에 세 항목을 포함했다. 형식1과21/22 백업을 계속 읽고, 과거 백업으로 현재 기록이 비워질 때 복원 전 경고한다. 최대4,096종×1,000자/JSON 이스케이프를 수용하도록 JSON 상한32MB·ZIP96MB로 늘렸으며 WAV는 기존10MB/파일과 정확한 엔트리/해시 검사를 유지한다.
- 별도 `.cache/fish-personal-build/` → 정규 Debug 경고0/오류0·한영964키/형식 인자·문서112개/로컬 링크561개·diff 검사 통과. 설치된 wasdcxz15.0.3.9 참조를 사용했으며 SDK/의존성/lock·네이티브 계약은 변경하지 않았다. 테스트는 요청되지 않아 추가/실행하지 않았다. 실제 인게임·백업 생성/복원·캐릭터 전환·장애 실험·패키징·원격 게시는 실행하지 않았다.

## 사용자 검수 순서

검수 DLL은 `DUCKBILL_ROOT/src/DuckbillFisher.Plugin/bin/Debug/DuckbillFisher.dll`이다. 현재 PC의 루트/참조는 [HANDOFF](../../SESSION-HANDOFF.md#환경과-경로)를 따른다.

1. 어종 상세의 ‘나의 기록’을 펼쳐 한국어·여러 줄 메모를 저장한다. 횟수를 ±로 조절하고 숫자로도 입력한다. 다른 어종/별도 상세/비교 상세와 한영 전환을 오간 뒤 해당 어종 값이 유지되는지 확인한다. 재로드 후에도 저장된 메모와 횟수가 같아야 한다.
2. 저장 전 메모를 고쳐 다른 어종으로 이동했다 돌아온다. 초안은 남아 있어야 하며 ‘되돌리기’는 저장된 원문을 복구해야 한다. 빈 메모 저장은 메모만 지우고 횟수/연결은 유지해야 한다.
3. ‘프리셋 관리’에서 캐스팅 프리셋을 저장하고 상세에서 연결한다. 연결/어종 선택만으로 현재 알림 목록이 바뀌면 안 된다. ‘타이머에 적용’ 후 목록이 바뀌고 채팅 채널·입질/터주/터주왕 소리는 그대로여야 한다.
4. 같은 이름 프리셋을 덮어쓴 뒤 다시 적용하면 새 목록을 사용해야 한다. 연결된 프리셋을 삭제하면 연결만 해제되어야 한다. 낚시 중 적용은 지난 알림을 소급하거나 같은 알림ID를 중복 출력하지 않아야 한다.
5. 테스트용 메모·횟수·연결을 저장하고 **JSON과 WAV 포함 ZIP을 각각 내보낸다.** 개인 기록 수가 미리 보기에 나오고, 값을 바꿨다가 복원하면 세 항목과 프리셋 연결이 함께 돌아와야 한다. WAV·즐겨찾기·채널·캐릭터 수집/기록의 기존 계약도 유지되어야 한다.
6. 실제 현재 백업을 먼저 보관한 뒤 이전21/22 백업을 가져오면 개인 기록이 없는 백업이라는 경고가 나와야 한다. 취소하면 현재 기록은 유지되어야 한다. 이전 백업 복원을 확인하면 개인 기록은 비고 다른 이전 설정은 정상 이전되어야 한다.
7. 좁은 별도 상세·한영·배율·다른 테마에서 입력/버튼/긴 프리셋 이름과 툴팁을 확인한다. 횟수0/상한·노트 글자 수/제어 문자·기록 상한, 저장 실패/이전 요청·64개 미저장 초안/충돌·다른 캐릭터/종료 경계는 별도 확인 대상이다.

사용자 검수 완료 전 앱 버전·업데이트 노트·배포를 진행하지 않는다. 이전 알림/일반 설정 UI·전체 백업/음원·KR/구조의 확인 대기는 [STATUS](../../STATUS.md)를 따른다.
