# MVP-01 남은 시간 정렬

날짜: 2026-10-16 · Plugin 0.1.18.0 · 별도/정규 빌드 통과 · 정렬 사용자 대표 확인 통과

## 범위와 기준

- 사용자 확정: 현재 열린 제한 창은 종료 임박순 → 예정 창은 시작 임박순. 상시는 맨 아래에 두며 제외하려면 기존 ‘시간제만’을 사용한다. [정책](../../product/LIST-SORTING.md).
- 현재 지역은 기존 ‘현재 지역만’ 체크박스 필터로 유지하며 정렬/동률 기준에 넣지 않는다. 다른 필터와 수집 판정은 변경하지 않는다.
- Core의 `FishingWindowOrdering.Key`가 그룹과 절대 UTC 경계를 반환한다. Open+End → Upcoming+Start → Unknown → Always 순이며, 경계가 없는 Open/Upcoming과 NotFound/null은 Unknown 그룹이다. 실패를 상시나 0초로 해석하지 않는다.
- Plugin은 위 키→어종명→FishParameter ID로 정렬한다. 기존 Sort=2 선택을 사용하고 표시는 ‘남은 시간순’으로 바꾼다. 이름/ID/즐겨찾기 우선과 초기 선택은 유지한다.
- 한국어 행/상세의 시간 표시는 ‘종료까지’와 ‘시작까지’를 구분한다. 정렬 콤보 툴팁에 그룹 순서와 예측의 범위를 안내한다. 같은 리소스를 공유하며 위젯 ID는 유지한다.
- 기존 ForecastRevision이 변경될 때 결과를 갱신한다. 초 단위 카운트다운만으로 재정렬하지 않으며 예측 갱신은 기존 Framework의 최대 약 1초 간격을 따른다. 자동 갱신은 스크롤을 맨 위로 보내지 않는다.
- 예측은 기존 추천 낚시터의 일반 ET/날씨 기준이다. 직감/생미끼/전승록 등 개인 조건이나 먼바다 어종별 출현을 확정하지 않는다. 추천 위치가 표시 지역과 다르면 기존 위치 차이 안내를 유지한다.
- 새 이벤트/네이티브 접근/외부 데이터/런타임 HTTP/게임 조작은 없다.

## 인게임 확인 순서와 기대 결과

1. 0.1.18.0 로드 후 검색을 비우고 제한을 넓힌 뒤 정렬을 ‘남은 시간순’으로 바꾼다. 열린 창은 종료까지 짧은 순, 그 뒤 예정 창은 시작까지 짧은 순이어야 한다. 정렬 툴팁과 각 행의 시작/종료 문구를 확인한다.
2. 아래로 스크롤한다. 시각 미확인/범위 내 미발견/먼바다는 열린/예정 그룹 뒤이며 상시는 맨 아래다. ‘시간제만’을 켜면 상시 어종을 제외하고, 끄면 돌아와야 한다. 상세 데이터 없는 어종을 상시라고 추측하지 않는다.
3. ‘현재 지역만’을 켰다 꺼도 정렬은 남은 시간순을 유지하며 포함된 어종만 바뀌어야 한다. 검색·수집·등급 등 기존 필터와도 함께 적용한다.
4. 어종 선택 후 한영 UI를 전환하면 선택/필터가 유지되어야 한다. 열린 창 종료나 예정 창 시작 경계에서 다음 예측으로 순서가 갱신되어야 하며 초가 줄어드는 것만으로 동률 행이 흔들리지 않아야 한다.
5. 결과는 ‘정상’ 또는 문제 화면 한 장을 우선 받는다. 필요할 때만 짧은 진단을 요청하며 전체 로그/반복 도감 검증은 요구하지 않는다.

## 미확인

- 사용자 ‘정렬은 잘 됨’으로 로드와 남은 시간 정렬의 대표 확인을 기록한다. 시간 경계/한영/모든 필터 조합까지 확대하지 않는다.
- 별도 발견: 바다구렁이(Item 24215/FishParameter 670)가 Teamcraft에서는 열린 창(16분 남음)인데 Plugin은 시작까지 약 6시간 28분으로 표시됐다. 사용자 동시 화면을 받았으며 조건 데이터/직전 날씨/캐시 차이 조사로 분리한다. 정렬 정상과 예측 정확성을 구분한다.
- 실제 게임 ET/날씨 동시 대조와 기존 다른 캐릭터 격리 등은 별도 미확인으로 유지한다.
