# 0.1.36.0 전체 보기·사용자 필터 프리셋

갱신: 2026-10-17 · 정규 반영 완료 · 인게임 확인 대기

## 사용자 동작

- 필터 메뉴 맨 위의 ‘전체 보기’는 검색어/진단 제한과 모든 일반 필터를 해제한다. 수집 상태/등급/시간제/즐겨찾기/현재 지역/지역·확장팩/도감 포함 제한을 풀고 먼바다도 포함한다. 정렬은 유지하고 이름 확인 불가 행은 계속 제외한다.
- 기존 기본값 복원은 유지한다. 전체 보기는 제한 해제, 기본값 복원은 남은 시간/터주 이상/시간제/수집 숨김 등 요청한 기본 설정으로 돌아가는 서로 다른 동작이다.
- 사용자 선택으로 이름 붙인 프리셋 저장/불러오기/삭제를 구현했다. 최초 상한은 20개, 이름은 1~32자이며 앞뒤 공백 제거/중복 이름 방지, ID는 이름과 분리한 GUID다.
- 저장 범위는 일반 필터와 정렬이며 캐릭터 공통이다. 검색어/어종 선택/스크롤/진단 옵션은 저장하지 않는다. 불러올 때 검색어와 진단 옵션을 해제해 저장한 범위가 숨은 검색 조건과 충돌하지 않게 한다. 현재 지역 체크는 불러온 시점의 현재 지역을 의미한다.
- 상단 ‘프리셋’ 팝업에 개수/새 이름·저장/저장 목록을 둔다. 선택하면 적용 후 닫히며 삭제는 별도 확인을 받는다. 삭제해도 현재 필터는 유지한다. 목록 안에 별도 스크롤 영역을 만들지 않으며 팝업 높이는 화면의 80% 이내다.
- 즐겨찾기 행의 ‘미래 알림 예약됨’ 문구를 제거했다. 모두 예약 상태이면 상태 설명 줄 높이도 제거한다. 다른 상태의 이유와 기존 알림 예약/중복 방지/발송 정책은 유지한다.

## 유지보수와 저장

- CatalogPresetsPanel은 UI, CatalogPreset은 이름/상한/유효 프리셋 복사, FishPreferences는 Framework 큐와 기존 SavePluginConfig를 사용한 저장을 담당한다. 렌더링 중 파일 읽기/저장/원격 요청 없음.
- schema v11은 v1~v10을 계속 읽으며 기존 필터/즐겨찾기/수동 기록/알림/언어/간략 설정을 보존한다. 역직렬화된 선택적 프리셋의 잘못된 ID/이름/조건·중복/상한 초과 항목만 제외하여 기존 다른 기록을 무효화하지 않는다.
- 프리셋 저장/삭제는 현재 설정 복사에 적용하고 저장 실패 시 이전 상태를 유지한다. 알림/간략 설정 등 같은 Framework 표본의 다른 수정도 변경 플래그 OR로 함께 반영한다. Dispose에서 대기 편집을 폐기한다.
- 이름은 사용자 텍스트 그대로 그리며 ImGui 식별자로 사용하지 않는다. 새 안내는 한영 리소스이며 preferences/v9에 CatalogPresets 개수와 PresetError 코드만 추가했다. 프리셋 이름/캐릭터 ID는 보고서에 넣지 않는다.
