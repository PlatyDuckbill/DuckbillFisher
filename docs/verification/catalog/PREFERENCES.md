# 즐겨찾기·수동 수집 상태와 필터

갱신: 2026-10-16. Plugin 0.1.6.0 / KR Dalamud 15.0.3.6. **빌드·기존 DLL 반영·재로드 후 상태 유지 확인 / 캐릭터 격리·추가 UI 대기**.

## 구현한 동작

| 필터 | 표시 대상 |
|---|---|
| 전체 | 수집됨·미수집·미확인 모두 |
| 수집한 어종 숨기기 | 미수집과 미확인 |
| 미수집만 | 명시적으로 미수집인 어종 |
| 수집됨만 | 수집됨으로 지정한 어종 |
| 미확인만 | 수동 지정이 없는 어종 |

- 상세 패널에서 즐겨찾기 체크, 수집됨/미수집 지정, 수동 지정 해제를 제공한다. 수동 해제는 현재 Unknown으로 돌아간다. 자동 관찰값에 연결하면 기존 CollectionFilter.Resolve의 수동 우선순위를 유지한다.
- 즐겨찾기만 보기와 즐겨찾기 우선 정렬을 추가했다. 이름·ID·출현 시간순 정렬, 검색과 상세 조건/수첩 포함 필터를 함께 적용한다. 동률은 FishParameter ID로 고정한다.
- 즐겨찾기는 공통 설정이다. 수동 기록은 로그인한 캐릭터별로 저장하며 로그아웃 시 표시에서 제거한다. 다른 캐릭터에 이전 기록/선택/미처리 수동 요청을 적용하지 않도록 세션을 확인한다. 실제 캐릭터 전환 동작은 인게임 대기다.
- 저장은 Dalamud의 공개 설정 API를 사용한다. 설정 로드/지원 버전 확인 실패 시 기존 파일을 보존하고 편집을 비활성화한다. 저장 실패 시 이전 메모리 상태와 오류 안내를 유지한다. 사용자 요청 처리와 저장은 Framework.Update에서 수행한다.
- 즐겨찾기/수동 상태는 재로드 후 복원하도록 구현했다. 검색·필터·정렬 선택과 UI 언어는 현재 창/Plugin 세션의 메모리 설정이다.
- 수동 지정을 바꿔 현재 필터에서 빠진 어종은 선택도 해제한다. 언어 변경은 수동 기록/즐겨찾기/선택을 초기화하지 않는다.
- 원시 수집 비트 진단을 목록 판정에 연결하지 않았다. 자동 수첩 상태는 아직 Unknown이며 별도로 검증할 MVP-04다. 입질 초 수·아이템 링크·스킬/날씨 아이콘도 이번 범위에 포함하지 않았다.

- 사용자 언로드 완료 후 위 명령에서 OutputPath를 뺀 정규 Debug 빌드도 경고 0 / 오류 0으로 통과했다. 주 DLL 140800바이트/어셈블리 0.1.6.0, Core·한국어 DLL 존재, manifest InternalName/DalamudApiLevel/AssemblyVersion을 확인했다. 게임 재로드와 실제 결과는 대기다.

## 사용자 확인 순서

1. 0.1.6.0을 로드하고 어종 목록에서 수집 필터를 전체로 둔다. 황금나비어를 검색·선택해 즐겨찾기를 켜고 수집됨으로 지정한다. 목록의 수동 수집됨 표시를 확인한다.
2. 수집한 어종 숨기기로 바꾸면 황금나비어가 사라지고 선택이 해제돼야 한다. 전체 또는 수집됨만으로 바꾸면 다시 보여야 한다. 이때 다른 미확인 어종은 수집한 어종 숨기기에서 계속 보인다.
3. 홍룡을 미수집으로 지정한다. 미수집만 보기에서 홍룡이 나타나고 수동 지정이 없는 어종은 빠져야 한다. 수동 지정을 해제하면 미확인만 보기에 나타나야 한다.
4. 즐겨찾기만 보기/우선 정렬과 검색을 함께 확인한다. English/한국어 전환 시 선택/상태가 유지돼야 한다.
5. 플러그인을 언로드·재로드한 뒤 전체 필터에서 즐겨찾기/수동 기록 복원을 확인한다. 필터 선택 자체는 세션 메모리다. 로그아웃 후 수동 버튼은 비활성화돼야 하며 재접속 시 해당 캐릭터 기록을 복원해야 한다.
6. 가능하면 다른 캐릭터에서 수동 기록이 공유되지 않고 즐겨찾기만 공유되는지 확인한다. 설정 파일을 일부러 손상시키는 확인은 사용자에게 요구하지 않는다.

화면 이상과 목록 진단의 `MVP-01/preferences/v1` 구역을 받아 결과를 기록한다. 저장/복원·캐릭터 격리·추가 UI는 인게임 검증 대기다.

## 사용자 결과

0.1.6.0 재로드 후 즐겨찾기/수동 상태 유지 확인 요청에 사용자가 ‘유지됨’이라고 응답했다. 이 범위의 저장·복원을 통과로 기록한다. 개별 필터·언어 전환·로그아웃/다른 캐릭터 격리는 별도 결과가 없어 대기를 유지한다. 이번 결과 반영은 문서 변경이며 빌드·테스트는 실행하지 않았다.

사용자는 후속 자동 연동이 수첩 조회 시뿐 아니라 새 어종 습득 시에도 갱신되어야 함을 명시했다. MVP-04 요구사항으로 추가했으며 실제 습득 감지 경로는 미구현/미검증이다.
