# MVP-01 지역 선택 UI 개선

날짜: 2026-10-16 · Plugin 0.1.17.0 · 사용자 대표 확인 통과

## 문제와 변경

- 0.1.16.0 사용자 화면에서 높이가 제한된 콤보 팝업 안에 별도 목록 child가 있어 스크롤이 중첩됐다. 필터 기능 자체는 대표 확인을 통과했다. [이전 결과](GEOGRAPHY-FILTERS.md).
- 확장팩은 드롭다운 대신 직접 보이는 체크박스로 제공하고 사용 가능한 폭에 따라 1~3열로 배치한다. 전체 버튼은 확장팩 제한만 해제하며, 체크가 없으면 전체 범위다.
- 지역 후보는 선택된 확장팩에 속한 지역만 노출한다. 검색과 확장팩별 묶음·후보/검색 결과 수를 제공한다. 전체 64개/신생 25개/효월 9개가 현재 자료의 기준이다.
- 지역 전용 팝업에 크기를 명시하고 외부 스크롤을 비활성화했다. 검색·해제·닫기는 상단에 고정하며 나머지 영역의 목록 child 하나만 스크롤한다.
- 확장팩 변경으로 가려진 기존 지역 선택은 자동 삭제하지 않는다. 범위 밖 선택 수/이름 툴팁과 해당 선택만 해제하는 버튼을 제공한다. 메인 패널이 접혀 있어도 안내/해제는 보인다. 검색으로 가려진 선택도 유지한다.
- 표시 후보와 검색 결과는 옵션 참조/확장팩 revision/검색어가 바뀔 때, 가려진 선택은 지역 revision/후보 범위가 바뀔 때 갱신한다. 언어 변경은 ID 선택을 유지하고 새 문자열만 표시한다.
- 기존 그룹 OR/동일 낚시터 AND/현재 지역·수집·분류 조합, 데이터/시트 접근/진단 형식과 Core는 변경하지 않았다. 새 구독·런타임 HTTP·네이티브 접근은 없다.

## 실행한 확인

- 별도 빌드: `dotnet build src/DuckbillFisher.Plugin/DuckbillFisher.Plugin.csproj --no-restore -c Debug "-p:DalamudLibPath=${env:DALAMUD_HOME}/" "-p:OutputPath=${env:DUCKBILL_ROOT}/.cache/geography-ui-build/"` 성공, 경고·오류 0.
- `pwsh -NoLogo -NoProfile -File scripts/check-localization.ps1`: 한영 244키/형식 인자 검사 통과. 사용하지 않는 이전 지역 항목 리소스는 제거했다.
- 사용자 ‘언로드 완료’ 후 같은 build 명령에서 OutputPath를 빼고 정규 Debug 빌드 성공, 경고·오류 0. 주 DLL 912896바이트/0.1.17.0, Core 31744바이트/1.0.0.0, ko 27648바이트/0.1.17.0, manifest DuckbillFisher/0.1.17.0/API 15 확인.
- `git diff --check` 확인. 테스트는 추가/실행하지 않았다. 실제 팝업 위치·스크롤·체크 배치·한영 전환·캐시 갱신과 화면 크기 조합은 인게임 미확인이다.
- 진단은 기존 summary/v4·preferences/v5·catalog/v5를 유지한다. UI 후보를 좁혀도 RegionOptions=64는 원본 후보 전체 수이며 팝업의 현재 후보 수와 구분한다.

## 인게임 결과

- 사용자 ‘정상’으로 안내한 확장팩 체크·지역 후보·단일 스크롤과 선택 UI의 대표 확인을 통과로 기록한다. 개별 화면/확장팩별 수치는 별도로 받지 않았다.
- 모든 화면 크기/한영 전환/숨겨진 선택 해제의 개별 조합까지 검증했다고 확대하지 않는다. 기존 판정/관찰과 정량 성능 검증도 별개다.
- 이번 결과 기록은 문서만 변경했다. 빌드/리소스 검사/테스트를 재실행하지 않았다.

## 재현 순서

1. 기존 DLL 경로로 0.1.17.0 로드 후 지역·확장팩 패널을 펼친다. 확장팩 체크가 바로 보이고 창 폭에 맞춰 배치되는지 확인한다.
2. 신생만 체크 후 지역 선택: 신생 지역만 25개, 효월만이면 효월 지역 9개가 보여야 한다. 모두 해제하면 전체 64개다. 검색을 했다면 검색 결과 수는 별도로 줄어드는 것이 정상이다.
3. 지역 팝업의 스크롤 막대가 목록에 하나만 있는지 확인한다. 휠을 굴려도 검색/해제/닫기 버튼은 고정되어야 한다.
4. 신생에서 림사 상층을 선택하고 효월만으로 바꾼다. 지역 선택은 숨겨져도 유지되고 범위 밖 안내가 보여야 한다. 해당 선택 해제 버튼은 그 지역만 지우며 확장팩/다른 필터는 유지해야 한다.
5. 결과는 ‘정상’ 또는 문제 화면 한 장으로 받는다. 기존 도감/분류/원본 집계 검증은 반복하지 않는다.
