# 0.3.12.0 배포 후보

2026-10-20. 현재 확인 대상은 추가 요청을 반영한 **후보r2**다. 구현·로컬 검사는 완료했으며 새 고정 ZIP의 인게임 대표 확인과 공개는 대기 중이다. 사용자는 완료 후 배포 예정이라고 지시했다. 이전0.3.11.0의 최종 추가 실기 생략 지시를 이번 새 기능의 확인 완료로 확대하지 않는다.

## 범위와 검사

- 추가 합의에 따라 일반 낚시 합계를 표 위 큰 요약 블록으로 분리했고 좁은 폭에서는 세로 배치한다. 지역 막대의 고정 최소 폭/가로 스크롤을 없애 가용 폭을 따르게 하고 긴 수치는 축약/툴팁으로 제공한다. 진행률 색상은0%/25% 미만/50% 미만/75% 미만/100% 미만/완료로 세분화했다.
- 확장팩/지역/먼바다 막대만 어종 목록1개를 재사용하며 일반/도감 전체 합계에는 클릭 기능을 제공하지 않는다. Framework에서 선택 범위만 정렬·수집 필터 배열로 준비하고 보이는 행만 그린다. 목록은 직접 닫기 전까지 유지하며 범위 교체/닫기 때 표시 캐시를 비운다. Unknown은 수집 숨김에서도 유지한다.
- 설치 KR 시트와 공식 패치 안내를 대조해 시로가네641→홍련2/지고천979→효월4를 지원 빌드에서만 보정했다. 먼바다259종의 설명/내장 자료에는 확인된 터주/터주왕 양성이 없어 전체+미확인 안내를 유지하며 유효한 등급 자료가 있을 때 같은 보기를 제공한다. [시트 ID·원본·설명 근거 해시](../../development/DATA-SOURCES.md#03120-거주구-확장팩과-먼바다-분류-점검).
- 사용자 합의대로 메인에 수집 현황 탭과 확장팩→지역 펼침 표·진행 막대를 추가했다. 도감 전체 기준으로 일반 낚시의 전체/터주(왕 포함)/터주왕 보기를 전환하며 먼바다는 별도다. 수동 우선/Unknown/캐릭터 세션과 고유 어종 집계를 유지한다. [동작·확인 순서](../catalog/UI.md#03120-수집-현황과-메인-진입-2026-10-20), [영어 요약](../../releases/0.3.12.0.md).
- 메인의 간이 목록 버튼을 열기 고정에서 Toggle로 바꿨다. 업데이트 안내는 메인 OnOpen에서 미확인 버전을 표시한다. 개발판과 배포판의 버전이 같고 이미 확인했다면 생략되는 기존 저장 계약은 유지한다. 이번 사용자 상황이 이 조건이었는지는 실제 설정/실기 근거가 없어 단정하지 않는다.
- 0.3.11.0의 누락 시각을 기존 배포 기록의2026-10-20T07:59:10Z로 보완했다. 새 후보는 사용자 지시에 따라 배포 요청 무렵2026-10-20T08:09:35Z를 기록했다. 표시는 한국 시간의 년·월·일·시까지다. 날짜 인자를 필수화해 다음 이력의 생략을 컴파일 단계에서 막는다. 기존 공개 ZIP/태그는 바꾸지 않았다.
- 별도 `.cache/collection-progress-r2-build/`→정규 Debug와 최소 참조 `.cache/compat-15.0.3.6/full/` Release 직접 빌드는 모두 경고0/오류0. 한영720키·형식 인자 검사를 통과했다. 테스트 추가/실행 없음. SDK/lock 파일·네이티브 계약·설정schema15는 유지한다.
- `scripts/prepare-release.ps1`로 고정 ZIP·체크섬·후보 설치 JSON을 준비했다. 추출7파일 모두 Release 출력과 SHA256 일치, Plugin/한국어 DLL0.3.12.0·API15·csproj/manifest/후보 JSON의 Changelog 일치, 내장 조건/등급/THIRD-PARTY-NOTICES와 원본 해시 일치를 확인했다. 참조는 Dalamud15.0.3.6/FFXIVClientStructs7.57.0.9376/Interop1.0.0.0이다. 결과는 `.cache/release-build/0.3.12.0-r2-validation.json`에 있다.
