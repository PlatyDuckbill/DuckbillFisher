# 0.3.12.0 배포 후보

2026-10-20. 구현·로컬 검사는 완료했으며 고정 ZIP의 인게임 대표 확인과 공개는 대기 중이다. 사용자는 완료 후 배포 예정이라고 지시했다. 이전0.3.11.0의 최종 추가 실기 생략 지시를 이번 새 기능의 확인 완료로 확대하지 않는다.

## 범위와 검사

- 사용자 합의대로 메인에 수집 현황 탭과 확장팩→지역 펼침 표·진행 막대를 추가했다. 도감 전체 기준으로 일반 낚시의 전체/터주(왕 포함)/터주왕 보기를 전환하며 먼바다는 별도다. 수동 우선/Unknown/캐릭터 세션과 고유 어종 집계를 유지한다. [동작·확인 순서](../catalog/UI.md#03120-수집-현황과-메인-진입-2026-10-20), [영어 요약](../../releases/0.3.12.0.md).
- 메인의 간이 목록 버튼을 열기 고정에서 Toggle로 바꿨다. 업데이트 안내는 메인 OnOpen에서 미확인 버전을 표시한다. 개발판과 배포판의 버전이 같고 이미 확인했다면 생략되는 기존 저장 계약은 유지한다. 이번 사용자 상황이 이 조건이었는지는 실제 설정/실기 근거가 없어 단정하지 않는다.
- 0.3.11.0의 누락 시각을 기존 배포 기록의2026-10-20T07:59:10Z로 보완했다. 새 후보는 사용자 지시에 따라 배포 요청 무렵2026-10-20T08:09:35Z를 기록했다. 표시는 한국 시간의 년·월·일·시까지다. 날짜 인자를 필수화해 다음 이력의 생략을 컴파일 단계에서 막는다. 기존 공개 ZIP/태그는 바꾸지 않았다.
- 별도 `.cache/collection-progress-build/`→정규 Debug와 최소 참조 `.cache/compat-15.0.3.6/full/` Release 직접 빌드는 모두 경고0/오류0. 한영710키·형식 인자 검사를 통과했다. 테스트 추가/실행 없음. SDK/lock 파일·네이티브 계약·설정schema15는 유지한다.
- `scripts/prepare-release.ps1`로 고정 ZIP·체크섬·후보 설치 JSON을 준비했다. 추출7파일 모두 Release 출력과 SHA256 일치, Plugin/한국어 DLL0.3.12.0·API15·csproj/manifest/후보 JSON의 Changelog 일치, 내장 조건/등급/THIRD-PARTY-NOTICES와 원본 해시 일치를 확인했다. 참조는 Dalamud15.0.3.6/FFXIVClientStructs7.57.0.9376/Interop1.0.0.0이다. 결과는 `.cache/release-build/0.3.12.0-validation.json`에 있다.
