# 0.4.0.0 배포

2026-10-20. 사용자가 기존 미공개0.3.12 후보 전체를0.4.0.0으로 바꾸고 마지막 문구/아이콘/먼바다 해역 구분 후 배포하라고 지시했다. 0.3.12는 공개 이력에 추가하지 않는다. 최종 추가 인게임 확인은 이 마무리 배포 지시에 따라 생략하며, 빌드·패키지/자료 검사와 실제 게임 확인을 구분한다.

## 범위와 검사

- 메인 수집 현황: 큰 일반 낚시 합계, 확장팩→지역별 전체/터주/터주왕 표·유동 폭 진행 막대, 먼바다 전체와13개 해역별 수집 현황이다. 확장팩/지역/해역 막대에서 필터를 가진 독립 어종 목록1개를 재사용하고 직접 닫기 전까지 유지한다. 일반/도감/먼바다 전체 합계는 클릭 대상이 아니다. 선택 범위만 준비하고 보이는 행만 그리며 수동 우선·Unknown·세션 경계를 유지한다.
- 합계 옆 클릭 안내는 접지 않고 표시한다. 상세 규칙은 하단 기본 접힘 ‘수집 규칙’으로 옮겼고 색상 기준 설명은 표시하지 않는다. 서로 구분되는 진행 색상·전체 수치 툴팁은 유지한다. 메인의 어종 목록/수집 현황/즐겨찾기 관리/낚시 기록/설정과 진단 탭에 기존 아이콘 폰트로 아이콘을 추가했다.
- 업데이트 내역은 강조된 ‘새 기능 · 수집 현황’ 소개·기능 설명5항목과 ‘기타 개선’2항목(간이 목록 토글/메인 탭 아이콘)으로 구분했다. 시로가네/업데이트 안내 표시 설명과 문구 조정 자체는 이번 공개 내역에 넣지 않는다. 해당 구현은 보존했다. 한영 내장 내역·manifest/후보 설치 JSON·[영어 Release 본문](../../releases/0.4.0.0.md)을 대조했다.
- 새 이력의 시각은 배포 요청 무렵2026-10-20T08:43:34Z이며 한국 시간의 년·월·일·시까지 표시한다. 0.3.11.0의 누락 시각 보완과 메인 진입 시 미확인 버전 표시 동작도 포함한다.
