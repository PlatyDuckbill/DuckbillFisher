## 변경과 확인 범위

- 직감 진행도/종료 후 재집계·실제 수령 수량 연결, 터주 회차 자동 기록과 수동 보정, 필터 외 소지 미끼/선행 미끼, 이름 명령/물고기 우클릭 상세, 일반 어종 수량 안내와 복수 어획 기록이다. [최종 로직 검토](../fishing/TIMER-HISTORY.md#배포-전-기능로직-재점검-개발본-2026-11-05).
- 이름 명령과 채팅 물고기 링크는 이전 개발본의 사용자 대표 정상 보고가 있다. 새 수정본의 직감/소장품·터주 회차/재로드·미끼 필터/폭·우클릭 제외 경계는 확인 대기다.
- 일반 수량 자료는21종(이중21·삼중10), 직감 선행43종 중15종/삼중7만 포함한다. 전수 자료·현재 획득력의 보장값은 아니다.
- 테스트는 추가/실행하지 않는다. 내장 한영 안내·설치 manifest·GitHub 안내는 같은6개 사용자 기능 문장으로 맞춘다. 최근10개 내장 이력 유지를 위해0.4.0.0 항목과 전용9개 리소스 키를 제거한다.
- PublishedAtUtc는 준비 시각2026-11-05T12:37:34Z이며 실제 GitHub 공개 시각은 아니다.
