## 변경과 검사

- 알림별 이름·초·사용 여부·기본SE와 +/− 편집, 별도 설정/이름 있는 프리셋, 기존 시전 타이머와 별도의 루어 효과 중첩 관찰 후 경과를 제공한다. 상단은 물고기 아이콘 어종 보기와 스톱워치 설정이다. [계약·KR 관찰 근거·실기 순서](../fishing/TIMER-HISTORY.md#복수-시전-알림과-루어-경과-개발본-2026-10-23).
- 수집/미수집은 캐릭터별로 로컬 저장하고 수동→현재 관찰→저장 백업→Unknown 순으로 사용한다. 저장 상태를 현재 도감 전체 대조 성공으로 표시하지 않는다. [저장·실기 순서](../collection/GUIDE-SNAPSHOT.md#수집-상태-로컬-백업-개발본-2026-10-23).
- 기존 구조 정비·KR15.0.3.9 조합 추가도 포함한다. [구조 범위/기존 테스트 결과](../ARCHITECTURE-TESTS.md)·[정확한 KR 모듈 조합](../native/NATIVE-RUNTIME-DAL4KR.md#15039-대응과-반복-검사-2026-10-23)을 따른다. 이번 작업에서 테스트는 명시 요청 없어 추가/실행하지 않았다. SDK/lock/정적 자료·기록schema2는 유지하고 설정schema20을 사용한다.
- 검증한 최소 지원 `.cache/compat-15.0.3.6/full/`로 별도 Release `.cache/release-build/0.5.2.0/`를 빌드해 경고0/오류0. 한영884키/형식 인자 검사와 `scripts/prepare-release.ps1`을 통과했다. Plugin/한국어 리소스 DLL0.5.2.0·API15·프로젝트/manifest/후보 설치 JSON의 Changelog/Description 일치다.
- 추출7파일 모두 빌드 출력 SHA256 일치, 내장 조건/등급/고지3자료의 원본 해시 일치를 확인했다. 결과 `.cache/release-build/0.5.2.0-validation.json`. 이것은 실제 게임 동작 확인이 아니다.
