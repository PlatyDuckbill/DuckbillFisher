# 코드 구조 정리와 관리 코드 테스트

확인일: 2026-10-22. 사용자 요청으로 테스트를 추가·실행했다. 공개판은0.5.1.0이며 이번 개발 DLL은 같은 버전의 별도 소스다. ZIP/태그/원격 저장소는 변경하지 않았다.

## 변경과 유지한 계약

- Core/Plugin/테스트를 기능별 디렉터리로 나눴다. assembly/namespace/InternalName, 설정 직렬화 타입/필드/schema19, 기록schema2, 한영854키와 리소스 이름은 유지한다.
- 설정 모델·검증·파일 접근 없는 표시 설정 변환을 분리했다. 세션/저장/채팅 채널 처리는 Plugin에 남긴다. 기존18이하 최대 예정0→null, 이전 간이 즐겨찾기와 일정 기본값 변환을 보존한다.
- 반복 사용하던 직업18·상태850/568·액션4105는 Game/Contracts/FishingGameIds에 이름을 붙였다. 표본200ms/유효1초는 관찰기에 유지한다. 네이티브 허용 조합/오프셋/시그니처를 변경하지 않았다.
- 기록 Store는 종료 미처리 건수 출력만 콜백으로 받고 실제 로그 형식은 Plugin.cs에서 유지한다. SDK/의존성/lock 파일과 조건/등급 자료는 변경하지 않았다. 미사용 CollectionFilter.ShouldNotify는 제거하고 실제 알림 예약기 정책을 검증한다.

## 한계와 대표 재확인

테스트는 Core 프로젝트와 csproj에 명시한 실제 Plugin 정책/저장 파일을 사용한다. 가짜 게임 객체·구현 복사본·실제 사용자 기록은 사용하지 않는다. xUnit 이외 테스트/모킹/커버리지 패키지는 추가하지 않았다.

게임/DLL 네이티브 계약·Framework 관찰/큐 세션 경계·Dalamud 설정 전체 직렬화/채팅 채널 변환·UI 렌더링·실제 음원·사용자 데이터의 장애 조합은 자동 검증 범위 밖이다. 현재 자료 전체 판독 통과는 모든 어종 예측값의 독립 대조를 뜻하지 않는다. Linux 실행은 CI에서 별도 확인해야 한다.

1. 정규 Debug를 로드하고 메인/간이/일정표/타이머가 열리는지 확인한다.
2. 기존 즐겨찾기·수동 수집·프리셋·예정/잔여 빈칸과 범위를 확인하고 한영 전환·재로드 후 유지되는지 본다.
3. 직접 시전1회 뒤 타이머·기록 요약/상세·삭제·재로드를 확인한다. 기존 기록이 유지되고 삭제한 묶음이 다시 나타나지 않아야 한다.

2026-10-22 사용자 안내에 따라 현재 게임 실행 불가로 위 인게임 대표 확인은 아직 수행하지 못했다. 확인 대기를 유지하고 이번 작업을 종료했다. Release 준비/게시·원격 CI 결과도 미확인이며, 기존 공개판/다른 캐릭터/친구 PC 확인 범위를 자동 확대하지 않는다.
