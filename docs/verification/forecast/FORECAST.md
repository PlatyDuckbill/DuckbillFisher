# 시간·날씨 예측 계산 대조

갱신: 2026-10-19 · 개발 0.3.2.0. 웹 실제 표시·DLL 계산·게임 실기를 구분한다.

## 현재 웹 표시 대조 (2026-10-19)

사용자 요청으로 과거 Teamcraft 불일치의 추정 원인 추적을 중단하고, [FF14 Fish Tracker](https://ff14fish.carbuncleplushy.com/)와 [Teamcraft](https://ffxivteamcraft.com/)의 현재 표시를 비교했다. 두 사이트는 커뮤니티 자료이며 공식 게임 판정의 정답으로 간주하지 않는다. 제품 코드/자료/예측 정책은 변경하지 않았다.

### 방법과 재현 자료

- 사용자 브라우저/계정과 분리한 임시 Chrome 155 세션에서 실제 배포 페이지의 JavaScript를 실행했다. 사이트 소스의 함수만 추출해 돌린 이전 조사와 구분한다. 로그인/알람 등록/서버 저장 없이 공개 페이지를 읽었다. Teamcraft 표본은 익명·지역 KR·v11.4.32이며 일반 예측 버튼만 읽고 Fish Eyes 버튼은 제외했다. Tracker도 fishEyesEnabled=false를 확인했다.
- Tracker는 `2026-10-18T15:09:02.427Z`(KST 10-19 00:09:02)에 표시 행의 상태·텍스트·툴팁용 절대 시각(data-val/data-prevclose)을 함께 수집했다. Teamcraft는 KST 00:14:12~00:15:21에 12종을 순차 조회했다. 각 페이지를 읽은 UTC로 **우리 Core DLL을 호출**했으며, 세 화면을 한순간에 동시에 촬영하거나 우리 인게임 UI를 읽은 결과는 아니다.
- 대상은 Item ID로 연결하고 제품 조건 JSON과 설치 KR 시트의 해당 낚시터 확률표를 사용했다. Upcoming은 시작과 확인 가능한 종료, Open은 종료를 대조했다. 현재 열린 구간의 원래 시작을 복원하지 않는 Core 특성 때문에 Open 시작은 일치 판정에서 제외했다.
- Tracker는 밀리초 차이를 그대로 보존했다. Teamcraft의 초 단위 카운트다운은 관찰 UTC에 더해 목표 시각을 환산했다. 정수 표시와 약 1초 갱신 주기를 고려해 2초 이내를 비교 허용치로 두었으며, 일치 표본의 실제 최대 차이는 0.444초였다. Teamcraft의 미래 출현 종료 시각은 카운트다운에서 얻을 수 없어 검증하지 않았다.
- [Tracker 원시 표시/대조 CSV](reports/forecast-live-2026-10-19/fish-tracker.csv), [Teamcraft 원시 표시/대조 CSV](reports/forecast-live-2026-10-19/teamcraft.csv)에 어종 ID·관찰 UTC·사이트 표시·Core 상태/UTC·차이를 보존했다. CSV는 UTF-8 BOM이며 이름을 제외한 상태/숫자는 언어 독립적이다. 캐시의 수집/계산 도우미는 Invoke-ForecastBrowser.ps1, Capture-Teamcraft.ps1, Compare-LiveForecasts.ps1이다. 테스트 코드/스위트가 아닌 현재 공개 자료 관찰용 도우미다.
- 비교한 Core는 커밋 e0bc578의 개발0.3.2.0 출력이며 SHA256=`B248E42B9BD986EFAEA759A410270E2830E1CDB69CDA4794D6F75CC0A8A596CC`. 조건 JSON SHA256=`172BF562969B0F8D17199F0DA12085291E6D0C34DB38910EB7A235A10F8307A0`, KR 빌드 `2026.10.06.0000.0000`이다.

의미 있는 Tracker 차이는 아래 5종이다. 표는 모두 **KST 2026-10-19 00:09:02의 비교**이며 시각도 KST다.

| 어종 | 우리 자체 시간·날씨 예측 | Tracker 표시 |
|---|---|---|
| 잠수인형(33240) | 00:59:10~01:16:40 | 19:39:10~19:56:40 |

| 쿠노(8763) | 자체 시간·날씨 제한 없음(Always) | 00:53:20~01:45:50 |

- 이 5종은 모두 직감 선행 어종이 있다. Tracker는 대상 어종의 조건에 **선행 어종의 출현 구간과 직감 지속 시간**을 교차시킨다. 우리 Core는 대상 어종 자체의 시간/날씨만 계산한다. 따라서 값 차이가 확인됐으며, 외부 화면의 정지/캐시 문제로 설명할 필요가 없는 현재 사례다. Tracker도 사용자의 실제 선행 어획 상태를 관찰한 것은 아니다.
- Teamcraft에서는 잠수인형/스테타칸투스가 우리 자체 시간 조건 계산과 일치했다. 칠채천주/쿠노는 일반 타이머 자체가 없었다. **사이트 둘이 직감 조건을 동일하게 처리하지 않는다.** 한 사이트의 시각으로 무조건 덮어쓰면 현재 제품의 예측 의미가 바뀐다.
- **나미타로는 추가로 원본 조건 차이가 있다.** 우리 자료와 Tracker의 기본 조건은 현재/직전 날씨 배열이 비어 있지만, Teamcraft 배포 자료는 현재 날씨 `9,10`(번개/뇌우)을 가진다. 실제 Teamcraft 페이지는 다음 출현 카운트다운을 표시했다. 어느 표현이 실제 대상 어종의 직접 조건인지, 선행 어종의 조건을 포함한 표현인지는 게임 근거 없이 단정하지 않는다.
- 바다구렁이(24215)는 현재 비교에서 일치했다. 우리/Tracker의 다음 구간은 KST 10-19 01:40:00~02:03:20이며 Teamcraft의 시작 카운트다운도 일치했다. 과거 불일치가 해결됐거나 없었다는 뜻은 아니다.
- 긴 대기 표본도 일치했다. 신들의 사랑은 KST 10-27 05:56:02.5, 바다일등성은 10-27 17:14:10, 두둑지갑은 11-02 05:56:40 시작이다. 7일 밖 표본에 대해 Tracker 절대 시각·Teamcraft 시작 카운트다운과 30일 Core 검색 결과가 맞았다.

## 0.3.2.0 검색 범위 확대 (2026-10-18)

- 기존 432개 날씨 구간(약 7일)을 현재 UTC부터 실제 **30일**로 확대했다. 최대 1853개 구간으로 계산량을 제한하며 양 끝의 부분 구간도 포함한다. 시작이 범위 밖이면 제외하고 끝을 확인할 수 없으면 End=null을 유지한다. 물고기의 눈 효과나 직감 발동 여부는 계산하지 않는다.
- 코드의 SearchDays를 미발견 문구·범위 툴팁·진단에서 함께 사용한다. 메인 목록과 상세 출현 표시 위에 물고기의 눈 미사용 기준 안내를 추가했다. 한영 리소스를 사용하며 번역 변경으로 예측을 초기화하지 않는다.
- 지역 확률표/조건 실패는 Unknown, 정상 검색에서 범위 내 출현 없음은 NotFound다. 날씨 대안은 OR로 처리한다. 기우어/폭풍왕의 비(7)·눈(15) 조건에서 통상 확률표에 눈이 없어도 비 예측은 유지한다. 설치 KR 시트의 원래 확률 순서와 중복 날씨 행을 보존한다.
- 고정 시각 `2026-10-18T06:00:00Z`와 제품 조건 JSON·설치 KR 시트로 실제 1258종을 계산했다. Always=813/Open=70/Upcoming=373/Unknown=2, NotFound=0. Unknown은 원래 ConditionsKnown=false인 Item52014/52015다. 이 결과는 고정 시각의 자료 계산이며 모든 시각/인게임 확인이 아니다.
- 이전 7일 범위 밖의 다음 출현 6종을 찾았다: 신들의 사랑(24995), 바다일등성(33316), 두둑지갑(49794), 푸누사냥어(49795), 헤리티지참바리(49799), 제파 보포(52008). 예: 두둑지갑은 `2026-11-01T20:56:40Z~21:02:30Z`다.
- 시트/입력 준비 후 1258종의 단일 계산은 이 PC에서 약 6.5ms였다. JIT/호스트/시각에 따라 달라지는 참고 측정이며 인게임 프레임 성능 보장이 아니다. 기존 경계까지 결과 재사용·NotFound 분 단위 재검색을 유지해 Draw에서 계산하지 않는다.
- 현재 KR 참조로 별도→정규 직접 Debug 빌드(경고0/오류0), 리소스609키·문서 검사와 실제 자료 계산을 수행했다. 테스트 추가/실행·인게임·패키징·배포 없음. 바다구렁이 비교는 [별도 조사](OPEN-WINDOW-DIAGNOSTICS.md#0320-재조사-2026-10-18)를 따른다.

재현: 개발 DLL 재로드 후 메인 목록/독립 상세의 미사용 안내·툴팁, 한영 전환, 긴 대기의 현지 날짜/남은 시간, 기존 출현 중→종료 전환을 확인한다. 기본 시간제/등급/수집 필터 때문에 어종이 가려지면 해당 필터를 해제한다. 부분 확인 2종은 예측 불가로 유지돼야 한다. 실제 게임 확인은 대기다.

## 남은 범위

- 실제 게임의 ET와 현재/직전 날씨를 같은 UTC 시각에 기록해 대조한 결과는 아직 없다. 커뮤니티 출현 조건이 한섭에서 실제 어획 조건과 일치하는지도 이번 계산 검증으로 확정하지 않는다.
- 현재 열린 창의 start는 현재 날씨 구간에서 잘릴 수 있다. 과거부터 이어진 원래 시작 시각은 복원하지 않는다. UI는 열린 창의 종료까지 남은 시간을 표시한다.
- 당시 검색 제한은 432개 날씨 구간이었다. 현재 30일 범위는 위 0.3.2.0 기록을 따른다. 물고기의 눈·직감·개인 준비 상태와 실제 어획 가능 여부는 별개다.
- 인게임 정렬/영어 전환·넵토드래곤 직감 상세 등 기존 추가 UI 확인은 [상세 검증 기록](../data/DETAILS.md)에 남아 있다.

계산 수정 사항이 없어 Plugin 재빌드/언로드/재로드는 요청하지 않았다. 다음 구현 단위는 MVP-01 즐겨찾기·수동 수집 상태 및 필터다. 미끼/생미끼 아이템 링크·스킬/날씨 아이콘은 [후속 목록](../../product/ROADMAP.md)에만 추가했다.
