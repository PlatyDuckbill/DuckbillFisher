2026-10-25. [현행 제품 계약](../../product/NEXT-FISH-RECOMMENDATION.md#0600-구현-계약), [별도 출현 알림](../alerts/SPAWN-ALERTS.md#현재-낚시터-출현-알림-0600-2026-10-25).

## 간소화한 현재 동작

- 사용자가 조건/일정 중심 간소화와 탭 기준, 추천 테스트 교체/실행을 명시 승인했다. 준비 시간·첫 투척 예상·종합 점수·최적 보관량/경로·롱카 특례와 저장 전략 필터를 제거했다. 일반 게임 예측/낚시 기록의 생미끼 보관 관찰은 변경하지 않았다.
- 지금 노릴 어종은 현재 출현/30분 이내, 밑작업은 조회 기간 안 생미끼·직감 조건 대상, 출현 드문 순은 같은 기간의30일 횟수 오름차순이다. 상시는 희귀 탭에서 제외한다. 앞 두 탭은 출현 중/예정/상시 순이고 준비 시간 때문에 후보를 제외하지 않는다.
- 자체 제한 대상의 일정/빈도/다음 출현은 대상 기준이다. 자체 상시 대상은 이 기간의 대표 준비 어종 실제 구간과 이름을 표시한다. 직감 지속 시간 누락만으로 제외하거나 여러 구간을 합치고 버프 길이로 늘리는 계산은 없다. 준비 어종 전체의 자체 구간과 요구량을 팝업에서 확인한다.
- 기존 전체 폭·세 줄/세 열·왼쪽 탭/오른쪽 조작 한 줄·고정 하단·수동 갱신·관련 링크 동선을 유지했다. 추천 근거는 일정/조건 표와 짧은 이유이며‘조회 정보’에는 빈도 기준과 기간만 둔다. 목록 미끼/직감/지도는 기존 FishRowRenderer를 공유한다.
- Core는 시간/자료 입력만 사용한다. Framework의 관리 snapshot 캡처/단일 작업자·취소/요청 세대·캐릭터 격리, 자료/수집/시간 변경 시 갱신 안내를 유지했다. Draw 장기 계산/파일 읽기·런타임 HTTP·게임 조작은 없다.

## 게임 대표 확인 대기

1. 기본3시간/미수집에서 세 탭과 기간/필터/갱신을 확인한다. 지금 탭은 현재/30분 이내이고, 기간을24시간으로 늘려도 지금 탭에30분 이후 대상이 들어가지 않아야 한다. 밑작업/희귀는 선택 기간을 따른다.
2. 밑작업에서 단일 생미끼·긴 연쇄·직감 요구 어종을 찾고 이름/요구량/실제 조건을 확인한다.‘준비 완료 가능’, 준비 시간/첫 투척 추정, 점수/보관 수량/롱카만의 경로가 남지 않아야 한다.
3. 칠채천주처럼 자체 출현 시각이 없는 대상은‘직감 준비 어종’의 실제 일정/이름을 표시하고, 팝업에 각 선행 어종의 일정과 남채어3/등채어3/녹채어5를 구별한다. 일반 제한 대상의 다음 출현은 목표 자체 일정이어야 한다.
4. 롱카의 물뱀과 다른 연쇄 생미끼 대상 모두 공통 미끼 경로/직감 배지/위치 링크를 유지하는지 확인한다. 보관 최적화 안내는 없으며 준비 순서·보관 활용은 정보를 보고 선택한다.
5. 출현 드문 순의 횟수/공동 순위/다음 출현을 비교한다. 대표 준비 어종 기준이면 이름이 보이고 상시는 제외된다. 실제 낚일 확률/직감 발동 횟수로 설명하지 않아야 한다.
6. 읽는 동안 순위/조회 시각이 유지되고 잔여와 갱신 안내만 변하는지 확인한다. 갱신·필터 변경 후 일정이 바뀌며 탭 전환은 다시 조회하지 않는다. 화면 이탈/캐릭터 전환/연속 요청에 오래된 팝업/결과가 돌아오면 안 된다.
7. 기본980px/최소700px·UI 확대·한영에서 헤더 한 줄/목록 세 줄·세 열·하단이 잘리지 않는지 확인한다. 추천 근거의 조건 표·조회 정보·도움말, 행/상세·지도·미끼 링크를 대조한다. 최신 메뉴/도감 공통 경고의 별도 확인 대기도 유지한다.
