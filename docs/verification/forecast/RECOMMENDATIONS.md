# 0.6.0.0 터주작 추천 개발본

2026-10-25. [제품 계약/초기 추정/출처](../../product/NEXT-FISH-RECOMMENDATION.md), [현재 낚시터 알림](../alerts/SPAWN-ALERTS.md#현재-낚시터-출현-알림-0600-2026-10-25).

## 변경 범위

- Core의 단계별 준비 계획·시간/날씨 달력·단일 조건 참고 빈도와 Plugin의 작업자/수집 snapshot/추천 탭을 추가했다. 기존 FishingForecast의 직감 예측 계약은 바꾸지 않았다.
- 첫 진입/필터/다시 추천으로 계산하고 읽는 동안 순위를 유지한다. 조회 시각·현재 잔여·지난 회차·새로 수집된 후보를 구분한다. 미확인 수집은 명시 선택 때만 포함하며 준비 미확인/범위 밖 후보의 접근 경로를 남긴다.
- 보관 사용 여부는 검토한 롱카 경로만 바꾼다. 추가 여분1마리의 작업량/시작 참고는 별도이며 점수 가산이 없다. 목표 시전 전에 남는 연쇄와 직감 유효 시간을 계산한다.
- 사용자 첨부 화면에서 확인된 반복 정보와 과한 준비 표시를 줄였다. 좌우 배치를 유지하고 목록은 두 줄/전체 스크롤, 오른쪽은 출현·추천 이유·다음 출현·상세/지도에 집중한다. 준비 시간 요약/시간축/작업 목록/경로 선택/일정표 버튼을 제거했다. ‘추천 기준’은 탭에 맞는 짧은 표로 바꾸고 점수 합산식을 노출하지 않는다.
- 미리 준비의 작업량은 출현 전 부분만 계산하고, 출현 전에 끝난 어획만 사전 확보 마릿수로 표시한다. 자체 시간·날씨 제한 없는 직감 대상은 선행 준비를 유지한다. 미래에 열릴 선행 구간을 이미 열린 준비 기회로 표시하지 않는다.
- 후속 문구/배치 개선: ‘7분 후 남음’은 알림용 완성 문장을 잔여 시간에 삽입한 문제로, 추천 전용 단위 값으로 분리했다. 고정 출현 시각 없는 직감 대상은 발동 조건/실제 어종·수량을 안내한다. 희귀 목록에 목표 자체의 다음 출현을 추가하고, 선행 출현과 빈도 기준은 별도로 유지한다. 점수·선별·정렬은 변경하지 않았다.
- 상단은 조작/탭 두 행, 조회 시각은 하단이다. 최신 첨부4장에 따른 후속 정돈은 목록 세 번째 줄을 탭별 비교 정보로 사용하고 오른쪽을 출현 요약→추천 이유→상세/지도→작은 ‘계산 근거’ 펼침 순으로 묶었다. 출현 시각/잔여를 합치고 오늘/내일/이번 이후를 구분한다. 도움말/툴팁은 폭을 제한하고 긴 기간 설명을 나눴다. 추천 이유는 실제 준비 어종·마감·간격·빈도 비교의 짧은 사실이며 펼침에 출현 시각을 반복하지 않는다. 빈도 순위는 작업자에서 계산하고 동률은 공동 순위다.
- schema24는 현재 낚시터 알림 기본ON 및 캐릭터별 출현 알림 회차 종료 기록을 추가한다. 설정 백업은 스위치만 포함하고 발송/회차 기록은 포함하지 않는다. 이전 백업의 누락 스위치는 기본ON이다.

- 후속 알고리즘 revision4: 미리 준비는 실제 사전 확보 어획이 있어야 한다. 직감용 어획/2단계 이상 생미끼/일반보다 큰 대표 예산을 포함하고, 일반 생미끼 한 마리는 준비 어종이 목표 출현 전에 사라질 때만 포함한다. 작업 일부만 출현 전에 걸치는 경우는 제외한다. 정렬은 사전 작업분을 시작 대기시간으로 완만하게 할인하며5분 이내 우선 그룹을 제거했다. 지금/희귀 탭의 선별·정렬과 기존 작업량 통계 자체는 유지한다.
- 최신 목록은 전체 폭을 사용하며 고정 오른쪽 영역을 제거했다. FishRowRenderer의 아이콘/등급·미끼 연결·직감 배지·지도 핀을 공유하고 날씨·ET 토큰은 생략한다. 넓은 폭은 어종/위치/미끼, 출현 상태/실제 구간/준비 어종, 다음 회차/30일 횟수/버튼과 아래 추천 이유의 네 줄이다. 첨부 화면에서 불필요한 두 열/다섯 줄 전환을 확인해 기준을 글꼴50배에서42배로 낮추고 목록 안의 세로 간격을 글꼴0.18배 이하로 제한했다. 가상 목록도 같은 높이를 사용한다.
- 하단 잘림은 TextWrapped와 부족한 높이 예약을 수정했다. 별도 고정 높이 영역에 짧은 조회/갱신 문구를 줄바꿈 없이 표시하고, 공간이 부족하면 조회 시각만 남긴다. 바깥 스크롤을 막고 목록 높이에서 하단과 간격을 먼저 뺀다. 제외 버튼의 폭을60% 이내로 제한해 UI 확대에서도 시각 영역을 남긴다.
- 생미끼 추천 이유는 일반 경로/선택된 보관 경로를 명시하고 확정적인 ‘이번 출현에 도전할 수 있습니다’를 제거했다. 보관 여부는 Plan.StoredItemId 기준이며 대안 경로의 보관 여부를 현재 계획으로 오인하지 않는다. Core 계산/정렬은 변경하지 않았다.
- 행/상세 버튼은 기존 어종 상세를 열고, 추천 근거 버튼은 준비 어종별 구간·이유·계산값 팝업을 연다. 지도·버튼이 행 클릭도 함께 실행하지 않도록 분리했다. 팝업은 선택 당시 snapshot/탭을 사용하며 조회 세대 변경·캐릭터 전환·화면 이탈 때 참조를 폐기한다. 선별/정렬은 변경하지 않았다.
- 고정 시각 없는 직감 대상은 대표 준비 어종 자체의 실제 출현 구간을 ‘직감 준비 어종 출현’으로 표시한다. 대표는 필요한 직감 어종 중 출현 횟수가 가장 적은 어종이며 이름·수량을 연결한다. 작업자가 선택한 계획의 직감 어획별 달력을 캡처하고, 상세는 준비 어종별 구간/마릿수를 제공한다. 같은 어종이 여러 구간에 나뉘면 따로 표시한다. 준비 시작 추정/합친 가상 구간을 출현 시각으로 사용하지 않는다. 실제 준비 상태/자동 순위 변경은 추가하지 않았다.

## 자료·소스 검토

- 내장 대표5종의 경로/요구 수량/시간 제한을 읽어 모델 입력과 대조했다. 롱카의 앞2단계와 Priest의 ET10–12, Charibenet의 공유 어획, 칠채천주의3종/분리 시간대, 스테타칸투스의 조각가2마리, 홍룡의 쿠얼 경로를 확인했다.
- 조각가는 내장 BigFish=false이므로 일반 선행 예산을 그대로 적용하지 않고 명시적 계획 여유를 둔다. 조건 ID/시간/마릿수 원본은 수정하지 않았다.
- 다른 선행 어종을 잡기 위한 미끼가 다시 직감 요구에 포함되는 교차 누적(예:52009→52002의43740)은 일반 경로로 확정하지 않고 확인 필요로 남긴다.
- 직감 최종 어획이 선행 구간 종료 직전에 가능하고 버프가 목표 출현까지 이어지는 경우를 허용한다. 준비 기준 경로를 과거에 시작시켜 누적을 이미 채운 것으로 만드는 계산을 제거했다.
- 자체 조건 빈도는 완전한 복합 경로 빈도가 아니다. 시간 예산·순위 품질·모든 어종의 경로를 독립 실측으로 대조하지 않았다.

## 알고리즘 회귀 확인

앞선 좌우 배치 수정은 UI 조건만 바꾸고 테스트를 재실행하지 않았다. 이번 사용자 첨부 화면은 변경 전 추천 화면의 배치 문제를 확인하는 근거이며, 새 간소화 화면의 실기 확인을 대신하지 않는다.

이번에는 출현 후에만 가능한 직감 준비의 사전 작업 제외, 출현 시각을 걸치는 작업의 부분 계산/확보 마릿수0 유지, 상시 직감 대상의 선행 준비 유지, 미래 선행 구간의 현재 기회 오인 방지를 고정 입력4개로 추가했다. 롱카 기존 입력에 출현 전 생미끼2단계 검사를 보강했다. 추천17개 결과는 로컬 `.cache/recommendation-tests/recommendation-simplification.trx`에 있다.

처음7개 입력에서3개 결함을 수정 전에 재현했고 수정 뒤 모두 통과했다. 이후 탭 기준·간격·갱신 검사를 더해13개를 고정했다. 결과는 로컬 `.cache/recommendation-tests/recommendation-before.trx`, `recommendation-repair.trx`, `recommendation-focus.trx`, `recommendation-final.trx`에 있다. 입력은 [FishRecommendationTests](../../../tests/DuckbillFisher.Core.Tests/Forecast/FishRecommendationTests.cs)의 통제된 시간/조건이며 실제 어획 시간 측정이 아니다.

## 게임 대표 확인 대기

1. 메인 → 추천 진입: 기본3시간/미수집/세 탭, 상단 조작/탭 두 행·하단 조회 시각과 전체 폭 목록을 확인한다. 아이콘/등급·지도 핀/낚시터·미끼 연결·직감 배지를 유지하고 날씨·ET는 없다. 출현 구간/다음 회차/횟수/추천 이유를 비교하고 전체 스크롤·긴 값/미끼 경로의 잘림 툴팁을 확인한다. 고정 오른쪽 영역은 없다. 현재 생미끼/직감 수량은 반영하지 않는다.
2. 목록을1분 이상 읽는다: 기준 시각/순위는 유지되고 현재 잔여/갱신 안내만 바뀐다. 다시 추천 또는 필터 변경 후 기준 시각·순위가 갱신된다.
