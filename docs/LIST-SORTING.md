# 목록 정렬 개선안

상태: 사용자 지정 순서 기록 · 지역 우선순위 세부 확인 중 · 구현 전 · 2026-10-16

## 확정 요구와 현재 동작

- 남은 시간 정렬은 필수다. 사용자가 지정한 순서는 현재 열린 제한 창(종료까지 짧은 순) → 예정 창(시작까지 짧은 순)이다. 출현순/종료순을 별도 메뉴로 나눌 필요 없이 하나의 ‘남은 시간순’으로 제공한다.
- 상시 어종은 선두에 두지 않는다. 맨 아래 표시를 기본안으로 두고, 숨기기는 기존 ‘시간제만’ 필터와 결합한다. 후자는 모든 비시간제 어종을 제외하는 필터이며 시간 정렬 자체가 어종을 제거하지는 않는다.
- 지역은 현재 지역 우선만 검토한다. 다른 지역끼리의 순서나 확장팩/지역별 묶음 UI는 이번 범위에서 요구하지 않는다.
- 현재 `FishListPanel.WindowSortKey`는 Open/Always를 함께 맨 앞에 두고, Upcoming은 다음 시작 시각으로 정렬한다. 동률은 FishParameter ID순이다. 열린 창의 종료 임박 순서는 제공하지 않는다.
- 남은 시간은 ET/날씨 창 기준 실제 시간이다. 직감·전승록·생미끼 등 개인 준비 완료나 낚시 성공을 뜻하지 않는다. 먼바다 방문 시간대를 어종별 출현 창으로 대신 계산하지 않는다.

## 정렬과 표시

| 선택 | 기준과 화면 표시 |
|---|---|
| 남은 시간순 | 열린 제한 창은 종료까지 짧은 순 → 예정 창은 시작까지 짧은 순. 각각 ‘종료까지 3분’ / ‘시작까지 12분’처럼 기준을 표시 |
| 이름순 / 어종 ID순 | 기존 기본 탐색 기준 유지 |

- 세부 그룹 순서는 종료 시각이 있는 Open → Upcoming → 시각 미확인(종료 불명 Open / NotFound / Unknown / 먼바다) → Always를 제안한다. 상시를 맨 아래에 두되 미확인을 0초나 상시로 취급하지 않는다. 시각 미확인은 이유를 구분해 표시한다.
- 남은 시간 동률은 어종명→FishParameter ID로 안정적으로 정리한다. 다른 지역 이름순을 별도 기준으로 추가할 필요는 없다.
- 시간 정렬을 기본 선택으로 바꿀지는 미정이다. 기존 기본값이나 선택을 임의로 변경하지 않는다.

## 현재 지역 우선: 확인할 한 가지

- ‘현재 지역 우선’ 체크로 단순화하는 안이다. 켜도 예정/상시 어종이 현재 열린 제한 창보다 앞으로 오지는 않는다.
- 각 그룹 안에서 현재 지역을 먼저 둘지, 남은 시간이 같은 경우에만 현재 지역을 먼저 둘지는 사용자에게 확인 중이다. 전자는 현재 지역 종료 10분이 타 지역 종료 1분보다 먼저 오며, 후자는 반대다. 답변 전 우선순위를 확정하지 않는다.
- 즐겨찾기 우선은 기존 기능을 유지한다. 시간순과 결합하는 새로운 즐겨찾기 옵션이나 복잡한 다중 정렬 편집기는 이번에 추가하지 않는다.
- 검색·수집·등급·시간제·지역/확장팩 필터는 포함 여부를 결정한다. 정렬은 포함된 결과의 순서만 바꾸며 어종을 추가/제외하지 않는다.

## 구현 시 지킬 기준과 확인 항목

- 복수 낚시터 어종은 현재 지역/지역·확장팩 필터를 같은 낚시터에서 충족하는 후보 중 대표 지역을 고른다. 행 표시와 정렬은 같은 대표 위치를 사용하고 중복 행을 만들지 않는다.
- 추천 낚시터와 대표 지역이 다른 경우 기존 조건·예측 위치 안내를 유지한다. 지역을 바꾸었다는 이유로 그 지역의 시간 창을 새로 계산했다고 표시하지 않는다.
- 남은 초 숫자 대신 시작/종료 UTC 시각을 정렬 키로 사용한다. 매 프레임 전체 재정렬/장기 예측을 하지 않는다. 예측·창 경계·필터/선택 변경 때 순서를 갱신하고, 현재 지역 우선 사용 시 지역 이동도 반영한다.
- 동률은 고정 ID까지 정리한다. 초 단위 카운트다운 갱신만으로 행이 흔들리지 않게 하고 선택·상세·언어 상태를 보존한다.
- 열린 창 여러 개/예정 창 여러 개/상시/미확인/범위 내 미발견/먼바다, 현재 지역 우선 전후, 지역 이동과 복수 낚시터를 확인한다. 예측 자체의 게임 ET/날씨 동시 대조는 별도 미확인으로 유지한다.
- 빌드·리소스 검사와 인게임 확인 결과는 구현 작업에서 기록한다. 이번 문서 작업에서는 DLL과 런타임 동작을 변경하지 않는다.
