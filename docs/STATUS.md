## 이번 작업

- 0.1.15.0: 사용자가 선택한 ‘시간제만’ 체크 + 전체/터주(터주왕 포함)/터주왕만 선택을 구현했다. 서로 다른 필터 사이는 AND이며 전체는 등급 제한만 해제한다. 목록/상세에 터주·터주왕 표지도 표시한다.
- KR 일반 도감 1258종의 명시적 설명 분류를 개발 중 ID 자료로 가공했다. 터주 335/터주왕 36종, 고정 조건 원본 903종과 불일치 0. 실행 중 UI 문자열/패치 번호로 추정하지 않는다. [재현/출처](../data/README.md).
- 시간제는 확인된 ET/현재·직전 날씨 제약이다. 정적 자료상 443종이며 현재 출현/준비 완료 여부와 구분한다. 분류/제약 미확인은 특정 필터에서 제외하고 전체에서는 유지한다. 먼바다를 일반 터주/시간제로 추측하지 않는다.
- 수집 필터는 전체/수집한 어종 숨기기/수집됨만/미확인만으로 정리했다. UI의 미수집만 제거, 내부 Unknown/미수집·수동 우선순위는 유지했다. UI 인덱스와 Core enum은 명시적으로 매핑한다.

1. 0.1.15.0의 분류/수집 필터 조합을 확인한다. 다음 구현 후보는 지역/확장팩 선택 필터의 범위 정리다. 통과한 현재 지역/목록 요약/전체 자료 연결 확인은 반복 요청하지 않는다.
