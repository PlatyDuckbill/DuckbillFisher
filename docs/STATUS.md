1. 다음 한 작업은 개발0.5.0.0 r6 정규 DLL의 얇아진 기본 크기 탭/글자·물고기의 눈 아이콘·좁은 배치·달력 목록 조절 확인이다. 사용자 사진은 이전 화면의 비율 문제 근거이며 새 수정본 확인을 뜻하지 않는다. 친구 PC·이전 예측/필터/미끼/성능/저장 장애·캐릭터 격리 미확인은 유지한다.
2. 다른 캐릭터 격리는 사용할 캐릭터가 없어 실기 보류. 모든 테마·보관 생미끼 다른 칸·신규 등록/작살 전환·좁은 폭/한영·장애/절전/상한은 별도 확인 대상이다.
3. 데이터 대표 화면과 외부 좌표 차이 4곳도 미확인이다. 정확한 근거가 생기면 잔여 데이터를 보완한다.
4. 사용자 보류: 복수 어획·수량, 입질 초 통계. 과거 Teamcraft 화면 차이 추적은 사실 자료 부족으로 중단했다. 직감 반영 구간의 실제 어획·나미타로 자체 날씨 조건은 게임 근거 확인이 남아 있다.
5. 터주작 후보·먼바다/작살·장기 목표는 [ROADMAP](product/ROADMAP.md)을 따른다. 새 글로벌 런타임 프로필은 실제 게임/DLL 계약과 데이터 검증 후 별도 도입한다.
