## 이번 작업

- 0.1.17.0: 확장팩 드롭다운을 직접 보이는 체크박스 표로 바꾸고 폭에 맞춰 1~3열로 표시한다. 지역 후보는 선택한 확장팩으로 한정하며 체크가 없으면 전체다.
- 지역 선택은 고정 크기 팝업으로 분리했다. 검색/해제/닫기 버튼은 고정하고 확장팩별 목록 하나만 스크롤한다. 기존 콤보/목록 중첩 스크롤 구조를 제거했다.
- 확장팩 변경으로 가려진 지역 선택은 유지한다. 남은 선택의 수·이름 툴팁과 범위 밖 선택만 해제하는 버튼을 제공한다. 접힌 패널에서도 안내/해제가 가능하다.
- 후보/검색/가려진 선택은 옵션·선택 revision·검색어 변경 때 캐시한다. Core 필터/게임 접근/데이터/진단 형식은 변경하지 않았다.
- 별도/정규 Debug 빌드 경고·오류 0, 한영 244키/형식 인자 검사 통과. 사용자 언로드 확인 후 정규 DLL/Core/ko/manifest 확인. 테스트 추가/실행 없음. [화면 확인 순서](validation/MVP-01-GEOGRAPHY-PICKER-UI.md).
- 사용자 ‘정상’으로 새 선택 UI의 대표 확인을 통과로 기록했다. 모든 화면 크기/한영 조합까지 확인했다고 확대하지 않는다. 이번 결과 반영은 문서만 변경하며 빌드/검사를 재실행하지 않았다.
- 0.1.12.0 전체 자료 연결과 대표 화면 확인은 통과 상태를 유지한다. 작살 UI/자동 수집과 외부 좌표 차이 4곳의 인게임 대조는 후속이다. [데이터 범위/근거](validation/MVP-01-ALL-SOURCE-DATA.md).

## 다음 작업과 보류

1. 다음 작업은 지역순/현재 지역 우선 정렬이다. 복수 낚시터의 대표 지역·지역 미확인·동률 기준을 짧게 정리하고 기존 필터와 결합한다. 확인된 선택 UI/집계/필터 기능은 반복 요청하지 않는다.
2. 신규 등록 시 자동 미수집 제거·작살 모드 전환·한영 조합은 추가 확인 대기. 다른 캐릭터 격리는 사용자 ‘다른 캐릭터 없음’으로 실기 확인 보류이며 진행을 막지 않는다.
3. 동일 캐릭터 재접속·홍룡 기본 판정은 통과했으므로 반복 요청하지 않는다.
4. 입질 초 수 통계는 사용자 요청으로 후순위. 런타임 HTTP·게임 조작 자동화는 범위 밖.
