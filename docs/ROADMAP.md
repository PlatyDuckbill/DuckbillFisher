# 구현 순서와 완료 기준

원래 Phase 1~5 앞에 한섭 호환성 검증을 추가하고, 사용자 가치가 빨리 드러나는 작은 범위부터 만든다.

| 단계 | 작업 | 완료 기준 |
|---|---|---|
| ENV-01 | 기존 한섭 설치의 개발 대상 확인 | 배포처·게임 빌드·Dalamud API·호환 템플릿·SDK 근거 기록 |
| ENV-02 | 최소 Plugin/Core/Tests와 빌드 | Windows 창 로드/언로드/재로드, 게임 독립 Core 테스트, SDK 고정 |
| ENV-03 | 캐스팅/수첩 읽기 기술 검증 | 실제 API/관찰 방식 확인, 로그와 실패 조건 기록. 불가능하면 범위/대안 명시 |
| MVP-01 | 전체 어종 목록 화면과 검증된 5~10종 상세 정보 | 스크롤·검색·기본 정렬·필터, 내장 데이터·출처·수동 미수집·즐겨찾기·미끼·클릭 지도 |
| SHARE-01 | 친구에게 URL 공유 | 첫 유용한 기능과 인게임 검증 후 커스텀 JSON/ZIP 게시, 친구 PC에서 설치·업데이트 확인 |
| MVP-02 | 캐스팅 타이머 | 시작/취소/완료/로그아웃, 목표 입질 구간 시각화, 재로드 중복 없음 |
| MVP-03 | ET/날씨와 알림 | 다음 창 시작/종료·남은 실제 시간·시간순 정렬, 알려진 예측과 대조, 창별 사전 알림 1회 |
| MVP-04 | 자동 수첩 필터 | 수첩 조회·새 어종 습득/등록 시 자동 갱신하고 숨김 필터 반영, Unknown/수동 override/캐릭터 격리 |
| RELEASE-01 | 데이터 확장과 배포 준비 | KR 패치별 검수, 성능·설정 복구·패키징, 제출 대상별 요구 확인 |

ENV-03은 완제품 구현이 아니라 불확실성을 줄이는 작은 실험이다. 검증되지 않은 기능은 구현 완료로 표시하지 않는다. 자동 수첩 연동 전에도 수동 필터로 MVP를 사용할 수 있다.

2026-10-16 사용자 우선순위 변경: 입질 초 수 통계를 후순위로 두고 나머지 상세 안내를 먼저 진행한다. 0.1.5.0에서 초기 10종 상세/지도 핀과 MVP-03의 기본 시간·날씨 창 카운트다운/시간순 정렬을 선행 구현했다. 황금나비어 지도 핀과 고정 원본 기준 예측 계산 대조는 통과했다. 실제 게임 ET/날씨 동시 대조와 나머지 MVP 기능은 별도로 남아 있다.

SHARE-01은 최소 배포 목표이며 이후 기능을 같은 URL로 업데이트한다. 공식 등록을 기다릴 필요는 없다. 현재는 빈 설치 목록과 로컬 배포 준비 도구까지 구현했고 공개 설치 항목은 없다.

0.1.6.0 구현: 즐겨찾기 저장/필터/우선 정렬, 캐릭터별 수동 수집 상태/해제, 수집한 어종 숨기기·미수집/수집됨/미확인 필터. 인게임 저장·복원·캐릭터 격리 확인은 대기다. 미확인은 미수집으로 간주하지 않으며 게임 수첩 자동 필터는 MVP-04로 유지한다.

후속 사용자 확인: 재로드 후 상태 유지는 통과했다. MVP-04는 수첩을 다시 열지 않아도 새 어종 습득/등록 후 갱신되는 것을 목표로 한다. 습득 감지 경로와 수첩 비트 반영 지연을 한섭에서 확인한 뒤 연결하며, 기존 Fishing 플래그를 어종 습득의 증거로 사용하지 않는다.

0.1.7.0은 이 요구의 첫 구현이다. 기존 범위의 수첩 True 관찰과 KR 도감 등록 LogMessage의 숫자 Item ID를 수집됨 필터에 연결했다. 자동 False→미수집 확정·전체 수첩 준비 판정은 남겨 두며, 등록 이벤트/수집 숨김/캐릭터 격리는 인게임 검증 대기다. MVP-04 전체를 완료한 것은 아니다.

후속 한섭 결과: 수첩 자동 집계 738종·황금나비어 자동 숨김·도감이 닫힌 상태의 가라루파 첫 등록 자동 반영(739종으로 증가)을 확인했다. 로그아웃/재접속·다른 캐릭터 격리와 자동 미수집 판정은 여전히 남아 있다. 세부 근거는 [자동 수집 검증](validation/MVP-04-COLLECTION.md)을 따른다.

## 어종 목록 화면의 구현 시점

지도 버튼으로 낚시터 위치에 핀을 표시하는 기능은 MVP-01에 포함한다. 미끼·생미끼·섬세/강력한 낚아채기·입질 시간 안내를 위한 출처와 검증 범위는 [데이터 계획](DATA-SOURCES.md)을 따른다. 입질 경과 타이머는 MVP-02, 다음 출현까지의 카운트다운은 MVP-03에서 연결한다.

MVP-01에서 어종 아이콘·이름·낚시터·미끼를 행으로 표시하는 메인 목록을 만든다. 게임 시트에서 확인한 전체 어종을 탐색할 수 있는 구조로 만들고, 조건·미끼·지도 등 상세 정보는 검증된 5~10종부터 채운다. 상세 데이터가 없는 어종은 미확인으로 표시하며 목록에서 임의로 제외하지 않는다. 현재 진단 탭의 검색 결과 30행 제한은 제품 목록의 제한이 아니다.

| 기능 | 구현 시점 |
|---|---|
| 전체 어종 스크롤, 이름 검색, 지역·확장팩 필터 | 0.1.16.0 필터 기능과 0.1.17.0 확장팩 체크/지역 선택 UI의 사용자 대표 확인 통과 |
| 이름순·즐겨찾기 우선 정렬, 안정적인 동률 순서 | 기본 구현. 현재 지역은 기존 체크박스 필터로만 적용하고 정렬 기준에서 제외 |
| 즐겨찾기·수동 수집 상태 필터 | MVP-01 |
| 시간제 / 터주 / 터주왕 / 모두 보기 분류 필터 | 0.1.15.0 시간제 체크 + 전체/터주(왕 포함)/터주왕 선택 구현. 기존 필터와 AND, 런타임 집계/수집 조합 표본 확인 |
| 필수 남은 시간 정렬: 열린 창 종료순→예정 창 시작순, 상시 후순위 | 다음 작업. 기존 시간순의 종료 임박 정렬 누락 보완. 지역 필터와 독립 적용. [개선안](LIST-SORTING.md) |
| 실제 게임 수집 상태에 따른 자동 필터 | MVP-04 |

스크롤은 화면에 보이는 행 위주로 그린다. 검색·필터·정렬 결과는 입력/데이터 변경 때 갱신하고 매 프레임 전체 어종을 다시 계산하지 않는다. UI 문구는 기존 다국어 리소스와 고정 위젯 ID 규칙을 따른다. 시간/날씨 창 표시를 직감·생미끼 등 모든 낚시 조건 충족으로 표현하지 않는다.

## 상세 UI 요청 (2026-10-16, 0.1.10.0 대표 어종 확인 통과)

- 미끼와 생미끼 경로의 모든 중간 물고기: 실제 Item ID의 아이콘/이름 버튼을 누르면 내 채팅창에 게임 아이템 링크를 표시한다. 채팅 링크로 아이템 정보를 연다. 직감 필요 어획도 같은 링크를 제공한다.
- 섬세한/강력한 낚아채기: 해당 스킬 아이콘과 이름을 표시한다.
- 현재/직전 날씨 조건: 해당 날씨 아이콘과 이름/툴팁을 함께 표시한다.

초기 상세 데이터 10종에 적용했다. 공개 링크 API와 실제 한섭 Item/Action/Weather 참조를 사용하며 한국어/영어 UI와 고정 위젯 ID 규칙을 유지한다. 사용자 ‘정상’ 응답으로 대표 어종의 아이템 링크/조건 아이콘을 확인했다. 한영 전환 조합은 별도 미확인이다. [구현 근거와 결과](validation/MVP-01-ITEM-LINKS-ICONS.md)를 따른다. 입질 초 수 통계는 계속 후순위다.

## MVP 이후

전체 확장팩의 검증된 상세 데이터 확대, 복합 조건 상세 지원, 미끼 선택창의 시각적 하이라이트, 접근성·UI 개선. 데이터를 늘릴 때 알고리즘 지원 범위를 함께 확인한다.

사용자 요청으로 다음 데이터 작업은 확장팩별 추가 대신 전체 원본 분류/일괄 확대다. 사전 점검에서 대체 미끼·훌치기/유인·물고기의 눈 안내·전승록 이름과 필드별 미확인 보완이 필요함을 확인했다. 원본 일반 도감 대응은 903/1258종이며 먼바다 자료는 별도로 필요하다. [수록 범위와 누락 점검](validation/DATA-COVERAGE-REVIEW.md)을 따른다.

0.1.12.0 전체 자료와 0.1.13.0 목록 요약·0.1.14.0 현재 지역 필터는 사용자 대표 확인을 통과했다. [데이터 범위](validation/MVP-01-ALL-SOURCE-DATA.md). 0.1.15.0의 분류 집계와 터주왕+수집됨 조합 표본을 확인했고 한영/전체 선택 화면은 별도 미확인이다. 어종별 먼바다 조건/작살 UI·연동은 후속이다.

0.1.16.0의 지역·확장팩 필터 기능은 사용자 대표 확인 통과. 0.1.17.0은 직접 보이는 확장팩 체크와 선택 확장팩만의 지역 후보, 단일 스크롤 팝업·범위 밖 선택 안내/해제를 구현했고 사용자 대표 확인을 통과했다. 다음은 남은 시간 정렬이다. 사용자 결정으로 현재 지역은 기존 체크박스 필터로만 유지하며 지역 우선 정렬/지역별 묶기는 추가하지 않는다. 상세 정책은 개선안을 따른다.

0.1.11.0: 같은 고정 원본의 신생 에오르제아 상세를 10→140종으로 확대하고, 재현 가능한 한섭 참조 대조 도구를 추가했다. 낚시터 없는 보조 15행은 상세에서 제외했다. 인게임 140종 연결/목록 결과와 사용자 대표 확인을 통과했으며 다음 확장팩은 지원 조건 검수 후 진행한다. [확대 기록](validation/MVP-01-DATA-EXPANSION.md).

## 공식 제출

목표 저장소가 글로벌 upstream인지 한섭 배포판 저장소인지 먼저 특정한다. 해당 환경에서의 호환성과 현재 정책을 확인한다. 사람은 자신의 코드와 설계를 설명하고 직접 테스트하며, upstream 제출용 PR 설명과 AI 사용 공개문은 직접 작성한다. 승인 여부는 심사 결과로 결정된다.
